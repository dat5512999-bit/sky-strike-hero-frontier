## 0.60.0 桌面瀏覽器縮放適配（2026-09-16，本機）

戰鬥 HUD 現在會依可用 CSS Viewport 選擇閱讀密度：寬螢幕 100% 縮放會放大 Wave、資源、英雄、技能、小地圖與快捷按鈕，使閱讀大小接近原本 150% 的舒適比例；150% 與 200% 則使用緊湊配置。倍速／開波列在三種縮放下都維持水平置中，暫停鍵固定於資源列最右側。此版只調整個別 HUD 元件，沒有縮放整個頁面，也沒有修改地圖、Camera、Canvas、輸入座標或戰鬥數值。

## 0.59.0 遠征選角美術與軍團識別（2026-09-16，本機）

「選擇遠征」已改為 RPG 選角式呈現：四張難度場景、三張大型英雄立繪，以及王國／銀葉／暮影三張獨立軍團橫幅都由資料欄位提供。英雄與軍團不再共用同一張人物圖，既有「難度 → 英雄 → 軍團 → 開始遠征」流程、數值、解鎖與戰鬥邏輯不變。圖片皆為本機 Asset，可在 `HeroRoster`、`FactionSystem`、`TDDifficultySystem` 更換，不需改 UI 程式。

## 0.58.0 戰場清晰度與緊湊操作介面（2026-09-15，本機）

新手谷地的快怪現在會沿同一條路在慢怪後方保持依體型計算的最小間距，不再穿進前方模型；這是路徑前進量限制，不是碰撞、推擠或第二條道路。此地圖暫時關閉英雄受傷並隱藏 HP，舊傷害／復活能力仍可供未來地圖啟用。桌面建造 Drawer 會一次顯示本軍團全部項目並依金幣、木材由低至高排列，手機橫向保留滑動；重複的「收合建造」按鈕已移除。軍械庫與戰利品改為不遮滿戰場的緊湊視窗，戰鼓堡三級不再疊加巨大通用旗幟。正式地圖維持原座標，只提高影像濾圖並把近看倍率限制為 1.65 倍；真正更近的高精度仍需同座標 2× Map Asset。

「選擇遠征」已先完成單一視窗的難度／英雄／軍團資訊層級；目前仍使用可替換的戰鬥預覽。使用者提供的完整概念合成圖可作正式視覺基準，但不能直接當互動頁面；獨立英雄與難度圖片仍需由該視覺拆分或補齊後放入 Asset Slot。

## 目前功能

- 滑鼠平滑控制玩家戰機，並限制於畫面邊界。
- 自動單發直線射擊。
- 普通敵機由畫面上方生成並向下移動。
- 子彈／敵機與玩家／敵機碰撞、HP、短暫無敵與擊破效果。
- 分數、死亡、暫停與重新開始。
- 6 套可即時切換的外觀包；玩家、雙彈體、敵人、特效、背景與 HUD 會成套更換。
- 外觀選擇保存在本機，包含會交替射出漢堡與薯條的「歡樂速食」。
- 手機相對拖曳操作、瀏海安全區、直向提示與 44px 觸控按鈕。
- GitHub Pages 自動部署、可加入主畫面及首次載入後離線啟動。
- 塔防士兵部署後在射程內自動攻擊；不承受怪物傷害，也不阻擋怪物。每名士兵獨立升級、累積熟練並可裝備最多一件軍械。
- 五級威脅曲線，逐步加入高速、追蹤、射擊與大型菁英敵機。
- 敵方瞄準彈與菁英三向彈幕。
- 草莓散射、香蕉連射、葡萄護盾、鳳梨清場四種技能果實。
- 同種果實可升至 Lv.3，逐級增加彈道、射速、護盾或清場傷害。
- 無傷 Combo 與 ×1～×5 分數倍率，護盾成功格擋不會中斷。
- 本機保存難度、最高分與歷史最高 Combo，死亡畫面提供本局比較。
- 休閒、標準、困難、無雙四種難度，各自調整敵潮、速度、威脅與果實經濟。
- 無雙模式讓散射與連射整局不限時，但敵軍生成、移動與威脅升級也大幅加快。
- 限時獵殺與無傷考驗交替出現；成功可取得一般掉落不會出現的龍果覺醒。
- 鳳梨清場依難度降至 10%／6%／4%／2% 的果實權重，避免清場過度頻繁。
- 分層星流、雲霧光塵、航線刻度、動態暗角與高威脅環境染色。
- 玩家傾斜、主題引擎尾焰、玩家／敵方子彈光跡與旋轉道具光環。
- 敵機類型以速度尾跡、鎖定框、炮台與菁英裝甲弧辨識，不再只靠色圈。
- 擊中火花、爆炸粒子、核心閃光、衝擊波與有限畫面震動。
- 100 波資料驅動遠征，共 10 個章節、20 個戰區，每 5 波固定進入 Boss 戰。
- 第 10、20…100 波為章節霸主，Boss 依血量切換三階段彈幕與狂暴速度。
- 第一波保證鏡像核心，解鎖自動射擊的戰機分身；升級後可增加為雙僚機。
- 第三波保證星靈核心，解鎖環繞玩家、自動索敵射擊的戰寵。
- 分身與戰寵為獨立支援系統，可與主武器果實同時成長。
- 防線耐久讓漏掉的普通敵機造成 1 點、大型菁英造成 2 點損傷；歸零即結束遠征。
- 休閒／標準／困難／無雙分別擁有 7／5／4／4 點防線，低耐久會顯示紅色警示。
- 一般波輪替狂戰號角、鐵壁符文、秘法疾射與雙生軍陣；HUD 與戰場符文會預告規則。
- Boss 威壓提高節奏，三階段改為 6／9／14 發瞄準或旋轉彈幕，章節霸主再追加火力。
- 新增獨立「英雄塔防」模式：30 波職業遠征，每波敵軍更密集且每 5 波出現首領。
- 塔防選職後進入 18 秒首波準備，其後每波有 12 秒整備；可閱讀敵種、數量、護甲與戰術提示，也可按「立即開始」跳過倒數。
- 金幣與木材改為清場後結算，30 波由獨立資料表控制名稱、編成、威脅與獎勵；六個 Boss 波的總耐久均高於前一波。
- 塔防新增遠征見習、邊境守衛、軍團老兵、災厄遠征四種難度；敵軍生命、傷害、速度、生成間隔、整備時間、城門生命與獎勵會成套調整。
- 30 波會逐步混編戰紋盾衛、血契祭司與軍團旗手：分別吸收首輪火力、治療傷兵，以及強化附近敵軍速度與護甲。
- 邊境步兵換用重新整理的半獸人 4×4 動作圖集，包含八格步行、四格受擊與四格倒地，維持既有速度、HP 與波次數值。
- 新增八把透明武器候選圖集，供後續英雄裝備外觀與掉寶系統使用；目前不改變戰鬥數值。
- 英雄商店的武器鍛造改為三職業專屬進階鏈；英雄卡會顯示目前武器與稀有度，戰場上的武器光效、彈道與技能色會隨精良／史詩／傳說階級強化。
- 暗影英雄購買武器後改用無武器 4×4 動作底圖，再依待機、行走與四格攻擊姿勢把左右武器貼到雙手；移除常駐的大型月牙光圈與烘焙斬擊，未載入完成時安全回退舊圖。
- 新增本局逐波戰報，記錄擊破、漏怪、城門損失、英雄倒下、守軍戰敗、戰鬥時間與收入；第 5／10 波會在整備期自動顯示 Boss 戰報。
- 開局分別選擇英雄與軍團；英雄有獨立普攻、技能、召喚與武器，軍團提供自己的守軍及防禦塔，可自由交叉搭配。
- 職業守軍是可獨立升級、熟練與配裝的固定火力；部署完成後位置永久不變，英雄仍可由玩家移動。

- 獵手、奧術師與盜賊使用各自 4×4 待機／行走／攻擊／受擊動作圖集，保持原始人物比例，不再壓成正方形概念圖。
- 士兵與塔皆禁止部署在道路，不攔怪、不阻擋；並共同遵守草地、邊界與防重疊限制。
- 新增林地弩塔、寒霜水晶塔與赤焰火砲塔三種不同外形建築，分別提供穿刺遠射、緩速及範圍爆破。
- 職業單位可升至 Lv.5，高階晉升消耗 Boss 掉落的功勳；出售仍回收總投入 70%。
- 加入金幣、木材、功勳三資源，以及穿刺／魔法／混沌對輕甲／重甲／秘法護甲相剋。
- 玩家直接操控英雄移動；英雄會自動射擊，靠近敵軍會攔截減速，並可施放範圍霜環震擊。
- 塔防包含金幣、擊殺獎勵、建造／升級成本、城門生命、漏怪傷害、勝利與失敗結算。
- 塔防改為原創經典 PC RTS 美術：低彩度軍營、農田、木牆、循環泥路、大面積建造草地與三種人物型守備單位。
- `ArtSystem` 負責本機 PNG 載入與圖集裁切；資產未載入時仍保留 Canvas 降級繪圖，不會出現空白畫面。
- 完全本機執行，不需登入、伺服器或第三方套件。

## 立即開始

1. 在專案資料夾雙擊 `index.html`。
2. 使用 Chrome 或 Edge 開啟。
3. 按「開始任務」，移動滑鼠操控戰機。

若要遊玩塔防，在射擊模式開始畫面按「進入英雄塔防模式」，或直接開啟 `td.html`。

手機使用手指在遊戲畫面任意位置拖曳；戰機依拖曳距離移動，手指不必壓在戰機上。

詳細說明見 [使用者操作手冊](docs/USER_GUIDE.md) 與 [安裝手冊](docs/INSTALLATION.md)。
