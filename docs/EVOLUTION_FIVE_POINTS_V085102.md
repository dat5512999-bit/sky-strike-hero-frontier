## 玩家操作與常見問題

照原方式購買進化石、擊敗火焰惡魔後，英雄才進化並回到 Lv.0。成功面板可看放大前後比較，按「繼續戰鬥」恢復遊戲。新圖不改初始武器、三階商店升級或軍械相容性。

若仍看到商城造型，在選單設定或英雄資訊切換為進化外觀；此功能保留造型所有權，沒有重買需求。沒有已購造型時直接顯示進化本體。進化圖尚在下載或載入失敗時，會先使用既有替代畫法，不阻擋遊戲。

若仍看到舊圖，先確認遊戲版本是否為 0.85.102。此版本尚未上傳，正式網站仍可能是舊版；不要用清除瀏覽器資料處理，避免丟失存檔。發布後使用 update.html 更新。

## 美術設計與檔案

依 imagegen 與英雄內容指引，以遊戲內原始動作圖作身份參照，不用選角立繪代替實際身形。矮人保留矮壯體型、深色頭盔及橘色雙辮鬍鬚，覺醒為青藍符文重甲，超凡為黑金甲與紅披風。地精保留尖耳、黃綠皮膚與戴在眼前的青藍護目鏡，覺醒為工作服與雙核心背包，超凡為橘色熔爐動力甲。

四張正式素材都位於 `assets/td/evolution/`，採真透明 4×4 圖集，包含待機、走路、攻擊、施法各四格：

- `dwarf-awakened-actions-v2.png`
- `dwarf-transcendent-actions-v2.png`
- `goblin-awakened-actions-v2.png`
- `goblin-transcendent-actions-v2.png`

工具模式為內建 imagegen 編輯，`transparent_background=true`，每張參照同英雄 `hero-actions-v2.png` 及該階舊版圖。四張 v1 原圖均保留，沒有像素後製或覆寫。提示設計與可重製規格見 [美術提示紀錄](EVOLUTION_ART_V085102.json)。生成結果仍需逐格量測，不能把同一套裁切座標套給新圖。

## 已驗證的戰術差異

測試直接執行正式技能與傷害管線，不只比對說明文字。固定 Lv15、武器 Lv3，個別技能使用獨立場景；敵人高生命值僅為觀察效果而不被一擊清除。這不是通關速度測試。

## 架構與 API

沒有新增伺服器、資料庫、API endpoint 或存檔欄位。沿用前版玩家外觀偏好與進化 rank。

```text
英雄 rank ＋ 玩家外觀偏好
  → HeroEvolutionSpriteArt
    → HeroEvolutionSpriteAtlas 的四筆 v2 路徑與裁切資料
      → 按需載入透明 PNG → 正式角色繪製 → 軍械疊圖
    → 缺圖／付費造型走既有替代路徑

同一圖集目錄 → sw.js 離線資產清單
             → verify-pages-release.cjs 發布逐檔比對
```

裁切資料在製作時量測，正式遊戲不做每幀像素掃描。`worldHeight` 保持原設定；碰撞、射程與數值不變。發布檢查允許正整數圖片版本後綴，但仍限制在 evolution 目錄與覺醒／超凡命名，防止只驗舊 v1 圖而漏驗新圖。

## 安裝設定與管理驗收

沿用現有 [安裝手冊](INSTALLATION.md) 與 [管理者手冊](ADMIN_GUIDE.md)，沒有新套件。以隔離測試玩家進行管理測試，不修改真實帳號鑽石、購買紀錄或遊戲進度。

```text
npm test
npm run check:site
npm run serve:test
```

另一終端以既有 Playwright 與 Edge 執行 `npm run qa:evolution-all`、`npm run qa:evolution-review`；本機 URL 可設 `EVOLUTION_QA_URL=http://127.0.0.1:4173/td.html`。`npm run qa:local-update` 自行啟動隔離測試伺服器，預設讀取 v0.85.100 Git 標籤，不改 Git 或玩家瀏覽器資料。若開發用 shell 找不到 Playwright，將 NODE_PATH 指向既有 runtime，玩家不需安裝。

驗收紀錄：全套 1,183／1,183 項通過；64 個新姿勢無裁邊或漏出實心像素；全部共享圖集 320 姿勢通過。11 英雄兩階雙尺寸共 44 組購石至成功／Lv.0／存檔還原通過；四種 UI 尺寸、付費造型切換與缺圖回退通過。本機 HTTP 發布驗證 265 檔／271 次請求比對通過，不代表遠端已部署。已視覺檢視矮人、地精三階並排，以及雙階四狀態左右鏡像／最高裝備疊圖。截圖與 JSON 報告位於 `artifacts/evolution-all`、`artifacts/evolution-review`、`artifacts/pages-update`，不隨正式遊戲發布。

靜態交付為 827 檔、878,579,075 bytes，約 879 MB；這是全部發布內容，不是開場下載量。新版四圖約增加 7.1 MB，保留 v1 便於回復；舊圖不會因保留在發布目錄就被開場請求。

## 部署備份與回復

遵循 [部署手冊](DEPLOYMENT.md) 與 [備份還原手冊](BACKUP_RESTORE.md)。發布前先匯出完整存檔，再建置與上傳；部署後才對線上執行 `npm run verify:pages`。本機更新成功不代表已上傳 GitHub。

套件、HTML、Worker、更新入口、ProfileStore、FrontierApp 與戰報版本已同步為 0.85.102。Git 標籤與遠端發布尚未建立。需要回復時先保留目前工作，在獨立目錄取出已發布 v0.85.100，依部署程序回復；不對這份工作目錄做破壞性 reset。若僅回復美術，需同時還原 v1 圖集路徑與對應裁切資料、離線清單，並發新的快取版本，不能只改檔名。
