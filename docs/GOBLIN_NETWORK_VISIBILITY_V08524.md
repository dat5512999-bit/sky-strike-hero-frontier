# 地精工程團：供能效果可讀性熱修（v0.85.24）

## 玩家會看到什麼

地精網路不再只以「供電／缺電」描述狀態。每個需要供電的裝置在戰場上會常駐顯示實際結果：

- 攻擊裝置：`供電 +22%傷害`；若沒有供電則為 `缺電 未獲 +22%傷害`。
- 重型攻擊裝置：沒有供電時顯示 `缺電＝停機`，因為它確實不會開火。
- 回收、技師與冷卻站：標示回收、機械支援或冷卻效果是否啟動。
- 動力機座：標示 `供能 used/capacity`，例如 `供能 1/3`；青色連線畫在單位與建築上層，不會被美術遮住。

這些是結果提示，不是指定建造順序或固定教學。部署預覽與選取資訊也會沿用同一套語意。

## 規則與相容性

本熱修沒有改動傷害、攻速、價格、初始資源、機座半徑／容量、超載、回收上限、英雄武器、軍械、掉落、存檔資料或戰報平衡版號。既有 `goblin-balance-v08523` 戰報樣本仍可用。

## 驗收與回復

自由遠征選地精後，部署動力機座與火器手／武器台：火器手或武器台應出現 `供電 +22%傷害`，機座應出現 `供能 1/3`，兩者之間有青色線。把重型裝置放在機座範圍外，應顯示 `缺電＝停機`。重新開啟遊戲後版本應為 `v0.85.24`，Service Worker 快取為 `sky-strike-v0.85.24`。

執行 `node --test tests/td-goblin-network.test.js` 與 `npm run check`。回復本版本只需連同 `sw.js` 與版本檔回到前一版；沒有資料庫或存檔遷移。
