# v0.85.94 · 漫畫取代舊劇情呈現

日期：2026-10-10。本機整合；尚未推送 GitHub 或部署 Pages。內容功能版號 storyMangaVersion 1.0.0。

## 使用者操作

1. 以 `npm run serve:test` 開本機站，瀏覽 `http://127.0.0.1:4173/td.html`；手機用 `td-mobile.html`，沿用橫向遊戲。
2. 大廳點「劇情模式」直接進入彩色漫畫；第一次從古代篇開始，之後回到目前玩家的續讀位置。
3. 用上一頁／下一頁、頁目錄，或鍵盤左右鍵、Home／End 翻閱。古代 6 頁後明確進入當代 6 頁。
4. 「放大拖看」保留整張圖，滑動或滑鼠拖曳查看；「故事文字」提供可放大的文字版本；音樂按情緒切換，可關閉。
5. 「返回章節」進入選關。關卡按鈕顯示簡短任務摘要，再明確按「開始戰鬥」；不會因讀完、翻頁或退出而自動開戰。

**尚未完成漫畫的關卡不再顯示舊插圖旁白，也不拿序篇 12 頁假裝是各關劇情。** 任務摘要會清楚提示漫畫尚未繪製。舊劇情資料與舊序章觀看紀錄留存供後續編劇及回復，正常 UI 入口不再播放舊式閱讀器／序章。

## 本次內容範圍

- 古代篇：同一條路、各有所長、下一趟也一起走、不必每次都道別、一座共同的城、把想法建成家。
- 當代篇：共同城市、雷恩正式介紹版城門頁、各族期待、王子的分量、王冠之外、首相與人類王的介紹／會面頁。
- 角色設定板不當成漫畫、不部署。公主、王子及團長等尚未登場者的候選臉，不因本次整合自動綁定既有 Hero ID。
- 雷恩仍為王國英雄，不擅自等同禁衛軍團長；公主不擅自等同希爾芙。首相與人類王使用本批指定外觀，但不揭露陰謀答案。
- 古代平民不是建城唯一始祖，各族在古代也已有文明；古代與當代沒有自造年份。

## 架構與資料流

```text
大廳「劇情模式」 → StoryManga → 12 頁 StoryMangaCatalog
                              ├─ WebP 圖片：目前頁＋下一頁預載
                              ├─ StoryMusic：目前頁情緒，退出停止
                              └─ ProfileStore.adapter('manga')：玩家隔離書籤
漫畫「返回章節」 → 既有選關 → 簡短任務摘要 → 原 launchStory／進度檢查
```

`src/td/app/StoryMangaCatalog.js` 為正式閱讀順序，保存穩定 page ID、年代、標題、圖片、情緒、摘要與台詞。`StoryManga.js` 負責呈現、導覽、圖片解碼／失敗重試、書籤及新入口。`td-story-manga.css` 採完整圖片 contain 和可捲動放大，不裁切漫畫或改成直向遊戲。

FrontierApp 只增加漫畫與任務摘要的 render／attach 分支，再安裝入口路由。原戰鬥與解鎖規則未更動；摘要的開始按鈕和實際動作皆檢查前置任務，預覽關卡不能開戰。

## 儲存、API 與權限

無遠端 API、資料庫或新權限。瀏覽器玩家檔案的 `data['manga:bookmark-v1']` 保存穩定 page ID，不保存路徑或任意 HTML。透過原有 ProfileStore 原子寫入與併發檢查，包含在玩家匯出／匯入、封存及回復內。管理者與一般玩家書籤隔離。

`StoryManga.open(app, index?)` 讀取續讀點；`turn(app,index)` 只接受整數並限制範圍；`render/attach` 產生安全文字及當頁圖片；`brief/renderBrief` 保留任務操作。`install(App)` 將 story/cinematic/replay 導向漫畫，story-battle/story-card-replay/chapter-battle 導向任務摘要。這些是專案內部 JavaScript 介面，不是 HTTP API。

圖片與文字使用本機靜態清單，文字經 HTML escape。壞書籤回到第一頁；儲存失敗不封鎖閱讀，顯示先備份、不要清除資料的提醒。閱讀不新增通關、解鎖、購買、獎勵或舊序章已觀看旗標。

## 圖片、效能與發布

12 張已繪製 PNG 保留在 concepts；發行用 WebP 複本在 `assets/td/story/manga/`，約 7.6 MB。轉碼 quality 92，不縮小、不裁切。`scripts/prepare-story-manga.cjs` 使用 sharp 重建缺少的發行複本，已有檔案不覆寫；要換圖請出新檔名並更新清單。

遊戲執行不需 sharp 或 Playwright。發布檔已包含 WebP，只需現有 Node 18+ 靜態站流程。開發者重建圖片／執行瀏覽器 QA 才需可解析的 sharp／playwright 套件與 Edge。可使用既有開發環境或設定 NODE_PATH 到工具提供的依賴位置。

CSS、清單與閱讀器納入 service worker 的程式快取；圖片沿用按需快取，不在首次開啟時預載全部漫畫。沒有讀取過的頁面在離線時可能無法顯示，仍可看文字；恢復連線後按重新載入。`img.decode()` 完成才標記可見，避免把下載完成當成已繪製。

整包版號 0.85.94 與 sw cache 同步。正式打包 `npm run check:site`、`npm run build:site`；後者若 `_site` 已存在，依原流程先備份舊輸出，不直接覆蓋。需同時部署程式、CSS、WebP 與 service worker。concepts／設定板仍排除。這次沒有執行 push 或 Pages 部署。

- 單元測試：頁序、12 個唯一圖片、情緒、文字轉義、壞書籤、儲存失敗、玩家隔離、匯出、入口取代、關卡鎖定、預覽不開戰、發布路徑。
- 瀏覽器 QA 已通過：獨立 Edge context，桌面 1365×900、手機橫向 844×390 與 667×375；逐張載入 12 頁、圖片解碼、按鈕邊界、放大、文字、音樂、續讀與圖片故障重試。輸出在 `artifacts/story-manga/`。
- 2026-10-10 全套 Node 測試 1,088 項通過、0 項失敗，靜態發布檢查通過；修改舊流程測試時改驗收新路由，保留舊資料測試而不刪資料。
- iPhone Safari 真機尚未驗收；手機看整頁時字會較小，使用放大或故事文字。自動逐格鏡頭尚未提供。
- 王室／關鍵人物後續正面分鏡、其餘關卡漫畫、完整故事結局尚未完成，本版不宣稱全部劇情已重畫。

## 常見問題與回復

找不到漫畫：從大廳點劇情模式，不是自由遠征。仍看到舊旁白：確認版本 0.85.94，關閉舊分頁並透過 update.html 更新程式；不要清除玩家資料。本機修改不代表 GitHub 已更新。

圖片空白：等待載入或按重試，也可開故事文字；斷網時未快取頁需恢復連線。文字小：放大拖看或故事文字。讀完沒解鎖：正常，仍需完成戰鬥。

更新前從設定匯出完整玩家備份，保存上一整包站台。回退用上一整包程式與對應快取版號；書籤是附加 data 欄位，舊版可忽略，玩家進度不需回滾。不以 git reset、刪網站資料或刪其他未提交檔案回復。原 PNG、舊漫畫與舊資料均保留。
