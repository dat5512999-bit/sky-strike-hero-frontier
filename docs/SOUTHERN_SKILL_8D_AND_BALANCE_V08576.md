# 南方軍團技能安全與全軍團平衡：8D 交付

版本：0.85.76。狀態：本機修正與回歸完成，尚未部署。

## D1–D2：範圍與確認問題

範圍是矮人、龍族、埃及島英雄的 Q／W／E／F、選角流程，以及所有可測試軍團的共同平衡基準。確認的 C1 問題是：新英雄或軍團沒有開局展示資料，選角摘要直接讀取未定義的 `identity`，使點擊中止。另有畫面缺口：新英雄 E／F 沒有對應繪圖分支。這不是已知的 Canvas 當機，但不能以「沒有畫面」當作安全驗收。

## D3–D5：修正與設計

- 為三位英雄與兩個軍團建立選角展示資料，並以選角回歸驗證點擊可完成。
- 新英雄 Q、E、F 採用各自的安全特效。特效以逐筆 `try/finally` 繪製；若單筆故障，只丟棄該特效並記錄 `southernVfxFault`，不吞掉其他邏輯錯誤。
- 埃及 E 使用 `egyptSunwatchTime`；不再共用戰牛的 `bullAvatarTime`。龍族／埃及 Q 依其魔法攻擊型別結算；矮人／龍族 F 的號令明確只增幅對應軍團。
- 背景分頁回復時，通用領域只處理一個當前脈衝，不重播所有逾期半秒脈衝，避免單一更新大量建立投射物。
