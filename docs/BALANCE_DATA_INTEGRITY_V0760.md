# v0.76.0 平衡資料可信化

## 目標

避免不同經濟規則的戰績被錯誤比較，並讓功勳與玩家實際策略可以由戰報驗證。本版只改觀測資料，不修改戰鬥、價格、收入、兌換率或波次。

## 版本隔離

新戰績寫入 `appVersion: 0.76.0` 與 `balanceVersion: economy-merit-v2`。歷史比較與九局成熟度只接受相同地圖、難度、英雄、軍團及 `balanceVersion`；舊戰績仍保留最佳分數，但不進入新版平衡樣本。

## 功勳帳本

戰報分開記錄：Boss 取得、補給取得、金幣兌入、兌回金幣、高階升級消耗與期末功勳。`1000G ⇄ 1 功勳` 規則不變，兌入所花金幣另列為兌換支出。

## 實際策略

玩家選擇的是宣告策略；結算再依部署與升級金幣判定實際策略。部署占兩者至少 65% 為擴軍、升級至少 65% 為核心，其餘為混合。九局成熟度依實際策略分組。

## 驗證與還原

執行 `npm run check`、`npm test`。回退時還原 `BattleReportSystem`、`TDGame` 的資源事件接線、版本顯示與快取；localStorage 舊資料無需刪除。
