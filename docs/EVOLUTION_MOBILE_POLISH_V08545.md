# v0.85.45 進化辨識與手機戰場修正

## 交付範圍

本版處理「升級看不出差異」、「英雄像被格子卡住」與「手機畫面過遠」三項可重現問題，不調整道路、部署、士兵承傷或既有關卡平衡。

## 進化

- 七個軍團的每名可建造守軍都有五個不重複的階級名稱。
- 每族至少一座三級建築可選兩條互斥分支。
- 地精升階會增加外露機械零件與尺寸；五階加上旋轉轉子。其發電機的「磁暴發電機」實際增加網路容量，回收器的「黃金拆解線」實際提高回收金額與儲存上限，冷卻器的分支實際改變網路冷卻。
- 霜原的冰晶塔「永凍核心」實際提高冰凍傷害與緩速，並非只改稱號。

## 英雄與手機鏡頭

- 破潮者・賽洛的施法只使用起手、出手、收勢三格；倒地收勢格不再參與循環。待機僅在兩個呼吸姿勢切換，減少三叉戟跳位。
- 娜迦英雄繪製高度提高到 112 世界像素；逐幀跨格邊界保留，尾部和長兵器不以單格裁切。
- 全部正式地圖的手機初始鏡頭至少 1.45 倍、最大放大至少 2.15 倍；新手谷地為 1.6／2.25。這是視覺設定，不會改變可建造區或碰撞。

## 驗收

執行：

```powershell
npm run check
npm test
```

針對本版可再執行：

```powershell
node --test tests/td-map.test.js tests/td-naga-prototype.test.js tests/td-goblin-polish.test.js tests/td-evolution-presentation.test.js
```

手機實機驗收：進入任一正式地圖，確認初始畫面較近；使用鏡頭放大直到上限，檢查英雄、士兵、塔、道路及 HUD 都仍可辨識。選擇地精後將任一守軍升至五級，確認螺栓、能量環、穩定翼、終階轉子與階級名稱依序出現；選擇賽洛後施放技能，確認不會出現倒地姿勢跳格。
