4. 隨後，拒絕交接的回報被送回，雷恩因此收到追捕通知；他要求重新審視交接的封件也遭退回。以先前行動與之後通知的時間銜接表現因果，不用未定罪名補成法律旁白。

**讀者知道：**制度途徑被封死、證人面臨立即風險；雷恩先拒絕交接並護住證人案卷，之後因這個選擇遭追捕。

**尚未知：**不將現場所有執行士兵定義為殺手或同謀。

## 第 33 頁 不是所有人都跟我走

1. 雷恩叫來少數可信部屬，攤開附近道路圖；大部隊仍在遠處正常值勤。
2. 他安排護送、後方掩護與撤離匯合位置。目的地暫標為城外可藏身的中繼處，屬路線提案。
3. 雷恩對一名猶豫者說：「留下照顧這裡。你沒有失職。」
4. 證人攜帶親手核對過的陳述；記錄與證人同行，不把一個神秘箱子當全部真相。

**讀者知道：**誰走、護什麼、往哪裡、誰留守清楚。

**尚未知：**不是全國內戰，也不是整支王國軍叛逃。

## 第 34 頁 讓人先過去

1. 小隊抵達狹窄通道，護送者先帶證人通過；追兵仍在後方，不像無止盡刷出的無名怪物。
2. 雷恩持盾擋住入口，與部屬配合延遲追趕，目標不是殲滅昔日同袍。
3. 證人差點因恐懼停下，護送者拉住他：「把你看見的帶出去。」
4. 雷恩最後撤過通道，回望城市；沒有勝利歡呼。

**讀者知道：**撤離是完成護證責任，並付出失去職位與安穩生活的代價。

**尚未知：**追捕尚未結束，證據也沒立即推翻王室。

## 第 35 頁 從防止戰爭到下令戰爭

1. 老王讀到雷恩被撤權、調查無法照原安排繼續的消息。他把通知放在王子案的未定初判旁。撤權只使他失去等待調查的信心，不是暮影有罪的新證據。
2. 族內代表指著早已出現的疑似術式判讀：「如果他們還能再用一次，我們要等到什麼時候？」希爾芙按住仍標著疑問的頁面：「這還沒有查明。」不新增確證，只讓同一懷疑在恐懼中被放大。
3. 老王看向兒子遺留的日常物品：「我不能再等下一個族人被送回來。」他將尚未證實的暮影威脅當作必須先制止的危險，遂下達攻擊暮影的命令；這是角色的誤判，不是作者認可的正當性。
4. 希爾芙站起：「父王，先動手的人也會改變答案。」命令使者已經轉身。

**讀者知道：**老王把疑似痕跡、悲痛與無結果的等待混成持續受威脅的判斷，最後自行決定開戰；雷恩撤權不是暮影罪證。

**尚未知：**沒有替戰爭判成合理正義；希爾芙也沒有掌握全部無罪證據。

## 第 36 頁 收到命令的人

1. 銀葉部隊整理行裝，部分士兵沉默，部分憤怒；希爾芙隨隊同行，不把她畫成下達攻擊令的人。
2. 隊列抵達暮影生活區外緣。希爾芙走到可見前方街口的位置，抬手要求注意居民與退路：「那邊還有人。」
3. 以她的視線看去，暮影居民仍在搬貨、修理，警報響起後才開始推著傷者與孩子離開。鏡頭保留她在前景的側影，確立這是她親眼所見的街口。
4. 同一視角中，銀葉方的第一輪攻擊越過她前方，擊破通道與屋頂。她立刻朝受阻居民的方向奔去；不把她的制止畫成能控制全軍的命令。

**讀者知道：**銀葉攻擊先發生，暮影尚未重啟黑魔法；希爾芙確實目擊這個街口的第一輪攻擊及居民撤離。

**尚未知：**希爾芙沒有看見所有戰線或維菈的室內決策；不把每名銀葉士兵寫成同樣動機，也不增加未知屠殺命令。

## 第 37 頁 先試過能做的事

**通道受阻與維菈管理疏漏的因果提案，待作者確認。此頁不將兩者直接定為同一事件。**

1. 維菈迅速穿過側路，利用隱匿與精準行動清除妨礙撤離的威脅；不使用禁術。
2. 她指揮將傷者送往另一條路，現場回報那條路目前不適合大量通行。鏡頭先呈現障礙與人群，原因不由旁白定罪。
3. 她立刻改安排，不把困境推給部屬：「走另一側。我去把入口打開。」
4. 下一波攻擊逼近，救出的人比仍困住的人少。她看見一名年輕搬運者回頭尋找同伴。

**讀者知道：**她有戰鬥能力，但治理與撤離不只靠個人武力，現有安排無法保護所有人。

**尚未知：**通道問題的原因待定，不能自動說成第 17 頁漏辦的結果；也不能以管理問題替敵方攻擊開脫。

## 第 38 頁 被封存的不是空白

**資料取得與技術銜接為演出提案，待作者確認：**沿用第 17 頁一般控制技術與舊記法的研究經驗，讓維菈能對照資料；不是戰時首次接觸技術就學全禁術，也不暗示她在戰前已使用亡魂。封存機制不新增設定。

1. 維菈回到第 17 頁已建立空間位置的封存資料區；外面的攻擊聲仍持續。
2. 她依自己整理的目錄找到相關部分，把第 17 頁的一般控制筆記攤在旁邊，逐段比對相通的記法；多處陌生內容仍留問號。她只標出當下可能維持短時防禦的部分，不把整卷變成已掌握的技能表。
3. 她沿著標出的段落核對真正不同的代價：拘束亡魂、消耗亡魂。手停在代價旁；看懂部分控制結構不代表她實施過，更不代表知道全部長期後果。
4. 工作人員問：「這能把他們救回來？」維菈看著代價：「這一式救不了已經死去的人。它會消耗亡魂。」

**讀者知道：**長期的一般技術研究讓她能判讀部分資料；她找到一種當下可能實行的手段，並看見必付代價，不是首次翻書便精通整套禁術。

**尚未知：**不出現長老、預錄全知導師；不宣告她已理解所有長期後果。此處指她正在考慮的防禦手段，不否認世界觀中其他黑魔法可能具有復活能力。

## 第 39 頁 不是沒有代價的選擇

1. 部屬回報最後一條可用退路即將被截斷，傷者尚未撤完。
2. 維菈拿起資料，又看向門外不斷被抬過的人；沒有神祕聲音誘惑她。
3. 她下令先把活人帶離施術區，自己留在原處；不是號召全族一起興奮施法。
4. 她對留下協助的人低聲說：「代價寫在這裡。我不能假裝沒看見。」接著催促：「先把他們帶出去。」

**讀者知道：**維菈主動承擔決定，不是被附身或突然邪惡。

**尚未知：**她只讀到資料列明的亡魂代價，不代表全知遠期影響。

## 第 40 頁 被真正打開的禁忌

1. 維菈照著核對過的部分開始施術，仍需回看記錄，控制並不從容；亡魂受到拘束，而非像自然元素那樣自由回應。
2. 力量形成時，受拘束的亡魂被消耗、消失；不能只畫漂亮紫色能量掩蓋成本。
3. 攻擊被短暫阻隔，撤離通道重新有了時間窗口。
4. 維菈沒有笑。她看向力量來源消失的位置，再催促最後一組傷者離開。

**讀者知道：**暮影現在確實重啟黑魔法，而且發生於受攻擊之後。

**尚未知：**亡魂具體來源與施術細節仍須魔法分鏡核准；不把前代消失原因連上此場。

## 第 41 頁 活下來 不等於贏了

1. 撤離者抵達暫時安全處，有人點人數，反覆數了兩次。
2. 維菈走來，看見空出的擔架與沒人回答的名字。
3. 一名居民想向她道謝，她蹲下協助固定繃帶：「先照顧還在的人。」
4. 遠景是破損街區，不是英雄站在壯麗法陣中央接受歡呼。

**讀者知道：**部分族人活下來，損失與代價同時成立。

**尚未知：**戰爭沒有因此結束，維菈也沒有立刻成為暴君。

## 第 42 頁 至少這份經過還在

1. 雷恩小隊抵達中繼處，先安置證人，再處理傷口。
2. 證人重新核對陳述，指出一處記錄者聽錯的細節；雷恩讓他親自修正。
3. 隨隊原始現場記錄、出入時間與撤權後的限制通知被分開整理，形成可追查的次序。
4. 雷恩圈出的不是凶手名字，而是下一個具體問題：「在我們被請離後，誰能進去？」

**讀者知道：**護證成功、初步事件鏈保存，有明確下一步。

**尚未知：**仍不能由一次權限衝突直接定首相或王室的罪。

## 第 43 頁 希爾芙看見的另一件事

1. 希爾芙沿第 36 頁親眼目擊攻擊的通道走向外圍傷者，看見銀葉與暮影傷者都需要水。
2. 她呼喚水元素協助；元素外觀依遊戲技能，不具王子面孔，不作弟弟亡魂回歸。
3. 一名銀葉士兵指向遠處禁術留下的後果：「他們真的用了。」希爾芙回答：「我親眼看見我們打進這條街。眼前的事，還不能回答弟弟那一晚。」她不宣稱自己看過所有施術過程。
4. 她先記下自己目擊的攻擊與撤離先後，再請人分開收集其他地方的經過、標明來源與待核對時間；決定把眼見帶回去，而非當場發表世界真相。

**讀者知道：**後來的黑魔法使用不能倒推出王子案最初指控成立。

**尚未知：**她尚未接到雷恩全部記錄，也不知道維菈如何解禁；目擊這條街不等於掌握所有戰線。自然元素不是亡魂。

## 第 44 頁 三個人還不能放下的事

1. 雷恩為下一次安全查證安排人手，留下證人受保護與記錄仍完整的畫面。
2. 希爾芙握著親眼觀察的記錄，站在通往父親處的道路前；任務是阻止錯誤繼續擴大。
3. 維菈將禁術記錄重新合上，旁邊是待安置族人與傷亡名單；她必須管理後果，不能退回只做研究的人。
4. 共同城市曾經暢通的貨運路口，如今一道門關閉、另一側仍有人修路。收尾短句：「還有人活著，還有事情能查。和平卻已不是原來的樣子。」

**讀者知道：**本階段有三項成果：證人與記錄保住、先攻後解禁的時序被見證、部分暮影族人成功撤離。

**尚未知：**真兇完整命令鏈、禁術遠期後果、前代缺失、南方歷史均未揭曉；不硬切西行或把所有異常歸成同一原因。

## 與既有關卡文字的小修邊界

以下為 StoryCatalog 的確定文字校正建議，不改關卡數值、不視為新版劇本已接入：

1. 燼道與石環 storyBeatPlans.lines 中的「蘭恩」改為「雷恩」，兩處皆為 hunter 的人名錯字。
2. 烽火初燃目標「守住谷地城門，完成 5 波王國叛軍的新兵演練。」可改「守住谷地城門，抵擋 5 波來襲敵軍。」，去除實戰與演習混淆，不藉此定稿敵人政治身分。
3. 最後一波提示「最後一波綜合演練」改為「最後一波混編攻勢」。教學介面可以教玩法，但劇情內的攻城不是演習。
4. 裂谷收尾不要以團長第一次發現另一套軍隊存在為突破。保守修文可用「殘存的調度紀錄尚不完整，雷恩仍須核對命令來源與當日行動。」對應 outcome 可用「紀錄被保存下來；下一步是核對命令來源，不能僅憑片段定罪。」不提前定稿具體矛盾，也不由此強接西行。

其餘「叛軍」身分、第一章與西行順序等牽涉整段故事重整，不包裝成小修順手定案。本檔只保存劇本與校正建議；實際程式變更及驗收由主線整合記錄另行確認。
