# 娜迦選角與第二章自由遠征交付 v0.85.43

## 玩家可見結果

- 自由遠征可直接選擇第二章 2-1「西境舊哨」與 2-2「燼火商道」。荒風隘道與燼火煙障的規則維持原樣。
- 劇情模式仍依序要求 2-1 → 2-2；自由地圖資格不會寫入 `completed`，也不表示完成故事。
- 破潮者・賽洛與娜迦潮衛各使用一張獨立的選角立繪；這是基礎外觀，不占用商城的英雄／軍團造型槽位。
- 破潮者的初始武器與三次商店鍛造仍使用既有 `spear` 流程：破潮三叉戟 → 珊瑚潮鋼戟 → 深淵潮印戟 → 萬潮王戟。升級後戰場會繪出發光三叉戟、深淵潮環與傳說粒子，不另設貨幣或平行商店。

## 實作與資料邊界

`ProfileStore` 對新存檔預設加入 `westernsignal`、`emberroad`，並對既有 profile／archive 做一次可重複的補齊遷移。地圖 `visible` 改為公開，開局畫面在現有可橫向滑動的地圖列動態插入兩張戰場卡並同步補入選擇下拉選單。

故事任務的 `requires` 與 `rewards.maps` 沒有改動，因此劇情章節不會被跳關。地圖壓力在波次開始時照原本設定啟動：2-1 第 2 波的順風，以及 2-2 第 3 波的煙障。

## 美術、離線與商城

新增 `assets/td/naga/tidebreaker-selection-v1.png` 與 `assets/td/naga/faction-selection-v1.png`，皆為 1536×1024 選角立繪。兩檔案已加入 Service Worker 預快取，快取名稱為 `sky-strike-v0.85.43`。角色戰場 4×4 動作圖與這兩張選角立繪分工，不再把動作圖集當成選單背景。

商城仍可在未來覆寫 `selectionArt` 槽位；本版基礎立繪不會鎖住或覆蓋任何已購造型。

## 驗收與回復

執行 `npm run check` 與 `npm test`。驗收時以一般玩家檔打開自由遠征，確認兩張第二章卡都可選、選娜迦英雄／軍團有圖、開始遠征後可開啟商店連續購買三次三叉戟升級。確認劇情頁仍顯示 2-1 → 2-2 的順序。

回復時必須把本版程式、兩張 PNG 與 `sw.js` 一起回復；只回復 `ProfileStore.js` 會使舊快取或選角資產不一致。玩家存檔不需手動修改，已遷移的地圖資格保留。
