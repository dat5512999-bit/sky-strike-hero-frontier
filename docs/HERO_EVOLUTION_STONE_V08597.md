# 英雄進化石：BOSS 挑戰與 Lv.0 重生

2026-10-12 · 遊戲 v0.85.97 · 本機修改，未提交、推送或部署。

## 需求與原先落差

玩家買完進化石後看不出變化。檢查發現原本只增加 stones，還要展開「英雄資訊」找另一個試煉按鈕；勝利固定回 Lv.1，外觀主要是徽記及光圈。本次保留既有試煉戰鬥、四技能轉職、裝備與章節存檔架構，修正取得流程、零級成長與辨識度，沒有新增英雄或軍團。

## 玩家操作

1. 自由遠征第 20 波守成後，用 3 枚首領勳章購買覺醒進化石；第 50 波守成後可用 5 枚購買超凡石。不是外觀商城的鑽石商品，價格與波次門檻不變。
2. 安全整備時購買會關閉商店，在英雄附近召出「覺醒／超凡試煉守衛」，鏡頭移到挑戰位置。波次還在進行則等清場；英雄倒下則等復活。手動暫停購買後仍維持原先暫停，按繼續才會開始戰鬥。
3. 試煉期間停止下一波倒數、禁止手動開波；只有英雄及其召喚可傷害守衛。塔及軍團不能代打，BOSS 不漏進城門、無一般掉落。
4. 打贏才消耗石頭並進化：等級 0、XP 0，生命補滿、技能冷卻清除，裝備與軍團保留；左／中上方提示顯示等級、攻擊、生命前後比較。Lv.0 到 Lv.1 需要 40 XP。
5. 失敗保留石頭，不自動無限重打。復活後從畫面提示、戰鬥商店或英雄資訊按免費挑戰。舊存檔已持有的石頭也可免費挑戰，不必重新買。

## 成長數值與外觀

- 初始英雄仍從 Lv.1 起，原本升級曲線不變。
- 覺醒／超凡的等級步數從 0 起算。基础攻擊倍率沿用 2.08／3.72，並繼承進化前等級戰力的 112% 作為下限；每級再成長 8%。此倍率不重複計入武器加成。
- 基礎攻速間隔乘 .92／.84，再套用每級 .985；繼承原本更快的攻速下限。
- 生命為基礎生命的 1.6／2.3 倍，加每級 12／16，且不低於進化前的生命上限。因此不是單純歸零變弱，同等級的進化英雄更強。
- 十一名英雄皆增加兩階持續可見的披甲、披風、冰稜、機械背架、背鰭或翼甲輪廓；使用 Canvas 原生分層與材質漸層，放在原角色圖前後。不是全新重畫的角色動作圖集，不替換已購造型、角色臉部或三階武器；原有徽記與施法效果保留。

數值與角色辨識已做功能驗收，但長時間配兵平衡與玩家美術偏好仍需試玩確認，不宣稱已完成所有難度的平衡驗證。

## 架構、資料與 API

```text
戰鬥商店點擊 → ShopSystem.buy
  → HeroEvolutionSystem.purchase
    → 扣勳章／持有石頭／autoTrial
    → 安全章節存檔（先保存，再召喚）
    → processPending → startTrial → 專屬 BOSS
       ├─ 英雄倒下 → cancelTrial → 石頭保留／免費重試
       └─ BOSS 真正死亡 → completeTrial → rank + 1／Lv.0／XP 0
          → 能力成長與四技能 → 安全存檔
HeroEvolutionFlow → 顯示待召喚／挑戰血量／重試／勝利比較
Hero.draw → 背面披甲 → 原有角色／造型 → 前面護甲 → 武器／徽記
```

主要檔案：`HeroEvolutionSystem.js` 管理支付、排程與結果；`HeroEvolutionFlow.js` 僅管理 DOM 與購買後關閉商店；`HeroEvolutionPresentation.js` 畫附加外觀；`Hero.js` 套用生命成長與前後層；`WaveHUD.js` 顯示待召喚狀態；`ChapterCheckpointSystem.js` 保持 schema 1。

新增／擴充的內部 API：`purchase(game,economy)`、`processPending(game)`、`holdTrial(game)`、`healthAtLevel(hero)`、`growthLevel(hero)`、`HeroEvolutionFlow.attach/update`、`drawRegalia(ctx,hero,front)`。既有 startTrial／completeTrial／cancelTrial 仍可使用。沒有 HTTP API、資料庫、帳號權限或外部服務變更。

沿用 hero.evolution，增加可選 `autoTrial` 與 `lastResult:{rank,before,after}`。老存檔缺少新欄位仍可讀；沒有重設既有玩家等級。過關存檔可保存 Lv.0，讀取不會用 `level || 1` 誤改為一級。中斷尚未完成的試煉會回到安全章節快照，已在該快照支付的石頭仍在；尚未到安全存檔點的整波进度仍依原本章節存檔規則，不是即時雲端存檔。

## 常見問題

- 買完沒有立刻進化：正確，必須打贏召出的 BOSS。挑戰提示會列出目前狀態。
- 戰鬥中买石沒出 BOSS：等本波清場；倒下的英雄則先等復活，不會額外扣款。
- 持有舊石但按鈕不能按：先清場、復活並解除暫停；英雄資訊或商店都能免費重試。
- 變零級是否丟失武器：不會，裝備保留；歸零的是英雄等級與 XP，進化後基礎能力更高。
- 為何已購造型還在：刻意保留，進化護甲層會疊在造型前後，不會把付費造型撤下。
- 線上仍舊流程：本次尚未發布；部署新版後再確認版本號與快取更新，不要清除網站存檔。
