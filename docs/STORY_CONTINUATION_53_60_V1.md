## 劇情推進

雷恩收到分開封存的案發夜與戰地陳述，將調查縮小到公共登記的交接缺項。共同城市代表同意保留原冊、核對後提供相關副本；王國提出統整援助登記的要求，遭市方拒絕，並不因此停止糧食協助。希爾芙與維菈首次在本故事中正面交談，兩人仍有怨憤，只同意協助眼前的傷者。

不把女吏的陳述與她經手的簿冊算作兩位獨立證人，不把空白欄位直接判定為滅證。首相與親衛的核心真相、亡魂代價、暮影前代缺失及南方歷史都不在本批揭露或改寫。

## 製作與審稿

採內建 imagegen，一頁一張 1536×1024 彩色四格，角色以遊戲原版 selectionArt 和前頁配角為參考。所有最終提示詞、參考圖、台詞與圖稿來源記於 `assets/td/concepts/story-comic-v2/continuation/production-v2.json`；原 `production-v1.json` 保留。

因果審稿先修正五項問題：停止登記的先後仍待核對；副本交付需市方同意；王國使者不知受保護調查；救援人員留守範圍清楚；簿冊空白不等於沒有交接。這是 AI 交叉檢查，不是人類專家背書或作者批准。

第 55 頁首稿誤添現實式日期與人名、並將送件人服裝混成王國使者，修成 v2。第 54 頁首氣泡錯字改為「先後與時間，都還要核對。」採 v3；第 60 頁副本誤添原冊未載項目，修成 v2 與第 55 頁逐欄一致。其他五頁採 v1，所有前稿保留供回復。

最終八頁已完成獨立 AI 視覺複核，未發現阻斷問題。三位英雄對照原立繪，送件人與證人雖同為短捲髮，鬍子、面型及服装可辨；女吏、頭巾救援者與王國使者各自一致。第 55／60 頁欄位相同，主對白與关键文書未見明確錯字，沒有不合理出現的已故王子。這仍是待作者閱讀驗收的本機稿。

## 操作與工程界線

沿用 `continuation/review.html`，以 `#page=53` 開啟本批。目錄依新版製作清單顯示 45–60 頁，固定操作列、放大拖看與故事文字保留，不寫入 localStorage 或 sessionStorage。舊的 `#page=45` 至 `#page=52` 連結仍有效。原正式 44 頁閱讀器完全不變。

原圖採版本檔名，WebP 只供本機審閱；build:site 繼續排除 concepts。沒有新增資料庫、後端 API、英雄或軍團。將來接入須先配置對應故事節點與配樂，不能直接把全部頁面混成正式全本連播。

共用驗證器 review-catalog.js 同時供 Node 轉圖腳本和瀏覽器使用，支援原八頁與新十六頁兩個明確版本，拒絕缺頁、跳頁、遠端圖片、不合法來源與錯誤發布狀態。當前 prepare 預設讀 v2；v1 作歷史快照，不隨新頁數修改。

## 重建及驗收

一般閱讀不需安裝新套件；Node 18+、sharp、playwright 與 Edge 沿用既有工具環境。若使用外部套件目錄，以環境的 NODE_PATH 提供，不提交機器專屬路徑。

```powershell
node scripts/prepare-story-continuation.cjs
node --test tests/td-story-continuation.test.js
npm test
npm run check:site
$env:TD_TEST_PORT='4189'
npm run serve:test
```

若 4189 已是本專案伺服器，直接沿用。另一終端執行 `node scripts/qa-story-continuation.cjs`；可用 STORY_CONTINUATION_QA_URL 指定其他 HTTP 入口。報告與截圖輸出到忽略版控的 artifacts/story-continuation。不要以直接雙擊 HTML 取代 HTTP 讀取；若目錄／圖像失敗，使用頁面的重試，不刪遊戲資料。
