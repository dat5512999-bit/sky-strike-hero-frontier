讀者須能辨認遊戲英雄、知道關鍵人物是誰，並在不同角度／表情下認出同一個人。不能把換髮色、換衣服當作唯一辨識方式。先核對既有設定，再設計外觀與介紹，最後用實際分鏡驗證。

## 可延續的角色資料

[製作對照表](../assets/td/concepts/story-comic-v1/cast-registry-v1.json) 保存角色鍵、已知身分、不可擅自合併的 Hero ID、圖檔／所在列、臉部辨識點、公開介紹與核准狀態。此 JSON 是製作資料，不由遊戲匯入。

角色參考優先序：原版英雄立繪 → 已核准人物設定板 → 分鏡用角色參考。配角或尚待核准草稿不能倒過來改寫主英雄。六個候選人的四視圖核對涵蓋眉眼、鼻形、顴骨、下顎、髮際線與鬍鬚；衣服換掉後仍應有不同輪廓。

## 首次登場規範

1. 重要角色首次清楚露面，要有足夠大的臉部畫格；不能只以背影、手、遠景或頭盔代替長期介紹。
2. 在同頁安排「姓名／稱謂＋當時公開身分」。雷恩用「守誓者・雷恩／王國英雄」，首相用「首相／人類王國・政務重臣」。不能加尚未確認的軍階或秘密。
3. 介紹框不得遮擋五官、動作和重要道具；文字與背景有足夠對比。
4. 介紹之後至少用一個行動或反應呈現性格，不讓整頁只是履歷卡。首相靠說法轉換、觀察和停頓呈現算計，不靠變成另一張邪惡臉。
5. 後續頁一般不重複大介紹框；長時間未出場、易混淆或改變公開身分時，用短提示輔助。
6. 每頁產圖提供當頁角色參考，不能只有陣營參考。未核准外觀僅可出現在明確標記的概念分鏡，不進正式 cast 或發布內容。
7. 使用者核准後才固定正式臉；若角色需要合併，停用對應候選稿並重檢已畫頁面，不能同一人物維持兩張臉。
