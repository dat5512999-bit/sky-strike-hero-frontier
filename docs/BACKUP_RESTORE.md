# 備份與還原手冊

## 備份

- 版本備份：保留 Git 儲存庫並建立版本標籤。
- 可攜備份：將整個專案資料夾壓縮為 ZIP。
- 沒有玩家帳號、伺服器進度或資料庫需要另外備份。外觀、難度、最高分與最高 Combo 只存在瀏覽器 `localStorage`；清除網站資料後會回到預設值。

## 還原

使用 Git 時可從版本標籤建立新分支或工作目錄：`v0.1.0` 為最小可玩版、`v0.2.0` 為皮膚版、`v0.3.0` 為手機／Pages 基線、`v0.4.0` 為技能果實版、`v0.5.0` 為成長與連擊版、`v0.6.0` 為難度與戰場事件版。不建議直接覆寫尚未提交的檔案。ZIP 備份則解壓至新資料夾，雙擊 `index.html` 驗證。
