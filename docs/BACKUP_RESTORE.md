# 備份與還原手冊

## 備份

- 版本備份：保留 Git 儲存庫並建立版本標籤。
- 可攜備份：將整個專案資料夾壓縮為 ZIP。
- 沒有玩家帳號、伺服器進度或資料庫需要另外備份。外觀、難度、最高分與最高 Combo 只存在瀏覽器 `localStorage`；清除網站資料後會回到預設值。

## 還原

使用 Git 時可從版本標籤建立新分支或工作目錄：`v0.1.0` 為最小可玩版、`v0.3.0` 為手機／Pages 基線、`v0.6.0` 為難度與事件版、`v0.8.0` 為百波遠征與支援小隊版、`v0.9.0` 為符文防線版、`v0.10.0` 為雙模式與英雄塔防首發版。不建議直接覆寫尚未提交的檔案。

塔防的波次、金幣、塔與城門均為單局記憶體狀態，重新整理或關閉頁面後歸零，不需另外備份。未來加入存檔時必須同步擴充此文件與資料遷移流程。
