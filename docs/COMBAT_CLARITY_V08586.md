# v0.85.86 戰鬥清晰度交付

更新：2026-10-07。這一版處理玩家提出的八項操作回饋；只調整提示與一項索敵優先順序，不增加英雄、軍團或付費內容。

## PM／UI 與開發順序

1. 修復「手動選索敵卻被兵種內建菁英優先覆蓋」：手動策略生效；只有預設「最接近城門」保留兵種專長。
2. 修復 Q／W／E／F 冷卻中快捷鍵無回應或錯誤歸因。冷卻顯示剩餘秒數，無目標、未供能等條件保留各自訊息。
3. 選取士兵／塔可看目前目標或不能攻擊原因；目標以細虛線圈標示。升級前顯示現有與下級的攻擊、射程、間隔或支援屬性。
4. 敵人接近出口時在小地圖圈出、在波次列下方提醒；波後短暫顯示零漏怪或主要漏怪種類及下一步建議。
5. 命中分穿刺、魔法、重擊、護盾與免疫短音；免疫不再顯示假「-1」。普通傷害文字有繪製預算，首領預告等重要回饋不被滿額列表直接淘汰。

這些是資訊與手感改善，不是全新戰鬥數值平衡。升級預覽是當前增益下的即時估算，其他單位稍後變動的光環仍可能改變結果。波後建議是提示而非自動最優策略。

## 架構、資料夾、資料與 API

```text
目標／技能／升級／波次／怪物資料
          ↓
src/td/systems/CombatClaritySystem.js（純讀取、文字與威脅判定）
          ↓
TDGame（每 100 ms 介面更新、每 120 ms 城門掃描）
          ├─ 選取資訊與波次提示 DOM
          ├─ Canvas 當前目標細圈
          └─ MiniMapView 城門前威脅圈
BattleReportSystem.recordLeak → 波後漏怪種類
FrostlandAudio + CombatFeedbackSystem → 有界音效／文字
```

沒有資料庫或 HTTP API。`BattleReportSystem.recordLeak(damage, monster?)` 的第二參數為可選；舊呼叫仍有效。`leakTypes` 只屬單波報表資料，舊紀錄沒有此欄時使用安全回退。新增展示模組不寫玩家存檔。`td.html`、`td-combat.css`、`sw.js` 同版載入。

## 玩家操作與可理解的錯誤訊息

- 選取士兵後，在「選取資訊」調整索敵策略；「最接近城門」可保留兵種原生菁英專長，改為最低血等手動策略即以玩家選項為準。
- 選取士兵或塔，展開「選取資訊」可看目前目標、射程外、隱形未揭露、無法對空、免疫、供能不足或暈眩等原因；同處顯示下一級差異。
- 小地圖金色圈與「敵軍接近城門」在最後約 3 秒內提醒；不暫停或強制移動鏡頭。波後提示約 6 秒，可照常開下一波。
- 冷卻中仍按快捷鍵，會告知剩餘秒數；音效由設定中的「戰鬥音效」控制，不支援 Web Audio 或未解鎖播放時安靜略過。

## QA、安全、效能與權限

- 執行 `node --test tests/td-combat-clarity.test.js`、`npm test`、`npm run check`、`npm run check:release`、兩種平衡 audit。驗收手動索敵、五種不能開火原因、下一級預覽不改實體、漏怪類型、技能冷卻、音效節流與離線殼。
- 桌面與手機橫向目視確認提醒不遮住資源／波次、選取卡不裁字、小地圖標記落在真正威脅上。用相同地圖、怪數與倍率比較更新及繪圖 P95；自動測試不能替代自然 50 波與玩家真機長局。
- 只處理本機 Canvas 與 DOM，沒有遠端傳送、登入或新權限；無新執行依賴。通知文字使用 `textContent`，不把敵人或外部資料插入 HTML。
- 城門掃描每 120 ms，選取診斷沿既有 10 Hz UI 更新；只標一個最近威脅，額外 Canvas 只有細圈。音效沿用最多 6 聲部與同類最短 180 ms，普通傷害文字繪製上限桌面 20／手機 12。
- 本機實際結果：6 項定向測試、全套 1012／1012、`npm run check`、`npm run check:release`、兩種平衡 audit 及 `git diff --check` 通過。隔離瀏覽器於新手谷地看見城門預警，遠征失敗結算時警告消失，Console error 為零；未宣稱手機真機或完整 50 波前景測試已完成。

## 安裝、部署、備份及還原

Node.js ≥18，在專案執行 `npm run serve:test` 後開啟 `http://127.0.0.1:4173/td.html`。不需安裝新套件或設定 API key。部署須同時發布新模組、HTML、CSS、音效、報表與 `sw.js` 版號；檢查入口為 0.85.86。部署前可由遊戲設定匯出玩家 JSON，保留上一完整 Git 提交。回退時還原整個 v0.85.85 提交及 Worker 快取鍵，不清除玩家存檔；新報表的可選 `leakTypes` 在舊版可忽略。

## 已知限制與交接

此版不新增塔的手動索敵模式；塔仍按原配置自動鎖定。免疫攻擊的傷害結算規則未改，現在只是正確顯示「免疫」。無法僅憑合成測試保證所有手機尺寸與長局 FPS；前景設備至少 10 分鐘、自然波次及大批量音效仍應實測。若提示過度頻繁，先看 `CombatClaritySystem.gateThreat`、`TDGame.refreshClarityUi` 與 `FrostlandAudio.playImpact` 的節流，不應關掉實際戰鬥判定。
