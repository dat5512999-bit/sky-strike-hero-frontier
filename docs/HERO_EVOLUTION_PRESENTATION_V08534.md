# 英雄進化呈現與發行驗收 v0.85.34

本次補丁把進化從單純數值／文字狀態提升為可辨識的戰場呈現，且不覆蓋玩家已購買的商城造型。

## 玩家可見結果

- 覺醒與超凡各有一張六格透明徽記圖集；雷恩、希爾芙、維菈、戈爾、奇克、凜皆會在戰場角色頭上方顯示對應職業徽記。
- 超凡徽記擁有更大的尺寸、金色外環與節奏性光暈；覺醒維持較克制的徽記光效。
- 角色本體、商城造型、武器三階升級與既有攻擊動作不被替換，避免進化破壞外觀商品價值。
- 徽記圖集為本機透明 PNG，納入 Service Worker 資產表；圖檔未就緒時安全退回既有文字星徽，不會中斷戰鬥。

## 技術責任

`HeroEvolutionPresentation` 只處理視覺層；進化門檻、石頭、首領勳章、試煉、存檔與技能規則仍由 `HeroEvolutionSystem` 管理。`Hero.draw()` 先繪製商城／角色本體與武器，再附加進化光環與徽記，因此二者可共存。

## 發行驗收

- `tests/td-evolution-presentation.test.js` 驗證兩張圖集的透明、六格裁切、離線快取、六英雄的正確對應，以及所有版本顯示來源一致。
- `tests/td-hero-evolution.test.js` 驗證六英雄兩階技能、英雄專屬試煉、勳章和生命下限。
- `npm test` 為完整回歸；`npm run check:evolution` 做進化模組語法檢查。

## 仍不可宣稱完成的範圍

目前自由遠征正式資料仍為 30 波。因此 Wave 50 的超凡規則與視覺可被資料及測試驗證，但不會在玩家正式流程中解鎖；31–50 波內容、長局數值模擬與真機效能量測完成前，不應把「超凡已可遊玩」寫入商店或版本公告。霜原與地精目前仍依既有設定顯示為測試／概念內容，是否作為正式上市內容需要世界觀與內容核准，不能由技術補丁自行升格。
