# 版本更新手冊

## 一般玩家更新

1. 備份目前整個遊戲資料夾。
2. 取得新版 ZIP，解壓到「新的資料夾」，不要直接覆蓋舊版。
3. 查看 `CHANGELOG.md` 確認版本與變更。
4. 雙擊新版 `index.html` 完成煙霧測試。
5. 確認可玩後再刪除舊資料夾。Phase 1 沒有玩家進度需要移轉；外觀偏好由瀏覽器保存。

## Git 維護者更新

先確認工作區沒有未提交的重要修改，再取得新版提交並執行 `npm run check`、`npm test`。需要回復手機基線時使用 `v0.3.0`，需要保留果實但移除成長／Combo 時使用 `v0.4.0`；避免用破壞未提交內容的強制重設命令。GitHub Pages 更新後 Service Worker 會優先抓取網路新版，短暫離線時才回退快取。
