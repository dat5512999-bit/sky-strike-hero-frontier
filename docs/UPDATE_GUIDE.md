# 版本更新手冊

## 一般玩家更新

1. 備份目前整個遊戲資料夾。
2. 取得新版 ZIP，解壓到「新的資料夾」，不要直接覆蓋舊版。
3. 查看 `CHANGELOG.md` 確認版本與變更。
4. 雙擊新版 `index.html` 完成煙霧測試。
5. 確認可玩後再刪除舊資料夾。沒有伺服器進度需要移轉；外觀、難度與最高紀錄由瀏覽器保存。

## Git 維護者更新

先確認工作區沒有未提交的重要修改，再取得新版提交並執行 `npm run check`、`npm test`。需要回復手機基線時使用 `v0.3.0`，保留百波但移除防線／詞綴時使用 `v0.8.0`，保留射擊版但移除英雄塔防時使用 `v0.9.0`，保留塔防玩法但回到原型美術時使用 `v0.10.0`，回到固定塔座美術版時使用 `v0.11.0`；避免用破壞未提交內容的強制重設命令。
