# v0.85.6 遊戲速度調整

2026-09-23。HERO FRONTIER 的原 X1 體感偏慢，原 X2 較接近一般戰鬥節奏。本版將原 X2 的模擬節奏設為新 X1，三個按鈕仍表示相對於新基準的 X1／X2／X3。出怪、移動、攻擊、冷卻、特效、倒數與戰報用時隨遊戲模擬時間同步推進；暫停仍不推進。

## 操作與常見問題

進入 `td.html`，選擇英雄和軍團後，使用戰鬥畫面上方的 ×1／×2／×3 切換速度。新 X1 約等於舊 X2；X2、X3 分別為新 X1 的兩倍、三倍。若更新後仍覺得 X1 與舊版相同，重新載入頁面，必要時關閉舊分頁再開啟，讓 Service Worker 換成 `sky-strike-v0.85.6`。倍速不改變怪物與友軍的設定數值；現實時間會縮短。低效能裝置可能無法達到標示倍率。

## 架構、設定與 API

`td.html` 的速度按鈕 → `TDGame.setGameSpeed(1|2|3)` → `TDGame.loop(timestamp)` → `TDGame.update(dt)`。`gameSpeed` 仍只接受 1、2、3，預設與重開局仍為 1。`loop` 先限制真實影格時間至 33 毫秒，再乘遊戲速度和新的基準 2；更新分為每步最多 33 毫秒，畫面每影格只繪製一次。沒有新增資料庫、HTTP API、環境變數、存檔欄位或 UI 控制項。日後調整基準需檢查碰撞、波次、冷卻、戰報用時與高速裝置效能。

## 安裝、部署、更新與回復

首次安裝沿用 `README.md` 和 `docs/INSTALLATION.md`：安裝 Node.js 18 以上，在專案根目錄執行 `npm run serve:test`，開啟 `http://127.0.0.1:4173/td.html`；無額外設定。更新需一起部署 `src/td/TDGame.js`、`td.html`、`src/td/app/FrontierApp.js`、`src/td/systems/BattleReportSystem.js`、`package.json`、`sw.js` 與本文件，避免畫面版本和快取內容不一致。部署後重新載入並檢查 ×1／×2／×3 與暫停。

回復上一版時，從保留的 v0.85.5 完整靜態檔案備份還原上述檔案；`TDGame.loop` 的基準乘數由 2 恢復為 1，並將 `package.json`、介面版本、戰報版本和 Service Worker 快取名同步恢復 0.85.5。重新載入後確認舊版 X1 節奏。先備份玩家資料；此版不修改存檔格式，無資料遷移。
