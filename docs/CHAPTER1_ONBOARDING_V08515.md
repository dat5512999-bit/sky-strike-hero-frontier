# v0.85.15 第一章引導可操作性修正

## 交付結果

第一章第一關《烽火初燃》現在是五波的完整入門演練，而不是三名敵人的短測試。流程依序為：讀路線、部署獵手、手動開戰、查看單位性能、認識商城、領取第三波軍械箱並替獵手裝備。第 4、5 波保留為讓玩家實際套用所學的練習。

## 操作設計

- 部署只畫出一個綠圈：世界座標 `(710, 430)`。此格通過 `BuildSystem` 合法部署驗證，離敵軍道路約 84 格，小於王國獵手 150 射程；不再顯示不能攻擊道路的誤導圈。
- 要操作的按鈕會高亮於半透明黑色聚焦層上方；建造欄步驟會把整個欄位抬到遮罩上，並將非目標卡壓暗，教學卡會依按鈕位置放在旁邊（空間不足時放到按鈕另一側）。
- 第一波開始前與每個教學節點都會暫停準備倒數。第一次擊殺後，觀察卡自動收起，避免遮住實際戰鬥。
- 「跳過引導」和完成引導會直接移除教學卡、遮罩、焦點樣式與波次暫停，不會留下卡片；重新播放使用 v2 進度鍵，因此曾遇到舊版卡住流程的玩家也會取得新流程。

## 架構與 API

資料流為：`StoryCatalog` 提供關卡／波次／唯一座標 → `TutorialSystem` 管理 UI、狀態與暫停 → `TutorialIntegration` 將遊戲事件接入。波次完成改接在 `WaveSystem.acknowledgeReward()`，這是戰鬥主迴圈已確認結算的唯一時點，不再以畫面更新輪詢猜測波次結束。

無新增 HTTP API、資料庫、權限或存檔 schema。完成旗標仍在既有 story profile local storage；新鍵為 `chapter1-border-onboarding-v2`。若需在測試中再看流程，任務頁的「重玩新手引導」會強制重播。

## 安裝、部署、回復與備份

安裝方式不變。部署時需一起發布 `td.html`、`td-tutorial.css`、`TutorialSystem.js`、`TutorialIntegration.js`、`StoryCatalog.js`、`BattleReportSystem.js`、`FrontierApp.js`、`update.html` 與 `sw.js`。版本為 `0.85.15`，離線快取為 `sky-strike-v0.85.15`；更新後重新開啟遊戲頁，讓新版 Service Worker 生效。

要回復程式，回復上述檔案與 Service Worker 版本即可；玩家既有 story profile 可保留。舊 v1 教學鍵不會阻止 v2 新流程，若必須清掉本版進度，只移除目前瀏覽器的 `chapter1-border-onboarding-v2` 鍵，不影響角色、裝備或其他關卡。

## QA 驗收清單

1. 進入 1-1，確認只看到一個綠圈，並可在該格放置王國獵手。
2. 確認圈內獵手會攻擊道路上的第一波敵人；第一波為分段到達的三名長戟衛。
3. 每個按鈕（獵手、開戰、選取、商城、裝備）都在黑色聚焦層上方，教學卡位在目標旁。
4. 依序通過第一、二、三波；第三波後選取軍械箱的獅心王弓，並可開啟獵手裝備面板。
5. 在任一步按「跳過引導」，確認 `#td-tutorial` 與 `#td-tutorial-dim` 立刻從 DOM 移除、倒數恢復。
6. 執行 `npm run check`、`npm test`，並以瀏覽器從 1-1 實測一次跳過與重播。
