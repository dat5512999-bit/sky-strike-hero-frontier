# 五十波與新怪物擴編 V1

此版本保留第 1–30 波原編成，新增第 31–50 波；每五波維持 Boss 節點。第 50 波使用濁潮小魔王作為插篇預覽終局，仍標示為 `CONCEPT`，不代表娜迦已完成正式劇情解鎖。

## 新敵軍

| 種族 | 輕型 | 職能／遠攻 | 重型 |
| --- | --- | --- | --- |
| 地精 | 蒸汽拾荒地精 | 爆罐地精工兵 | 以群體高速與遠攻壓力取代純重甲 |
| 獸人 | 裂牙戰旗獸人 | 戰旗推進／支援輪廓 | 巖鎧碎顱獸人 |
| 霜原 | 霜痕掠行者 | 霜骨祭司 | 與既有重甲及娜迦鹽甲混編 |
| 娜迦 | 淤泥小妖 | 濁潮小魔王 | 鹽甲破殼者 |

新怪物均有獨立透明 4×4 動作圖集，並由同一資料流載入：`WaveCatalog → Monster.TYPES → ArtSystem.enemyActions`。沒有建立第二套生成、掉落或戰鬥系統。

## 平衡與驗收

- v0.85.53 已將第 31–50 波改成連續後段壓力曲線，細節、目標與回歸門檻以 [五十波平衡交付](FIFTY_WAVE_BALANCE_V08553.md) 為準。
- 每五波含首領；第 50 波總耐久維持不低於第 49 波，且濁潮小魔王二階只召四族終局援軍。
- 修改波表時必須同步更新 `config.totalWaves`、Wave HUD、完整 50 波測試、長局探針與離線快取。
- 這批怪物只會在自由遠征第 31–50 波出現；既有故事關卡不會被改寫。
