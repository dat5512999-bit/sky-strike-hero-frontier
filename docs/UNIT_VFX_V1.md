# 士兵材質特效 VFX 1.0.0（未部署）

> 最新：Unit VFX 1.1.0 修正出手／衝鋒同步、命中預算與 Canvas 狀態還原；混戰測試、效能、API、部署回復及未完成的真機驗收見[戰鬥特效 QA](VFX_BATTLE_QA_V11.md)。尚未部署。

## 需求與範圍

依玩家確認，接續塔楼 VFX 2.0 的質感方向，調整現有士兵攻擊，不新增兵種或修改戰鬥平衡。涵蓋配置內 43 種攻擊兵（含敵軍限定配置）及 2 種純支援兵。英雄、召喚物與敵方 Monster 獨立戰鬥管線不在本次範圍；不代表全遊戲所有單位都已更新。

順序：近戰與終極兵攻擊身分 → 各族遠程命中 → 支援回饋 → 品質及效能保護。

## 操作與畫面

透過專案既有本機伺服器開啟 `unit-vfx-preview.html`，可篩選近戰／終極兵、遠程、純支援，暫停、重播、減少特效。預覽使用正式 UnitVFX，但靶標與時序為展示，不讀寫存檔；實戰從 `td.html` 進入。

- 近戰以斬痕、突刺、盾擊和震地表現，不再顯示飛行光球，保留原傷害到達時間。
- 終極兵：翡翠古龍用連續錐形吐息；皇家統領重击加金屬碎屑；魂鋼疊魂霧、霜原疊冰晶、娜迦潮水。
- 遠程區分箭、槍彈、砲彈、雷電、毒液、自然、魂霧與潮刃；穿透箭不再畫成折線閃電。所有受擊點立即顯示接觸層，連鎖移動層僅為裝飾。
- 支援依既有實際增益來源、技師支援對象與霜寒效率顯示；沒有受益者就不亮。
- 普通命中素材基準上限 90、終極 118 世界單位，隨動畫展開略放大；命中 0.32 秒後清除。刻意小於英雄大招。
- 減少特效保留彈道與命中核心，移除尾跡和餘波；共用每幀裝飾預算，連鎖逐點扣除。素材失敗降級回舊畫面並可重試。

## 架構、API、資料與權限

```text
CombatUnit.attack → 既有霜原／地精出手佇列（如適用）
                 → Projectile（unitVfx 只選畫面，不改 style）
                 → UnitVFX → 共用素材繪製工具／三張圖集
CombatUnit.draw  → UnitVFX.support → 讀實際支援來源
ArtSystem        → 預載／就緒檢查／失敗重試
```

新增 `src/td/systems/UnitVFX.js`：`key(owner)`、`ready(owner,key)`、`projectile(ctx,p)`、`support(ctx,unit)`、`texture(art)`。沒有新增 HTTP API、資料庫、帳號權限、存檔欄位或外部執行期依賴。傷害、style、傷害類型、射程、攻速、升級、武器觸發及擊殺流程不變。

傷害結算後僅繪製、不重算傷害；接觸點採結算座標，不跟著屍體位移。抑制已接管的舊霜原普通攻擊裝飾與通用爆炸，技能／碎冰狀態特效保留。

## 安裝、部署、更新與還原

沿用主專案 Node 18+ 與本機伺服器，無額外設定、金鑰需求。交付必須包含入口、UnitVFX、共用素材模組、Projectile／CombatUnit／FrostlandVFX／BattleSynergySystem、三張 PNG、預覽及 sw.js，依既有流程統一主版本與快取，勿只複製 PNG。

模組自帶版本 1.0.0；主版本由工作區發行流程管理。本次未部署或建立 Git 提交。部署前保留上一版完整發行包及玩家匯出備份；回復用新的回退版本號還原整包，不需資料遷移，不能覆蓋其他任務未提交修改。

## FAQ 與管理

- 還看到舊光球？檢查模組及三張圖載入狀態，再用既有更新修復入口；不要清除存檔。
- 為何士兵效果比英雄小？同樣追求材質品質，但短時、小面積才能看清大量混戰。
- 支援兵為何不亮？查實際受益者、供電／冷卻和技能窗口；待機不冒充生效。
