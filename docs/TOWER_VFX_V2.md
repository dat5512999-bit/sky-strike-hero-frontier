# 塔樓材質特效 VFX 2.0.0

玩家回饋指出 VFX 1.0 的幾何圖形缺乏霜原英雄技能的美術質感。本版採 `FrostlandSpellArt` 的透明繪製素材與分層動畫方法，保留 V1 作為素材未就緒的降級呈現。

## 視覺交付

- 七族共 38 座塔（27 座攻擊塔、11 座支援塔）及通用爆破工坊接上材質渲染入口。
- `assets/td/tower-effects-painted-v2.png`：16 格透明圖集，包含金屬、冰晶、根種、幽魂、魂鐮、岩塊、蒸汽、火箭、碎片、爆焰、絞索與潮水。
- `assets/td/tower-magic-effects-v2.png`：4 格透明圖集，雷電與瘟疫各有專屬彈道和命中，避免雷槍誤用冰晶、瘟疫誤用木根。
- 命中拆成快速接觸閃光、材質核心噴散、低位霧氣／碎片消退；沿用原命中 0.32 秒生命週期，普通攻擊尺寸上限控制在 155 世界單位。
- 支援塔依實際工作顯示材質光霧與受益光點，待機不畫強光符號。低特效模式保留攻擊主體並略去餘波，裝飾预算沿用現有手機／桌面限制。
- 素材由內建 imagegen 生成，以霜原英雄圖集為風格參考；兩張都經過留白修正並保留原始 alpha。完整提示詞見 `TOWER_VFX_V2_PROMPTS.md`。

## 檢視與驗證

開啟 `tower-vfx-preview.html` 可查看七族基礎與代表性進階特效、暫停及重播。預覽使用相同生產渲染器及兩張正式圖集；展示靶標與事件不會寫入玩家存檔。

![原生 Canvas 分時點對照，底列為霜原英雄參考](../artifacts/tower-vfx-v2/native-contact-sheet.png)

此圖由 `scripts/render-tower-vfx.cjs` 直接呼叫遊戲的渲染器產出，為離線材質／時序驗證，不是瀏覽器內實戰截圖。需要可用的 `@napi-rs/canvas`，本次使用 Codex 既有依賴套件；遊戲本身沒有新增 Node 或網路依賴。

`npm run test:tower-vfx` 包含各族及升級分支的素材裁切、透明留白、真實 drawImage 路徑、命中期限、預算／低特效、Canvas 例外還原、資產載入失敗重試與戰鬥資料不變檢查。`npm run check:tower-vfx` 檢查兩個渲染模組與預覽腳本語法。

全量測試在此工作區曾得到 786 項、781 通過、5 項地圖發佈／燼道位置失敗；兩項燼道位置失敗在停用本版渲染器後仍可重現。這份結果是檢查當時的工作區狀態，其他任務正同時修改地圖。逐塔瀏覽器實戰目視與手機幀率仍未驗收。

## 安裝、API、發佈與回復

主程式仍沿用工作區發行版本；本次模組版本為 2.0.0，尚未部署。

`TowerSkillSystem → TowerVFX → PaintedTowerVFX → ArtSystem`：有素材時走材質渲染，沒有素材時保留原降級路徑。新圖集沿用 ArtSystem 的 preload／coreStatus／failedAssets／retryFailed 契約。沒有新增 HTTP API、資料庫或存檔欄位；傷害、攻速、射程與控制契約不變。

安裝與設定沿用主手冊。發佈必須整包交付入口、TowerVFX／PaintedTowerVFX、兩張 PNG 與 sw.js 清單，並按照專案既有流程統一主版本／快取標記。若特效沒有更新，先檢查兩張圖是否載入，再使用遊戲既有更新修復入口；勿刪除玩家存檔。

回復應採上一份完整發佈快照與新的回退版本號，避免入口與圖集不同步。保留玩家匯出備份；不得覆盖工作區其他任務的未提交改動。
