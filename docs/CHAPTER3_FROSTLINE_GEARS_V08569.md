# 第三章〈霜線與齒輪〉交付說明

版本：v0.85.69

## 玩家可見內容

第三章在完成第二章〈赤土終站〉後開放，共四個依序進行的故事任務：

| 任務 | 戰場 | 觀點與可重看線索 | 通關結果 |
| --- | --- | --- | --- |
| 3-1 霜線未明 | 白痕隘口 | 凜追蹤逆風而行、沒有可確認重量的霜痕。 | 解鎖白痕隘口自由遠征地圖。 |
| 3-2 齒輪的回聲 | 回聲機座 | 奇克保存「回覆早十七秒」的原始讀值。 | 解鎖回聲機座自由遠征地圖。 |
| 3-3 兩種讀法 | 交痕溪谷 | 泥印與儀器讀值相互矛盾，但兩者都可重複驗證。 | 解鎖交痕溪谷自由遠征地圖。 |
| 3-4 夜守校準 | 夜守校準站 | 兩組觀測交叉校驗，確認異常存在、但無法辨認來源。 | 解鎖夜守校準站、霜原獵群／霜牙・凜、地精工程團／銅齒・奇克。 |

每關有三張可從劇情模式重播的故事卡。故事卡不是一次性動畫：其內容與戰場上的裂石、量架、採樣點、校準橋和訊標彼此對應，讓玩家在知道後續結果後可回頭重看細節。

## 敘事邊界

本章只建立霜原與地精各自的觀察方法，以及他們選擇共同調查的理由。它不宣告：

- 異常來自哪個勢力、人物、種族或地點；
- 南方帝國、獄烈戰爭或神秘古代種族的答案；
- 霜原或地精的正式起源、地理、歷史或政治關係。

因此沒有新增 Chronicle 正史條目。終章的「尚未送出的問題被回應」是角色眼前的現象，不是對來源的定論。

## 操作與解鎖

1. 在劇情模式完成第二章最终任務〈赤土終站〉。
2. 依序完成第三章四關；尚未完成前一關時，後一關僅可查看，不可出征。
3. 第四關勝利後，從自由遠征選擇霜牙・凜／霜原獵群或銅齒・奇克／地精工程團。兩個軍團仍可與其他既有英雄、軍團自由組隊。
4. 若畫面仍顯示舊地圖，關閉舊分頁後重新開啟；服務工作者會快取新戰場美術。

管理者檔案可直接選取任何章節與任務，按「觀看本關劇情」閱讀完整故事卡。此為純預覽，結束後會返回劇情地圖，不會把任務標記為通關或改寫一般玩家的解鎖順序。

既有存檔不需要移轉：`ProfileStore.complete` 會以既有的 hero、faction、map ID 寫入解鎖。重玩已完成任務不會重複解鎖或重複寫入圖鑑。

## 工程結構

- `src/td/app/StoryCatalog.js`：任務、故事卡、戰後文字、波次與獎勵。
- `src/td/maps.js`：道路、雙路匯流、建造區、禁建故事地標、手機鏡頭。
- `src/td/TDGame.js`：自由遠征地圖介紹與選單項目。
- `src/td/codex/StoryCodexMapping.js`：終章的既有英雄／軍團解鎖；不新增編年映射。
- `assets/td/chapter3-*-v1.png`：四張 1536×1024 戰場原圖。

## QA 清單

- 四張 PNG 均為 1536×1024，地圖以原尺寸繪製。
- 道路、橋面、採樣與校準地標皆不可部署；每張圖有至少十個相隔的有效塔位。
- 交痕溪谷為雙入口、橋頭匯流，匯流後道路資料相同。
- 第二章完成前，霜原與地精不會被解鎖；第三章前三關也不會提前解鎖。
- 第三章終章重複結算時，英雄與軍團解鎖保持單一 ID，無重複紀錄。
- 已驗證：`npm run check` 與故事／地圖／存檔／圖鑑相關測試。
