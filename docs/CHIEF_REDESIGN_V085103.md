## 玩家可見的變更

選角、排行榜頭像、故事卡引用的大酋長個人立繪、商城／造型實驗室的原型比較，改用選定的新立繪。本體的待機、移動、攻擊與施法，以及覺醒、超凡動作圖皆換成同一身份：灰黑及肩亂髮、舊傷、灰鬍渣、獠牙、露出的胸肌／手臂、不對稱破損拼甲與深青披風。

覺醒使用銀青色強化甲與斧刃，超凡使用黑金強化甲與金邊深青披風。兩階保留露肌與拼補特徵，沒有重新變回整齊全身甲。武器升級、軍械、商城造型所有權、進化石流程、Lv.0、傷害、射程與碰撞數值維持原規則。

有裝備既有商城造型時仍依玩家外觀偏好顯示；想看新本體可卸下造型，或在已進化且有商城造型時切換進化外觀。沒有新增需購買的新造型。舊備份可正常續玩，不需要清除資料或重新買商品。

新增 `ChiefBaseSpriteArt.js`，只替 chief 基礎圖使用已量測的矩形與腳底點。原始高度 92、覺醒 100、超凡 106 保持角色比例設定。所有框在製作階段量測，正式遊戲不逐幀掃像素。Canvas 操作以 try/finally 還原；缺圖返回既有渲染鏈，不重新載入退役圖。

沒有新增資料庫、網路 API 或玩家存檔欄位。HeroLooks／ThunderKing 的原型描述改為灰黑野髮、拼補破甲、深青披風；付費造型本身不重繪。版本同步至 package、HTML、Worker、更新入口、ProfileStore、FrontierApp 與戰報。

## 安裝測試與管理重現

沿用現有 Node 環境，沒有新增套件。一般網站啟動方式不變。

```text

```

另一終端使用既有 Playwright 與 Edge，指定 EVOLUTION_QA_URL 為本機 td.html 後執行 `npm run qa:evolution-all`。全部 11 英雄兩階雙尺寸共 44 組真實買石、進化成功、Lv.0 與 checkpoint 還原通過；仍屬加速流程驗證，不是平衡測試。新增本體 rank0 動作截圖，與 rank1／2 一起驗證四狀態、四影格、左右方向及最高階裝備。實際檢視同場士兵比例及三階並排，完整報告在 artifacts/evolution-all。

48 個新姿勢透明邊界、無漏出實心像素、逐格尺寸與定位通過；基本渲染不修改武器、軍械或成長資料，繪製例外可還原 Canvas。全共享進化圖 320 姿勢及既有付費造型／缺圖回退測試仍通過。本機全套 1,201 項通過。商城造型實驗室另驗證新本體對照已購冥骨帝王的四狀態，並調整本體立繪取景以保留野髮；本機發布逐檔比對 268 檔／274 次請求通過。
