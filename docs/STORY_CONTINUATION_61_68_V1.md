# 第 61–68 頁封件去向與未解的代價

2026-10-12，續篇審閱 0.12.0。新增八頁彩色四格，接續第 60 頁；本機閱讀器現涵蓋 45–68 頁，共 24 頁。這一批仍是待作者驗收的獨立審閱稿，不接入正式 44 頁，不新增戰鬥、配樂、解鎖或玩家資料，也沒有推送 GitHub。

## 故事推進與八頁順序

本批讓調查得到可追問的送件去向，讓兩位英雄正面談亡魂代價，再以仍在持續的追捕阻斷消息回傳。公共會所當晚送過封件，不代表那就是王子案卷；讀者知道新材料已保留，雷恩此時卻尚未收到。共同城市的守路權沒有被默默交給王國。

## 人物與美術

雷恩、希爾芙、維菈仍以遊戲原 selectionArt 為唯一英雄外貌基準；維菈保持象牙白膚色、銀白髮、紫眼與黑紫輕甲。聯絡員為橄欖膚色、黑短捲髮、細黑鬍、炭色外罩；受保護證人為褐膚短捲髮、無鬍、赭紅背心，兩者不得混臉。

新配角「公共會所遞送員・艾岑」有明確登場身分框：人類中年男性、灰色側梳短直髮、尖灰山羊鬍、長鼻與眉缺口、赭色背心、青灰襯衫及送件皮夾。首見第 62 頁，往後以 main-62-v2.png 作參考。他不是英雄或已故王子的替身。

使用內建 imagegen，每頁一張 1536×1024 彩色四格，閱讀順序由左至右、由上至下。全部原始提示詞、角色參考、可讀台詞、生成來源及修稿提示詞保存在 assets/td/concepts/story-comic-v2/continuation/production-v3.json。

本批五次修稿均保留前稿：

- 62-v2：移除公共會所的藍金旗幟，保留中立公共建築。
- 64-v2：受傷銀葉兵去掉頭飾，改為有短鬍、舊疤的普通成年士兵，避免近似王族。
- 66-v2：移除暮影安置處門外不恰當的銀葉軍旗。
- 67-v2：移除城門建築的王國旗海、減少王宮式背景；士兵制服不變。
- 67-v3：補上女吏對守路權與查驗命令的質疑，避免默認王國已獲接管權。

AI 因果審稿及獨立逐張視覺複核已完成；第 67 頁曾被指出權限銜接問題，修稿後再親看通過。未見未解決的阻斷問題，但 AI 檢查不代替作者對角色辨認、節奏與台詞的批准。

## 閱讀操作與故障處理

從本機伺服器開啟：

`http://127.0.0.1:4189/assets/td/concepts/story-comic-v2/continuation/review.html?v=0.12.0#page=61`

上下頁與選頁固定可見；支援左右鍵、Home／End、故事文字、放大與拖曳。手機保持橫向，全頁模式保留完整圖幅；小尺寸閱讀細字可放大或展開台詞。舊第 45–60 頁網址仍可使用，60→61 可直接翻頁。讀者頁不寫 localStorage、sessionStorage 或遊戲存檔。

若顯示連線遭拒，先啟動本機 HTTP 伺服器；若只顯示至 60 頁，使用上方含版本參數的網址。單圖失敗可按「重新載入圖片」，清單失敗可按「重新讀取目錄」；確認 v3 清單與所有 WebP 存在。不要清除玩家資料或把直接雙擊 HTML 當正式驗收方式。

## 架構與維護

```text
版本 PNG 與 production-v3.json
              ↓
review-catalog.js 共用 validate
       ┌──────┴──────┐
prepare 轉 WebP      review.js 閱讀 45–68
                          ↓
                 圖片重試／文字／固定翻頁
```

共用驗證器支援 0.10.0／8 頁、0.11.0／16 頁及 0.12.0／24 頁。prepare 與 reader 改讀 v3；瀏覽器腳本加 ?v=0.12.0，避免沿用舊版驗證器。production-v1/v2.json 保留不改，當前清單的前十六筆與 v2 深度比對完全相同。安全檢查繼續拒絕跳頁、遠端圖、路徑跳脫、缺失人物參考及虛假的發布／作者核准旗標。

此支線不新增資料庫、後端 API 或遊戲存檔欄位，不變更 StoryMangaCatalog。build:site 排除整個 concepts；未來正式接入須另配置故事段落、解鎖與配樂，不能把審閱全本直接當成每關劇情。工作區另外存在遊戲功能變更，由各自文件管理，不屬本次續篇修改。

## 安裝與重建

一般閱讀沿用 Node 18+ 與專案伺服器，不需新套件；重建圖檔需 sharp，自動閱讀驗收需 playwright 與 Edge。沿用已安裝的工具環境；外部套件可透過 NODE_PATH 提供，不把個人機器路徑提交為專案設定。

```powershell
node scripts/prepare-story-continuation.cjs
node --test tests/td-story-continuation.test.js
npm test
npm run check:site
$env:TD_TEST_PORT='4189'
npm run serve:test
```

伺服器已占用 4189 時先確認是否就是本專案，勿重複啟動。另一終端執行 `node scripts/qa-story-continuation.cjs`；可用 STORY_CONTINUATION_QA_URL 改入口。截圖與報告輸出至忽略版控的 artifacts/story-continuation。
