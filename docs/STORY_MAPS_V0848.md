# v0.84.8 三張劇情戰場

劇情第一章現有四個任務，順序為「烽火初燃 → 溪谷餘音 → 舊城疑雲 → 裂谷守望」。第一關仍在新手谷地；之後依序使用銀葉溪谷、暮影舊城、冰原裂谷。完成前一關才能開始下一關；既有存檔若已完成首關，可直接挑戰溪谷。自由遠征地圖隨任務獎勵開放，最終關沒有額外地圖獎勵，通關進度仍會儲存。第二章尚未開放。

## 玩家操作

從大廳進入「劇情模式」，在章節頁選擇已開放的任務並查看地圖、目標、波數與獎勵。任務開始後選擇英雄與軍團，於草地或雪地合法區域建塔；路面、水域、裝飾平台不可建。建塔前先看預覽顏色與道路距離，避免在只能照顧末端的地方花掉前期金錢。冰原裂谷有兩個入口，但兩路會提早匯流，建議把主力放在共用道路旁。

## 地圖與玩法

| 地圖 | 路線與關鍵部署 | 美術規則 |
| --- | --- | --- |
| 銀葉溪谷 | 一條連續溪谷道路，橋前、轉彎內側、後段草地可分段設防 | 森林、河流、瀑布與銀葉建築；只有下方藍色城門是終點 |
| 暮影舊城 | 單入口繞城；中央廣場是主要共用火力點，前段與出彎後可補防 | 暗色廢墟與水域；黑暗高塔退到遠景，中央可建塔 |
| 冰原裂谷 | 兩入口早期匯流，匯流後共用長路；可集中資源防守 | 雪地、冰橋與冰河；平台建塔，結冰水域不可建 |

地圖均使用 1536×1024 本機 PNG。道路座標、建塔多邊形、劇情資料與解鎖分別在 `src/td/maps.js`、`src/td/app/StoryCatalog.js`、`src/td/app/FrontierApp.js`。戰鬥仍共用原有 `TDGame`、`BuildSystem`、`WaveSystem` 和 `ProfileStore`；沒有新增 API 或資料庫。三張新戰場美術在玩家選中該圖時才載入，以免加重初次開啟的等待。Service Worker 將圖片列入離線資產清單。

## 維護、更新與回復

安裝與部署沿用既有靜態網站流程：更新完整專案後以 `npm test`、`npm run check` 驗證，再以 `npm run serve:test` 開啟 `td.html`；確認 Service Worker 快取版本更新。玩家資料仍在瀏覽器本機儲存，更新前先從設定頁匯出備份；回復前一版本時使用上一版程式與資產並匯入備份。已解鎖地圖與任務完成紀錄都在玩家檔案，勿只替換圖片檔。若地圖空白，檢查對應 PNG 路徑、離線快取與瀏覽器儲存空間；若建塔被拒，先確認位置不在道路、水面或裝飾區。無權限或伺服器端 API 變更。

## 驗證清單

- 三張圖片存在、尺寸正確，選圖與章節預覽顯示相同戰場。
- 道路起點與紅色入口、終點與藍色城門一致；怪物沿畫面道路移動。
- 冰原兩入口交替出怪，提早匯流且共用同一段路。
- 合法建塔位置足夠，抽樣點在 180px 道路射程內；路面不能建。
- 四關解鎖順序、獎勵、存檔與最終關結算正確。
- 既有地圖、其他模式及離線載入回歸測試通過。
