# v0.85.16 第一章教學可信度與穩定性修正

## 使用者體驗

《烽火初燃》的推薦點改為 `(680, 415)`：已同時以士兵與防禦塔的地基規則驗證為可部署，並保留獵手攻擊道路所需的距離。發光圈半徑為 34；教學中的獵手在圈內 64 單位範圍點擊時會自動吸附到合法中心，因此不會再因點到圈邊而失敗。

教學文案不再顯示「84 格／150 射程」等內部數值，改為「選擇王國獵手、點發光圓心」的可操作指令。部署步直接提供「選擇王國獵手」按鈕，按下後才顯示發光圈；玩家不必在被遮罩的建造卡列中尋找目標。

每波準備期會明確說明：倒數結束會自動開戰，也可以按「立即迎戰」提前開戰。第一波後，暫停點改為直接高亮「升級」：玩家升級後自動進入下一波準備，也可按「暫不升級」繼續。商城與第三波裝備教學沿用後續節點。

## 版面與穩定性

路線、部署、開戰和觀察卡改放於左側安全區且縮小寬度，避免覆蓋道路中央。教學事件（擊殺、開波、波次結算、掉落、升級）與教學繪製均有隔離：若教學本身發生例外，會記錄瀏覽器錯誤、移除教學並提示玩家可繼續戰鬥，不會令主迴圈停止。

## 架構與 API

`StoryCatalog.tutorial.recommendedPositions` 增加畫面半徑資料；`TutorialIntegration` 在第一關部署步包裝既有 `BuildSystem.stagePlacement()`，只在獵手與教學圈附近啟用吸附。`BuildSystem` 的地形／佔用／消費規則沒有放寬或繞過。無新增 HTTP API、資料庫、權限或存檔 schema。

## 安裝、部署、回復與備份

需完整發布 `td.html`、`td-tutorial.css`、`TutorialSystem.js`、`TutorialIntegration.js`、`StoryCatalog.js`、版本顯示檔與 `sw.js`。版本為 `0.85.16`、離線快取為 `sky-strike-v0.85.16`；更新後重開頁面，使新的 Service Worker 和腳本生效。

回復時同步還原以上檔案與快取名稱。既有 story profile、裝備和通關資料不需遷移；重播按鈕仍可測試新流程。

## QA 清單

1. 在推薦圈中心驗證 `canPlaceAt(..., 'unit')` 與 `canPlaceAt(..., 'building')` 均為真。
2. 在圈內不同位置點擊獵手，確認放置吸附至中心並成功扣除資源。
3. 驗證「選擇王國獵手」按鈕可直接進入部署，無須在建造卡列尋找目標。
4. 驗證準備倒數、提前開戰、第一波後升級與「暫不升級」分支。
5. 確認所有教學卡不遮住道路中央；手動模擬教學事件錯誤時戰鬥仍持續。
6. 執行 `npm run check`、`npm test` 與瀏覽器首關實測。
