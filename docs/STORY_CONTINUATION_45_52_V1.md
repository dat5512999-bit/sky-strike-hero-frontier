## 這一批要推進什麼

戰事造成的責任不因撤離成功而消失。希爾芙必須向父親提出他不願聽的目擊；維菈必須處理救援中的實際失誤；雷恩失去公權力後只能提出有限的核對請求。國王與首相把援助化為影響共同城市的機會，但讀者此時不會看見凶手自白或新的定罪證據。

共同城市的公共制度仍然存在。王國提出協助不等於已接管城市；銀葉王有限度處理傷者不等於已認錯停戰；維菈被救者感謝不等於禁術沒有代價。所有新流程均為本批場景提案，不補完未定世界謎團。

## 八頁分鏡與台詞

### 45 她帶回來的不是捷報

稍後，希爾芙回到先前議事的銀葉行館。她把戰地筆記放在父親桌上，袖口仍有灰塵。父親抬眼問：「他們是不是用了禁術？」她回答：「現場有人這樣判斷。我能確認的是，我們先攻進我在的那條街。」末格兩人隔著桌，希爾芙說：「我帶回來的是先後，不是替誰開脫。」區分禁術的轉述與她親眼看見的街道目擊，不冒充掌握全部戰線。

### 46 一條路還可以先打開

父親摸著已故王子留下的葉形衣扣，問：「那你弟弟呢？」希爾芙沒有催他釋懷：「我也想知道誰害了他。」她展開救援路線手繪圖：「先讓傷者通過。查案不會因此停下。」父親沉默後交給隨員一份限令：「銀葉把守的這處通道，先准傷者與救援車通行。其他命令不變。」最後框：「一條路先打開了，父女之間卻沒有和解。」這是局部讓步，沒有全境停火，也不是替共同城市決定所有道路。

### 47 不是每件事都能靠她一個人

暮影臨時安置處，沿用第 41 頁白頭巾的短黑髮女救援者。她拿兩份重複領取的敷料清單來；另一張床還沒領到。維菈對照自己先前匆促指示後承認：「這兩份都是我交代的，卻沒指定誰統整。」她把普通供應冊交給女救援者：「由妳統整。缺了什麼，直接告訴我。」女救援者分配敷料，維菈留在旁協助。禁術記錄依然合上放在她身邊，不因這項修正就洗掉使用亡魂的代價。

### 48 首相提出的幫助

稍後，消息送抵王國王宮；明確不是共同城市。使用既有人類王／首相外觀表，不新造另一張臉。王室議事桌上是戰事與商路受阻的報告，沒有暗殺密令。國王問：「他們現在總該需要我們了吧？」首相斟酌：「先送糧與護送人手。讓他們看見誰能讓街道重新通行。」首相專屬介紹框：「首相｜人類王國・政務重臣」。國王示意擬文；末格首相平靜補上：「先從協助的名義開始。」只顯示政治算計，不揭露王子案實行者。

### 49 援助不等於交出城市

其後，王國使者在共同城市公共議事廳提出援助方案，穿政務外衣，不用雷恩的英雄臉。商民與各族代表坐在同一張公共桌旁，沒有新王座或遍掛王國旗。第 19 頁短束黑髮、灰藍背心、白袖的辦事女吏記錄。沿用第 44 頁禿頂、黑鬍、褐背心石材商，問：「糧可以收。守路的人聽誰指揮？」公共會議有限同意後，女吏讀出：「糧車先送到公共檢點，護送者只隨車；守路權另議。」灰短髮的年長女精靈與黑辮的糧商代表參與議事，不使用已故王子或受保護證人的臉。沒有全面接管，士兵只在門外護送貨車，不佔領議事席。

### 50 沒有權力的人如何繼續查

城外受保護中繼處，雷恩與同一位褐膚捲髮證人繼續核對；不是證人走進公開會場。部屬問：「現在還能調閱封存紀錄嗎？」雷恩答：「沒有調閱權。先請當班的人核對自己的所見。」他只抄問題，原件與證人留下；書面標題「核對請求」。一名守衛換上普通外罩衣，到公開救援登記處交件，畫面不描出藏身路線。使者以短黑髮、細黑鬍、長鼻、明顯耳廓與橄欖膚色區分雷恩和證人；雷恩囑咐確認無人跟蹤再回來。另一守衛仍留守，原有兩名守衛不能全離開證人。中繼處不掛王室旗幟。

### 51 一封有限的請求

公共救援登記處，第 19／49 頁女吏接到封好的核對請求。普通外罩衣使者說：「這是自願核對請求，只寫親眼所見。」請求不公開雷恩、證人或藏身位置，沒有案卷原件隨行。女吏不私下交出封存案卷：「我只能先整理我親眼看見的部分。」銀葉哨兵核對第 46 頁限令後，放行希爾芙押送的救援車；女吏當面問：「公主，請另寫妳的戰地所見，好嗎？」希爾芙說：「我的記錄另寫，不先看別人的答案。」這只是願意獨立提供戰地目擊，不是王子案現場證言，也不是結盟或互相赦免。

### 52 還不是同一支隊伍

希爾芙獨自寫目擊；女吏將不同事件、各自標明時間的兩份記錄分開封存，以「當晚所見」及「戰地所見」區別，不把案發夜與戰地時序混成一冊，也不擅自確定為不同日期。雷恩的使者領回兩份封件，女吏提醒：「這只是各自的所見，還不是結論。」場景標示「另一處・暮影安置處」，維菈按供應冊指揮安置，仍未收到雷恩私密材料；不暗示精確同時。末格城中護糧車經過公共檢點，王國護送者只隨車，不設哨、不指揮居民，公共人員仍記帳。末句：「有人試著把事情查清，也有人開始決定，城市該聽誰的。」保留下一步交叉核對的空間，不突然結盟或西行。

## 身分與畫面驗收

三英雄使用 HeroRoster 的 hunter／arcanist／rogue 原始 selectionArt，另以第 41–44 頁承接姿態與場景。銀葉王與人類王不可混臉；首相無鬍、窄長臉、灰鬢，與圓臉紅棕鬍的國王分離。女吏取第 19 頁，救援者取第 41 頁，證人取第 42／44 頁；不能把他們換膚色或畫成王子。配角臉有明確五官。

每頁 1536×1024、四格、彩色、由左到右再由上到下；台詞短，依行動而非旁白講設定。王宮、銀葉行館、共同城市與城外中繼處用場景標示分清，不能把三位英雄畫成同隊一起旅行。

## 安裝、重建與測試

沿用專案 Node 18+ 與既有 HTTP 伺服器；一般閱讀不需安裝任何套件。圖檔重建需可供 Node 載入的 `sharp`；自動瀏覽器驗收需 `playwright` 與 Edge。若使用 Codex 提供的套件，先將該環境的 `NODE_PATH` 指向已安裝套件目錄，不把本機絕對路徑寫入專案設定。

```powershell
node scripts/prepare-story-continuation.cjs
node --test tests/td-story-continuation.test.js
npm test
npm run check:site
$env:TD_TEST_PORT='4189'
npm run serve:test
```

若 4189 已由這個專案的伺服器使用，直接沿用，不重複啟動。伺服器啟動後，用另一個終端執行 `node scripts/qa-story-continuation.cjs`；預設檢查 `http://127.0.0.1:4189/assets/td/concepts/story-comic-v2/continuation/review.html`，可透過 `STORY_CONTINUATION_QA_URL` 指定自己的 HTTP 入口。輸出位於忽略版控的 `artifacts/story-continuation/`。網址附 `#page=51` 可直達第 51 頁，也支援同頁改換頁碼；上下頁或鍵盤左右鍵、Home／End 都不需捲動頁面。細字可用「放大拖看」或「故事文字」。

若目錄讀取失敗，按「重新載入」；單張圖失敗可按重試，也能先讀台詞或繼續翻頁。直接雙擊 HTML 可能受到瀏覽器本機檔案限制，請改用 HTTP 入口。審閱稿不提供配樂，也不會更改正式故事的配樂設定。
