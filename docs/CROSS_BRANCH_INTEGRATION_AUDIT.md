## 已驗證

- 瀏覽器：大廳 → 商城 → 冥骨帝王 → 換裝比較 → 返回遊戲內商城可走通；大酋長原版與新造型素材載入完成，沒有頁面錯誤。
- 自動測試：商城、圖鑑接線、造型資料、四英雄試裝共 24 項通過；`npm run check` 通過。
- 完整 `npm test` 的結果會受同目錄並行修改影響；目前另有地圖測試失敗，需由該功能完成後再做最終回歸。

## 版本與交付邊界

這些功能目前在共享工作目錄中可執行，但多數仍是未提交變更或獨立分支內容；不能把「本機可玩」當成已合併到 `main` 或已部署。正式交付前需固定來源版本、將相關檔案納入單一可回復的提交，再部署完整資產與 Service Worker。
