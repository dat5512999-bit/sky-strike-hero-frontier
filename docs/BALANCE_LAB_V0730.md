# v0.73.0 多局平衡實驗室

## 目標

讓單一主要測試者也能以固定條件累積可比較樣本。工具只觀測與分組，不自動修改平衡，也不把單局結果視為結論。

## 使用流程

1. 固定地圖、難度、英雄與軍團。
2. 選擇自由遊玩、擴軍測試、核心升級或混合測試標籤。
3. 每個標籤至少完成三局。
4. 在「戰況」比較最近六局；壓力波需以相同策略複測後才考慮改數值。

## 指標

- 多局：進度、積分、時間、部署／升級／商店支出、剩餘資源、滿級數量。
- 效率：各兵種或塔的總有效傷害、擊殺、實際投入與每 100G 傷害。
- 里程碑：首次 Lv.3、Lv.5 與終極士兵的波次。
- 壓力斷層：本波壓力指數相對前三波顯著升高；包含清場時間、漏怪、城門傷害及英雄倒下。
- 支援：估算額外傷害、控制秒數、覆蓋秒數、補給節省與折射次數。支援數值用來比較，不等同精確因果傷害。

## 比較邊界

歷史只比較相同地圖、難度、英雄與軍團，避免不同規則混為一談。策略標籤不影響獎勵或積分。資料仍使用既有 localStorage，無網路上傳。

## 還原

回退 BattleReportSystem 的策略／效率／歷史方法、BattleSynergySystem 支援來源標記、BuildSystem 折扣來源、TDGame 戰報呈現、開局與戰況 UI，以及快取版本。既有舊紀錄缺少新欄位時以零值或自由遊玩顯示。
