# 劇情與戰鬥銜接 v1.0.0

日期：2026-10-12。狀態：本機實作與驗收；未宣告 GitHub 部署。

## PM：需求、範圍與原因

原本所有入口都是分段閱讀。每段讀畢退回目錄，觀看戰前與開始關卡相同，戰後不接續，所以故事與遊戲割裂。本次將「主線遊玩」與「章節回顧」分開：主線按既有正式漫畫順序推進，戰前結尾才開始戰鬥，勝利結算接戰後及後續段落。

正式內容仍是 44 頁與一場護證撤離戰鬥，不新增事件或把其他 15 場舊挑戰編入新版正史。後續製作中的漫畫不納入正式內容。沒有新英雄、美術、戰鬥數值、遠端 API 或帳號權限變更。

## UI／使用者操作

1. 大廳「開始主線／繼續主線」直接打開故事；側欄「劇情模式」仍可選章節。
2. 主線每段讀完按「繼續劇情」接下段，不退回目錄。
3. 戰前最後一頁按「劇情讀完・開始戰鬥」，直接開始本關；不再多經過摘要頁。
4. 勝利且任務已儲存後，結算按「繼續主線・戰後劇情」，再依序閱讀同期事件。失敗不推進；再挑戰留在原關卡。
5. 「回顧戰前／回顧戰後／只回顧本段」不會開始戰鬥，也不改變主線續玩位置。
6. 隨時可以返回章節。主線續玩記錄按玩家與輪次保存；戰鬥中重整後，從戰前結尾重新開始該戰鬥，不保存局內戰場。
7. 第 44 頁後明確提示本篇結束，後續未開放；既有挑戰仍可另選。

## 架構、資料與 API

```text
StoryMangaFlow 正式段落與任務映射
  → StoryCampaign.steps / start（連續主線、獨立續玩記錄）
  → StoryManga（漫畫、頁目錄、文字、完整圖片）
  → 戰前最後頁 → FrontierApp.launchStory → TDGame
  → onBattleEnd → ProfileStore.complete（原有獎勵／解鎖）
  → ResultScreen → openNextStory → 戰後漫畫 → 下一段

章節回顧 → StoryManga（非 campaign）→ 返回章節
```

新增 `src/td/app/StoryCampaign.js`，在 StoryManga 之後、FrontierApp 之前載入；Service Worker 同步登錄。`StoryManga.open` 使用 request.campaign 區分主線，不藉管理者預覽跳過戰鬥依賴。主線開戰需要正確人物檔案、戰前最後頁、可用任務，且避免重複開戰。結果須屬於同一玩家／輪次／任務，敗北與儲存失敗不能接戰後。

`StoryCampaign.start(app,nodeId?)` 開始／續玩或從所選節點開始；`next(app)` 銜接故事或開戰；`recordOutcome(app,victory,result)` 記錄這次結果；`afterBattle(app,mission)` 導向戰後。既有 `manga-before/after/section` 為回顧，`story-battle` 為遊玩，`story-continue` 為續主線。

資料在既有 ProfileStore 的 `manga:campaign-v1`，格式 `{key,pageId}`；`manga:bookmark-v2` 保留作分段回顧。無 schema 遷移，無新資料庫／HTTP API。損壞書籤從開頭重新閱讀，未解鎖戰後記錄導回对应戰前；絕不把讀過當成通關。管理者預覽不寫閱讀紀錄或獎勵，真正開戰則沿用既有管理者戰鬥規則。

## 安裝、設定、管理與部署

沿用 Node.js 與既有安裝流程；`npm run serve:test` 啟動後開啟 `td.html`，手機沿用 `td-mobile.html`。無新套件、金鑰或設定。管理者仍可直接回顧未解鎖內容，但「開始主線」遵守戰鬥依賴。內容人員只需維護 Flow 的正式分段／before／after，主線順序依頁码生成，不得將尚待審稿的素材接入正式主線。

功能版號記在 package.json 的 `storyCampaignVersion: 1.0.0`，主應用版號由整合發布管理。發布時必須包含新 controller、reader、FrontierApp、TDGame 重試修正、結果按鈕、HTML、Worker、測試和本文件。執行 `npm run test:story-campaign`、語法檢查、全套測試、`npm run check:site` 後再發布；其他工作未通過驗收時不得將全專案宣稱為已完成發布。

## 備份、回復與 FAQ

更新前由設定匯出玩家 JSON，包含主線及回顧書籤。回復應用時成套回復上述檔案與快取版本；舊版會忽略新的 campaign-v1，不必刪存檔。不要使用清空瀏覽器資料排除問題。

- 為什麼讀回顧沒有開戰？回顧刻意不開戰，請按開始主線或開始：劇情 → 戰鬥。
- 為什麼看完前情還沒戰鬥？既有正史前情為第 1–30 頁，戰前為 31–33 頁；沒有額外插入與故事無關的戰鬥。可在章節選擇「護證撤離」直接從該戰前開始。
- 為什麼下一場沒有接上？現有正式映射只有一場戰鬥，不能用未完成或舊版故事冒充新版主線。
- 為什麼戰後按鈕沒出現？本次必須勝利且任務儲存成功；失敗時不能靠以前通關記錄推進這次劇情。
- 重整後戰鬥從頭？主線書籤不包含戰場狀態，回到戰前末頁後重新開始該關。
