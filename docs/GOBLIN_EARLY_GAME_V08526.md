# 地精工程團：前期機座門檻（v0.85.26）

## 目的

地精的單一已供電火器手不弱，但原本的動力機座 125G／2 木沒有直接傷害，導致「機座＋火器手」剛好吃滿 240G 起始金幣。相較人族可以先部署兩個立即輸出物件，地精在第一至第三個部署時落後。

## 本次調整

| 項目 | 原本 | 現在 |
|---|---:|---:|
| 動力機座 | 125G／2 木 | 95G／1 木 |
| 機座容量 | 3 | 3 |
| 供電攻擊加成 | +22% 傷害 | +22% 傷害 |

因此機座＋火器手為 210G／3 木，能在首波保留 30G／2 木；機座＋武器台為 205G／3 木。這是降低前期入場成本，不是提高滿網路倍率。

## 驗收、相容性與回復

自由遠征以地精部署動力機座與火器手後，確認資源剩餘 30G／2 木、機座仍顯示 `供能 1/3`、火器手仍顯示 `供電 +22%傷害`。沒有存檔遷移、武器／軍械／掉落調整或戰報平衡版號變動。

執行 `node --test tests/td-goblin-network.test.js` 與 `npm run check`。回復時將動力機座成本回到 125G／2 木，並連同 `sw.js`、版本檔回到前一版。
