# v0.75.0 功勳節奏調整

## 決策

依第 16 波實玩截圖，混合策略仍持有 12 功勳、3688 金與 42 木，功勳沒有形成高階養成取捨。本版保留玩家指定的 `1000 金幣 ⇄ 1 功勳` 固定雙向兌換，只調整額外來源與建築消耗。

## 規則

- Boss 擊破仍提供 1 功勳。
- 邊境補給由 `120 金＋2 木＋1 功勳` 改為 `120 金＋2 木`。
- 金幣與功勳維持雙向 1000:1，無次數或波次限制。
- 建築 Lv.3→4 需要 1 功勳，Lv.4→5 需要 2 功勳；金幣曲線不變。
- 士兵高階升級、塔價、波次獎勵、擊殺金與難度均不變。

## 驗收

執行 `npm run check` 與 `npm test`。實玩時記錄第 15、20、30 波的金、木、功勳，以及滿級建築數量；目標不是強迫歸零，而是讓每座高階建築形成取捨。

## 還原

回退 `LootSystem` 的邊境補給資源、`Building.upgradeCost()` 的功勳階梯、版本與本文件。戰績與存檔格式未變。
