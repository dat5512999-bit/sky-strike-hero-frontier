# 第一章劇情角色連貫規格 v1

## 唯一基準

劇情圖的英雄必須能被玩家辨識為遊戲中同一名未套造型英雄。任何新圖先以 `assets/td/opening/` 的原版選角圖為五官與骨架依據；商城或活動造型只能補充氣質與材質，不能取代原版臉孔、髮型或身形。

| 陣營／英雄 | 原版基準圖 | 不可改變的辨識點 |
| --- | --- | --- |
| 王國守誓者 | `hero-hunter-selection-v1.png` | 棕色微捲髮、濃眉棕眼、方正成熟臉形、藍金甲、白毛領、藍色披巾與大盾。 |
| 銀葉森語者 | `hero-arcanist-selection-v1.png` | 長棕髮、葉片髮飾、尖耳、柔和綠瞳、綠披風、白綠葉紋甲與自然弓。 |
| 暮影影行者 | `hero-rogue-selection-v1.png` | 白髮、紫眼、蒼白膚色、黑紫兜帽與輕甲、纖細敏捷輪廓、短刃。 |
| 荒野大酋長 | `hero-chief-selection-v2.png` | 綠膚、黑色辮髮與鬍鬚、獠牙、額頭紅紋、巨型結實身形、紅黑皮甲與毛皮。 |

`assets/td/story/chapter1-hero-continuity-v1.png` 是上述四位英雄的統一劇情製作參考圖。所有第一章新劇情 Key Art 都必須用它與相對應原版基準圖做角色參考。

## 允許與禁止

- 允許：為劇情需要調整姿勢、鏡頭、環境、時間、表情強度，以及在不遮蔽辨識點下加入合理的任務裝備。
- 允許：造型版的布料質感、配色比例或飾件作為輕度參考，但原版五官與髮型仍優先。
- 禁止：生成新的主角臉孔、改變膚色或眼色、把銀葉改成銀白髮、把暮影改成不同瞳色或髮色、把王國英雄改成另一名黑髮人物。
- 禁止：以「同一陣營」取代「同一角色」；群眾可有變化，鏡頭中的主英雄必須符合基準。

## 驗收

每張圖在接入遊戲前，需對照原版選角圖檢查：臉部輪廓、髮色與髮型、眼色、耳朵／獠牙等種族特徵、主色裝備和身形輪廓。任一項無法讓玩家在三秒內辨認為同一英雄，即不採用。
