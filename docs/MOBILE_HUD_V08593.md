# 手機戰鬥介面 v0.85.93

日期：2026-10-09。手機 HUD 模組 1.1.0。本機完成；尚未推送或部署。

## 需求、設計與範圍

修正手機操作列左右抖動、招募關閉鍵裁切、英雄頭像遮住警告與技能圖未載入就開戰。不修改戰鬥數值、關卡、角色、權限或存檔格式。既有音效與劇情工作保留，未在本批重新發布。

1. 手機選取操作列固定在安全戰場下方中央，不隨單位或鏡頭移動；桌面繼續靠近選取單位。
2. 招募面板依扣除系統安全區後的容器寬度排版。卡片可橫滑，叉叉獨立固定於標題列，觸控範圍 44 × 44 CSS px。
3. 頭像右側保留警告區；展開英雄資訊時再往右避讓。
4. 三名原始英雄的共用技能圖集優先下載，納入開戰前必要資源檢查。慢網路留在載入階段；失敗沿用原有素材重試入口，不會以缺圖狀態自動開戰。

## 架構與 API

```text
手機系統安全區 → td-mobile / main → 安全戰場容器
                                  ├─ TDGame.positionSelectionActions → 固定觸控操作列
                                  ├─ td-combat.css → 招募欄／固定關閉鍵
                                  └─ td-combat.css → 頭像與警告分區
HTML 圖集預載入 → ArtSystem.coreStatus → chooseProfession → 技能美術
```

`positionSelectionActions()` 是操作列定位的唯一擁有者，讀取實際 offsetWidth/offsetHeight；ArmoryUI 不再二次修正位置。`ArtSystem.coreStatus(type)` 的回傳介面不變，hunter/arcanist/rogue 多計入共用 skillIcons。無新增 API、資料庫、服務、金鑰或權限。

## 安裝、操作與故障排除

沿用 Node.js 18+ 與 `npm run serve:test`，開啟 `http://127.0.0.1:4173/td.html`。手機自動使用旋轉外殼；無額外設定。選取守軍後在畫面下方中央升級、回收或配裝。招募面板滑動卡片不會帶走右上角叉叉。

技能只見符號：先確認已更新至 0.85.93、網路可用且素材載入完成；若顯示素材失敗，使用既有重試按鈕。不要以清除網站資料作為第一步，避免遺失存檔。本次不宣稱可以隱藏 iOS 系統狀態列。

## 版本、部署與回復

package、遊戲頁、大廳、戰報、存檔匯出、更新頁與 Service Worker 快取標示同步 0.85.93。部署前先匯出玩家存檔並備份目前完整版本；`npm run build:site` 產生靜態包，整包部署，勿只覆蓋 HTML 或 CSS。發布後透過更新頁更新快取並重新開啟遊戲。

本批沒有存檔遷移。需要回復時部署更新前備份的完整靜態包，保留網站存檔，並經更新頁重新整理快取。測試截圖及紀錄位於忽略追蹤的 `artifacts/mobile-hud/`，不放入正式站台。

## 驗收

- `node --test tests/td-mobile-hud.test.js`：手機操作列固定與縮放、桌面實際寬度定位、圖集必要資源與失敗狀態。
- `npm test`：全專案回歸。
- `npm run check:site`：發布路徑與素材檢查。
- 安裝 Playwright 測試工具與 Edge 後，先啟動本機伺服器，再執行 `MOBILE_HUD_QA_URL` 指向該網址的 `npm run qa:mobile-hud`（預設埠 4186）。PowerShell 範例：`$env:MOBILE_HUD_QA_URL='http://127.0.0.1:4173'; npm run qa:mobile-hud`。
- 五組瀏覽器尺寸：844×390、667×375、568×320、390×844 旋轉、1024×600；包含 44/60px 安全區。驗證卡片滑動後仍可點關閉、警告不重疊、20 次位置更新不抖動、四技能美術及慢速圖集延後開戰。
- 已使用 Edge 無頭瀏覽器隔離測試資料；未執行 iPhone Safari 真機驗收。手機仍須驗收持續觸控、旋轉與系統列變動。
- 本機結果：1,081 項單元／回歸測試全數通過；五組觸控版面與慢速載圖瀏覽器測試通過；732 個發布檔案檢查通過。
