# 玩家介面繁體中文化（v0.85.29）

## 目的

讓不閱讀英文的玩家仍能直接辨識可操作的按鈕、分類、狀態與數值名稱；不以英文副標作為操作提示。

## 已涵蓋畫面

- 大廳：導航、副標、個人頁、設定、劇情章節與尚未開放提示。
- 戰場：金幣、戰局積分、英雄生命／能量／經驗、指令、商城、戰利品、軍械庫與戰報。
- 世界圖鑑：分類、副標、使用說明、詳細數值、編年史模式與劇情典藏。
- 造型商城與比較頁：分類、標語、橫幅與攻擊／生命欄位。
- 過場：章節標題、分鏡計數、劇情典藏及字幕語言名稱。

## 不變項目

- `data-*` 動作名稱、程式內部 ID、網址、存檔鍵與戰鬥公式維持原值。
- 英文、日文字幕軌的技術語言代碼維持 `en`、`ja`；畫面僅將語言名稱改成中文。
- 未變更任何英雄、士兵、商城物品、傷害、成本或增益效果。

## 驗收

1. 開啟 `td.html`，確認首頁導航、劇情／遠征卡與設定頁皆為繁體中文。
2. 進入任一戰場，查看英雄面板、商城、戰利品、軍械庫與戰報標題。
3. 從大廳開啟「世界圖鑑」與「商城」，確認分類與主要操作為中文。
4. 播放或重播劇情，確認章節、分鏡與字幕選單為中文。
5. 執行 `npm run check` 與 `npm test`。

## 更新與回復

若手機仍使用舊快取，從「設定與測試 → 更新並重新開啟」更新至 v0.85.29。此版本只更換畫面文案；回到舊版程式不需要轉換或刪除玩家存檔。
