# 第二章 2-1「西境風號」地圖交付 v0.85.37

## 玩家流程

完成第一章〈裂谷守望〉後，劇情模式可選擇第二章〈荒野的回聲〉的 2-1〈西境風號〉。玩家會先觀看三張既有戰前劇情卡，再用雷恩與王國軍團守住六波古道追兵。此關只推進線索，不會提前解鎖荒野部族、戈爾或西境自由遠征地圖。

## 防 bug 設計

地圖背景、道路與碰撞分離：`western-signal-v1.png` 只繪製美術；`maps.js` 明確定義道路中心線、城門、出生點、可建平地、遺跡／懸崖禁建區及鏡頭安全區。完整塔底座仍會與道路及占位檢查，故不會發生看起來能放卻無法放置、建物蓋住道路、怪物沒有進入城門或縮放後指令偏移。

## 驗收

`tests/td-story-maps.test.js` 驗證 PNG 尺寸、路線到城門、每一合法建造點距道路、道路禁建、障礙禁建、真實放置、故事前置條件及手機鏡頭資料。離線快取包含地圖資產；完整發行仍需真機長局與第二章後續 2-2 至 2-4 的平衡驗證。
