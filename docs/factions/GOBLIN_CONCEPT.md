# Goblins／地精勢力 — Faction Concept V1.0

2026-09-21｜[總覽與標籤規則](FACTION_DESIGN_BIBLE.md)｜[世界觀最高基準](../WORLD_STORY_BIBLE_V1.md)

本文除「使用者指定方向」外，均為 CONCEPT 提案。單位、塔及技能名稱為工作名；沒有已實裝或已加入正史的含義。

## 1. Faction Name

Goblins／地精勢力。政體、文明正式名稱與可玩軍團名稱未定。

## 2. Canon Status

CONCEPT。使用者指定方向為機械、工程、發明、裝置、經濟及特殊塔型。舊程式的機器人、工坊或傭兵不構成地精文明的正史證據，也不自動證明其製造者是地精。

## 3. 所屬大陸 / 發跡地

未知。不自行指定地下王國、海島城市、工業大陸或與矮人的共同起源。

## 4. 種族外觀特徵

提案：低重心、靈活手部、明顯護目鏡與工具帶，身形可用較小比例探索；耳形、膚色與生理特性未定。工種靠裝備輪廓辨識，不能把全族都做成相同小型炸彈客。

## 5. 文明特色

使用者指定方向：工程與發明文明。提案：可拆換模組、記錄試驗結果、可見的工作流程與交易；經濟能力來自設備與投入選擇，不設定天生貪婪、偷竊或必定爆炸的族性。

## 6. 核心價值觀

提案：解決問題、可重複製造、實際成果與公平計價；可容納穩健技師與冒險發明者差異。未建立全族信仰、法律或階級制度正史。

## 7. 與其他種族的關係

未知。提案若日後採用，可經裝置維護或有限工程合作初次接觸；對方、契約與結果未定。不預設王國所有火槍由地精製造，也不預設與矮人競爭或替南方古代種族工作。

## 8. 歷史背景

未定。不編造工業革命、機械戰爭、放逐史或古代科技來源。特殊裝置的材料和能源來源需日後審閱；不以神秘古代種族、聖靈或亡魂當便利解釋。

## 9. 為什麼加入 HERO FRONTIER 主線

提案鉤子：未來遠征遇到工程障礙或需要修復設備時，透過共同解決問題認識此文明。是否採用待定；地精不能一登場用儀器直接解開王子之死、聖靈原理或獄烈戰爭全部真相。

## 10. Gameplay Identity

「在有限供電與插槽下，決定現在輸出，還是投資稍後的收益。」以特殊塔配置為重心，士兵負責起手、點殺與維護支援。可見、可預測的工程取捨，取代單純把王國弩塔換成機槍。

## 11. Early Game

機械弩手等不需供電的基礎士兵先建立火力，再放第一個動力機座。過早蓋回收設備會缺傷害；玩家不必一開始就解複雜網路。

## 12. Mid Game

選一組供電區，配置射擊、控路或經濟裝置。每座模組塔只裝一種戰術模組；射程、範圍與火力不能全拿。重配需要準備時間，當下會失去部分輸出。

## 13. Late Game

大型攻城裝置需要高額金幣、插槽與供電。經濟投資到回本後才值得轉成火力；終局前繼續投資收益裝置可能來不及回本。最強輸出留下過熱停機窗口，不得全場無限連射。

## 14. 核心資源 / 特殊機制

提案保留共通金幣／木材，專屬機制為有限「供電容量」與局部「熱量」。容量是可分配的使用額度，不是擊殺掉落貨幣；能源材料與歷史來源未定。

- 動力機座提供範圍內容量，裝置配置前顯示占用；同一裝置只選一個供電來源，不靠重疊多座重複領電。簡化為局部供電，不要求玩家手拉電線。
- 高功率模式累積熱量，滿熱後可預測地停機冷卻；不使用隨機失控或爆炸殺友軍，也不假定建築有可維修生命值。
- 經濟裝置占用與武器競爭的容量；有效作戰期間累積工作收益，每波設上限，戰間等待、暫停、讀檔重播都不能額外產錢。
- 回收僅返還未消耗設備投入的一部分，禁止買賣、拆裝、折扣重算或自造機械殘骸套利。裝置不使用亡魂，敵人屍體不作資源。
- 基礎士兵無電也能攻擊；高階裝置斷電停用並清楚提示。重配保留已累積熱量與當波收益進度，避免切換洗冷卻／收益。

UI 提案：購買前顯示「花費、占用容量、預計回本波數」；裝置顯示「供電中／缺電／過熱」與符號。公式與參數另做原型，不宣稱現行 API 已支援。

## 18. Equipment Identity

提案：可替換瞄具、冷卻套件、齒輪組與彈匣。裝備改變一個取捨，例如大彈匣換更長換匣，散射換精度；不以一件裝備同時加電、免熱、增收益。塔模組與現有一人一件裝備分開設計相容規則，不能假定現在已能替塔裝備。

## 19. Faction Weakness

啟動成本高，發電與經濟塔本身不輸出；供電範圍限制分散部署。換模組與過熱有空窗，快速波峰可能在裝置停機時通過。經濟收益需要時間，短局與晚買回收站不划算；不能靠免費重配或隨機巨額獎金消除風險。

## 20. Visual Identity

Silhouette：工具背架、圓筒彈匣、齒輪外罩與明確炮口；Architecture：可拆裝平台、支架與可見模組接點；Armor：工作防具、隔熱手套、護目鏡，重機偶外殼另成輪廓；Weapon：弩機、鉚釘槍、絞索與炮架；VFX：金屬火花、壓力排氣、換匣與熱量警示，不用魂火或元素生命召喚；Color Direction：黃銅、鐵灰、警示黃與少量藍色供電指示。所有狀態需形狀／文字輔助，不只靠紅綠燈。

## 21. Story Unlock Proposal

附條件提案：若未來獲准進入正史，Encounter 可安排在 Chapter II 之後的工程合作支線，或後續新篇章；不指定已存在的地點與章號。Discovered 在第一次可驗證合作後揭露基本文明情報；Unlocked 在完成完整合作任務及教學後另定里程碑，英雄獨立安排。現階段均不寫入玩家存檔、正式章節或圖鑑，也不取代 Chapter II 荒野主線。
