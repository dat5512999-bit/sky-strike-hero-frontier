# v0.85.84 英雄武器、技能圖與攻擊音效

## 產品決策

範圍是現有 11 位英雄，不新增英雄、軍團、數值或存檔欄位。玩家應在商店看見下一階的真實武器圖，購買後能看見該階武器、聽見普攻，並在 Q／W／E／F 看見符合英雄的圖示。武器已內嵌於部分 4×4 角色逐格圖，因此不把第二把武器直接疊在角色手上；這會破壞原圖。商店、英雄資訊和短暫的購買展示使用逐階武器圖，實戰普攻以輕量短光痕和武器顏色辨識，不使用常駐光圈。

## 架構與資料流

```text
HeroRoster.classType ──→ 專屬技能圖集 ──→ 選角／Q-W-E-F
Hero.equipment.spear ──→ EquipmentSystem.weapon ──→ ShopSystem.spear／HUD／購買展示
Hero.update 真正開火 ──→ FrostlandAudio.playAttack ──→ Web Audio（最多 6 聲）
```

武器沿用既有初始武器與 Lv.1–3 的 `spear` 購買流程、價格和效果。`EquipmentSystem.iconStyle` 消費圖集欄列；娜迦、戰神新增透明 2×2 武器圖，其餘沿用既有圖。新圖加入 `sw.js`。`TDGame.drawWeaponReveal` 只在成功購買武器後短暫展示該階圖格，不覆蓋角色逐格圖；載圖未完成時安全略過。遊戲音效預設開啟，使用者可在設定關閉，偏好沿用既有 `heroFrontierFrostAudio` 鍵。Web Audio 在第一次玩家操作後啟動，瀏覽器拒絕時安靜略過，不中斷戰鬥。

沒有資料庫、HTTP API、權限或玩家存檔格式變更；舊存檔中的 `equipment.spear` 直接沿用。日後要實現武器本體逐階替換，需重製相關英雄的完整 4×4 無武器動作圖及逐格對位，不能把圖示放大當作手持武器。

## 玩家操作與問題排除

進入自由遠征，選英雄後開商店：第一張英雄武器卡顯示下一階武器。購買後畫面會短暫展示剛取得的武器圖，英雄資訊顯示名稱與等級；滿 Lv.3 不再販售。戰場右下角 Q／W／E／F 分別顯示該英雄技能。攻擊音效可於遊戲選單的設定切換；瀏覽器要求先點一次頁面才可播放。若仍看見舊圖或空白卡，先確認畫面版號、重新載入，必要時使用 `update.html` 更新快取；若單一圖片無法載入，檢查網路及開發者工具的 404。

## 安裝、管理與發布

維持 Node.js ≥18，無新依賴。執行 `npm run serve:test`，開啟 `http://127.0.0.1:4173/td.html`；管理者用 `npm test`、`npm run check`、`npm run balance:audit` 驗收。部署時武器 PNG、`EquipmentSystem`、`FrostlandAudio`、`HeroRoster`、`TDGame`、`sw.js`、入口版號需同版，確認 Pages 與 Service Worker 皆取得新圖。安全回退使用上一個完整 Git 提交與相同版本快取鍵，勿清除玩家儲存資料；部署前可先匯出玩家 JSON。新音效若需暫時停用，玩家可從設定關閉，無需回退資料。

## QA 清單與界線

- 11 位英雄 × 3 階商店武器：圖集存在、格子不重複、價錢與滿級行為正確；娜迦／戰神新增圖格透明且非空。
- 購買武器只出現短暫實際武器展示；待機無常駐升級光圈，攻擊時才有武器光痕。
- 11 位英雄實際開火才嘗試播音；無目標、靜音、音訊 API 失敗時不中斷遊戲，並限制同時聲道。
- Q／W／E／F 圖集與英雄一致；矮人、龍族、埃及、霜原、地精和原三英雄均須實際畫面抽驗。
- 全套測試、語法、軍團及敵軍平衡檢查，並於桌面與窄螢幕實玩。自動測試與本機瀏覽器不能代表玩家裝置的長時間 50 波流暢度，該項保留為實機追蹤。
