# 南方帝國與埃及島：第一批可測試內容

## 已確認的世界觀方向

- 南方帝國目前由惡魔統治。
- 其統治之下有龍族、食人魔、萬獸與矮人。
- 過去由龍族經由和平確認為統治者；其後受到惡魔介入而統一。
- 東北方存在埃及島，日後可發展成埃及軍團。

以上是本次收到的方向；年代、惡魔介入方式、各族地位、埃及島政治與完整劇情均**尚未設定**，不可視為正式細節。

## 可測試內容

|內容|定位|構成|戰術|
|---|---|---|---|
|矮人符文堡壘|南方帝國旗下候選軍團；`TESTABLE / CONCEPT`|符石監軍・巴隆、4 士兵、4 塔|符文熔爐為附近矮人士兵與英雄提供 18% 攻速；火銃穿甲、迫擊砲清群。|
|龍脈議庭|南方帝國旗下候選軍團；`TESTABLE / CONCEPT`|蒼穹使者・賽爾、4 士兵、4 塔|龍脈巢台為附近龍族士兵與英雄提供 18% 攻速；雷鏈、龍焰與穿甲分工。|
|埃及島英雄|單一伏筆英雄；`CONCEPT`|曦陽守衛・納芙拉|可單獨選用，沒有埃及軍團、士兵、塔、地圖或劇情解鎖。|

每名新英雄沿用既有商城的初始武器加三次連續升級。兩個軍團所有士兵皆接入現有軍械庫相容表，因此掉落與商店不會提供無法裝備的物品。

## 視覺與操作

- 矮人與龍族各有英雄、士兵、武器的透明 4×4 圖集；埃及島英雄與武器也有透明 4×4 圖集。
- 矮人符文堡壘與龍脈議庭各有獨立的軍團群像選擇圖，不再以英雄頭像充當軍團代表；兩張選擇圖位於各自資料夾的 `faction-selection-v1.png`。
- 圖集位於 `assets/td/dwarf/`、`assets/td/dragonkin/`、`assets/td/egypt/`，並由 Service Worker 預快取。
