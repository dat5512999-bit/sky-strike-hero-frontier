# 霜原塔樓戰鬥特效重整

## 目的

讓每一座霜原塔在戰鬥中有可辨識的職責，不會只看見相同的藍色飛點或箭矢。

## 表現對照

| 塔樓 | 飛行演出 | 命中／持續演出 | 戰鬥規則 |
| --- | --- | --- | --- |
| 冰晶尖塔 | 三棱冰晶與尾端冰環 | 五向旋散冰片 | 不變 |
| 暴雪祭壇 | 雪核與雙層渦流 | 三層暴雪環與雪點 | 不變 |
| 碎冰重弩 | 冰紋重弩矢 | 放射裂痕與碎冰核心 | 不變 |
| 霜骨圖騰 | 無投射物 | 低頻符文增幅環 | 仍為支援、無傷害 |
| 霜墓尖碑 | 棱晶彈 | 折射冰鏈與分叉晶翼 | 不變 |
| 極光獵台 | 雙股極光緞帶 | 短暫極光標記 | 不變 |
| 冰河核心 | 厚重冰塊與冷霧尾跡 | 擴張凍土環與冰片 | 不變 |

## 相容性與效能

- 沿用既有投射物生命週期與每幀裝飾特效預算；預算不足時僅略過裝飾繪製，命中、傷害、控制與戰報不會改變。
- 沒有調整數值、存檔結構、資產清單或離線快取版本。
- 霜骨圖騰的光環只畫在塔樓附近，不把完整增幅範圍常駐鋪滿畫面。

## 驗收

```powershell
node --test tests/td-vfx.test.js tests/td-frostland.test.js tests/td-battle-polish.test.js
```

預期為 49 個測試全部通過，其中包含六座攻擊塔的 style 契約、飛行／命中（或連鎖）繪製，以及既有 Frost、碎冰、支援與繪製狀態回歸。
