# v0.85.14 第一章互動新手引導

## 目的與玩家流程

第一章 1-1「烽火初燃」的首波維持故事難度下的 **3 名長戟衛**，但每名之間改為 4 秒間隔，讓玩家有足夠時間觀察守軍攻擊。開始倒數會先暫停，玩家依序完成：

1. 看紅色虛線道路與金色城門，理解敵軍的前進方向與失敗條件。
2. 點選高亮的「王國獵手」，放到綠色建議部署區。
3. 由高亮的「立即迎戰」自行放行首波；守軍會自動攻擊。
4. 首波結束時閱讀獎勵與下一波預告提示，再繼續正常關卡。

劇情模式的 1-1 任務頁提供「重玩新手引導」。完成或跳過會在既有 story profile adapter 寫入 `chapter1-border-onboarding-v1`；這只是介面進度旗標，不影響任務通關、資源、軍團解鎖、戰報或難度數值。

## 架構與公開介面

`TutorialSystem` 是純前端狀態機，與 `WaveSystem` 的 `holdPreparation(held)` 協作：持有時不遞減準備倒數且 HUD 顯示「等待你的指揮」。`TutorialIntegration` 在遊戲與大廳載入後包裝既有的部署、開波、擊殺、更新和繪製入口，不更動既有戰鬥物件資料格式。

| 模組 | 職責 |
| --- | --- |
| `StoryCatalog` | 宣告 1-1 建議部署座標及首波 `spawnPace: 4`。 |
| `WaveSystem` | 支援可暫停的準備期，並照波次間隔出怪。 |
| `TutorialSystem` | 依序管理 `route`、`deploy`、`ready`、`combat`、`reward`，繪製路線／部署標示與儲存完成旗標。 |
| `TutorialIntegration` | 將教學掛到既有遊戲、大廳與 Wave HUD，不改對外 HTTP API。 |

無資料庫、帳號、網路 API、權限或資料遷移。備份只需照原流程匯出 story profile；此鍵會隨該 profile 一起保留。若要讓同一玩家再次看到引導，在劇情 1-1 按「重玩新手引導」，不必清除瀏覽器資料。

## 安裝、部署、回復

安裝需求和執行方式維持不變。部署時須完整發布 `td.html`、`td-tutorial.css`、`TutorialSystem.js`、`TutorialIntegration.js`、`StoryCatalog.js`、`WaveSystem.js` 與 `sw.js`；版本／離線快取為 `0.85.14`／`sky-strike-v0.85.14`。更新後重新開啟遊戲頁，避免舊 Service Worker 混用舊腳本。

若需回復，使用 Git 回復本版檔案與快取名稱為同一個已發布版本；不要單獨回退 `sw.js` 或只替換一支教學腳本。既有遊戲存檔不必刪除。

## QA 清單

- 劇情 1-1 首波準備期顯示「等待你的指揮」，時間不自行遞減。
- 路線步驟可看見紅色虛線、金色終點與文字提示。
- 部署步驟會打開建造面板、亮起王國獵手與綠色部署圈；未部署不能開波。
- 成功部署後「立即迎戰」高亮；第一波三名長戟衛分段抵達。
- 首波結束出現第 4 步，繼續後其餘波次照原規則運行。
- 跳過與完成都不重複自動顯示；「重玩新手引導」可強制再開一次。
- 執行 `npm test` 及 `npm run check:tutorial`，並以瀏覽器實測上述流程。
