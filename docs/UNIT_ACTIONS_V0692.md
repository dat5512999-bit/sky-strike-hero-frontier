# 0.69.2 守軍與召喚物戰鬥動作

## 使用者操作

照原方式部署單位即可。王國魔法師、王國煉金術師、賞金獵人、海盜砲手會依待機、移動、攻擊與受擊狀態切換動作；流浪鐵匠與時間術士會定期播放鍛造或施法動作。爆破機器人接敵後會先播放蓄爆動作，再造成原有傷害。翡翠古龍、皇家重裝統領與深淵魂鋼魔像也改為完整四格戰鬥動作。

## 實作與架構

`ArtSystem.ACTION_PATHS` 集中管理 11 張透明 4×4 動作表。列順序為待機、移動、攻擊／支援、受擊／收招；現有 `CombatUnit` 與 `Summon` 狀態直接驅動畫格，不新增資料庫或 API。`SpriteFrameBounds.js` 保存一般守軍與機器人的透明邊界；大型終極單位使用固定格表，避免跨格特效被錯誤裁切。

## 安裝、部署與更新

此版本只有本機靜態檔。依既有安裝流程取得專案後開啟 `td.html`，或用既有靜態伺服器部署。PWA 快取名稱為 `sky-strike-v0.69.2`；若仍看到舊圖，重新載入頁面一次讓 Service Worker 啟用新快取。

## 測試

執行 `npm run check` 與 `npm test`。`tests/td-missing-actions.test.js` 驗證 11 張素材、四列狀態選擇，以及重型爆破機器人的蓄爆與爆炸流程。

## 備份與回復

回復到 0.69.1 時，還原 `ArtSystem.js`、`Summon.js`、`SpriteFrameBounds.js`、`sw.js` 與 `package.json`，並移除本文件列出的 11 張 `*-actions-v2.png`。重新載入頁面即可清除舊 Service Worker 快取。玩家本機設定與戰績格式沒有變更，不需還原資料。
