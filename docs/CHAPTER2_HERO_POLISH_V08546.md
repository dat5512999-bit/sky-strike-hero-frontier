# v0.85.46 第二章與英雄戰場修正

## 玩家可見變更

- 西境舊哨（2-1）的荒風隘道改為沿道路流動的兩道淡風痕與小型石路封印。
- 燼火商道（2-2）的煙障改為補給路線上的低透明焦煙、餘燼與燒痕封印。
- 壓力數值與提示仍由波次 HUD 顯示，地圖本體不再顯示旗桿、黑框或重複文字。
- 賽洛與霜牙・凜在戰場上有接地陰影、移動起伏與攻擊前傾；原有臉部、盔甲、武器與動作圖集不變。

## 旋潮領域穩定性

旋潮領域持續六秒、每 0.5 秒結算一次。若裝置掉幀、頁面背景切回或一幀累積過長時間，系統現在不會回放過去遺漏的每一個脈衝；只會結算一個當前脈衝，並由路線前方優先選擇最多 18 個範圍內目標。這避免在高波數將同一幀的投射物與傷害回呼放大到整群敵軍。

## 架構與相容性

- `MapPressureSystem` 只負責地圖上的環境線索；地圖壓力的名稱、規則與波次仍由 `WaveHUD` 讀取同一份 `mapPressure` 設定。
- `HeroRoster.updateFields` 保持所有既有英雄的領域邏輯。娜迦僅新增目標上限與不補算舊脈衝的防護，不改變技能冷卻、半秒傷害頻率或緩速數值。
- `ArtSystem.drawNagaHero` 與 `FrostlandSprites.drawHero` 是繪製層；不會修改英雄位置、傷害、存檔或軍械資料。
- `ArmoryUI` 的販售流程改為 `requestArmorySale` → `confirmArmorySale`／`closeArmorySale`。確認前不會呼叫 `ArmorySystem.sell`；已裝備物品仍無法開啟販售確認。

## 使用者排除方式

若裝置仍顯示舊旗幟或舊版旋潮效果，請重新載入遊戲一次；安裝版會因快取名稱 `sky-strike-v0.85.46` 自動取得新版本。若仍卡住，請在戰況面板提供波次、地圖、英雄與是否剛從背景切回的資訊。
