# v0.85.11 手機排行榜與漸進搖桿

## 需求、原因與設計

- 手機橫向排行榜被擠到左邊：排行榜的 108px 桌面側欄規則覆蓋觸控版單欄，但手機導覽列已移到下方，主內容因而落入第一個窄欄。將側欄規則限定滑鼠裝置，觸控版主內容使用全寬並隱藏會重疊的固定 Logo；導覽、分類與成績列保留至少 44px 點擊高度。
- 左下英雄搖桿過敏：原本離開中心死區便全速移動。改成 20% 中心死區，剩餘推動距離正規化後取 1.5 次方；半推約 23% 速度，外圈 100%，放手即停。只控制英雄移動速度，技能、攻擊、遊戲倍率維持原有計時。

## 使用者操作與 FAQ

1. 在原本使用的瀏覽器開啟 [更新入口](https://dat5512999-bit.github.io/sky-strike-hero-frontier/update.html)，完成後進入 v0.85.11 大廳。
2. 點「排行榜」查看本機自由遠征成績；較長內容可上下捲動，底部導覽保持可用。沒有合格紀錄時會顯示空狀態，不產生假成績。
3. 戰鬥中輕推左下搖桿可慢走，推至外圈可全速移動，放手停止；中央小幅手指抖動不移動。搖桿下方顯示「輕推慢走」。

**為何推一點會慢走？** 推動距離現在決定移動速度；方向仍支援 360 度。

**為何還是舊版？** 結束戰鬥後用同一瀏覽器的更新入口重新取得檔案，不需清除網站資料。排行榜版面問題屬於 CSS 衝突，與玩家存檔無關。

## 架構、資料與 API

```text
FrontierApp → RankingView → td-ranking.css
                            ├─ 滑鼠：側欄 + 主內容
                            └─ 觸控：全寬主內容 + 底部導覽
Pointer events → HeroJoystick（方向 + strength）
               → NavigationSystem（邊界／建築）
               → Hero.setTarget(x, y, speedScale) → Hero.update（只縮放移動步長）
```

- `Hero.setTarget(x,y,speedScale=1)`：新增可選速度比例，限制於 0–1，非有限數回退 1。既有點地、右鍵與拖曳呼叫預設全速。
- `HeroJoystick.strength`：0–1 的暫態輸入；回中歸零，放手、取消或旋轉皆停止，重設不延續上一手勢。
- 不新增資料庫、伺服器 API、依賴或玩家設定；沒有存檔格式遷移，不保存搖桿手勢。

## 安裝、管理、設定與部署

沿用 Node.js 18+ 與 `npm run serve:test`，開啟 localhost 的 `td.html`。管理者不需變更設定。

發布必須包含 `td-ranking.css`、`HeroJoystick.js`、`Hero.js`、`td.html`、`FrontierApp.js`、`BattleReportSystem.js`、`update.html`、`sw.js`；版本為 0.85.11，快取名 `sky-strike-v0.85.11`。推送 main 由 GitHub Actions 檢查並部署 Pages。`artifacts/` 與 QA 產生的示範紀錄不發布。

- `npm run check` 通過；`npm test`：598／598 通過。
- 新增搖桿測試：20% 死區、半推慢走、外圈封頂、120Hz 小時間步、各方向等速、技能計時、回中／放手與恢復點地全速。既有阻擋、取消、多指與死亡測試通過。
- 執行 `node scripts/qa-mobile-ranking.cjs`，啟動本機伺服器後開啟 `/artifacts/mobile-ranking/index.html`。選擇尺寸與空／有紀錄頁面，可看到 `passed`、實測寬高與溢位結果。資料只在記憶體建立。
- 瀏覽器工具不提供觸控媒體條件模擬，QA 產生頁只在複本 CSS 啟用觸控條件、停用滑鼠條件；使用正式 renderer、完整樣式順序及手機旋轉容器。正式 CSS 與玩家資料不受測試頁影響。
- 手機真實觸感仍需實機確認；自動測試驗證位移比例與停止行為。

瀏覽器已確認：手機 667×375、844×390、932×430 的有紀錄頁與 932×430 空狀態皆全寬且無水平溢位；390×844 手機容器旋轉後亦通過。滑鼠模式 960×450、1440×900 保留側欄且無水平溢位。所有觸控情境的主內容底緣均未超過底部導覽上緣。
