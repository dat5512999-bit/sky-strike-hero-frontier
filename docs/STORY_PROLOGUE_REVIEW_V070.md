## 使用與安裝

使用現有專案與 Node.js 18 以上。PowerShell 在專案根目錄啟動：

```powershell
$env:TD_TEST_PORT='4189'
npm run serve:test
```

若 4189 已有本專案服務，直接使用，不重複開。瀏覽本機 `http://127.0.0.1:4189/assets/td/concepts/story-comic-v2/review.html`。請勿直接雙擊 HTML，瀏覽器會阻止直接读取 JSON。伺服器只綁本機回環，不對外公開。

- 用上一頁、下一頁、目錄或方向鍵翻閱，Home／End 到首末頁。
- 點圖或「放大拖看」檢查字與臉；滑鼠拖曳，手機觸控捲動；再次點圖或按 Esc 還原。
- 「逐句文字」顯示當頁圖中文字；長劇本為完整演出規劃，图内對白經精簡，並非遺失檔案。
- 「全螢幕」若遭瀏覽器拒絕，仍可一般閱讀，不會卡住。
- 書籤只用 `hf-story-v2-review-bookmark`；不讀寫正式角色、貨幣、通關或玩家檔案。儲存遭拒仍可讀，但不記頁。
- 末頁標示主線未繪製，不能把「前導審閱完」當全劇情完結。

手机維持橫向。整頁縮放旨在看構圖，不保證手機整頁細字直接可讀；請放大或開逐句。此次只做 Edge 尺寸模擬，尚未真 iPhone Safari 驗證。

## 管理、資料與 API

所有審閱素材集中 `assets/td/concepts/story-comic-v2/`：

```text
prologue-production-v1.json → 12 個來源 PNG ＋完整生成／修圖提示詞
                         ↓ prepare-review.cjs（只轉格式，不修畫面）
review/prologue-01.webp … prologue-12.webp
                         ↑
prologue-catalog.json → review.html → 作者逐頁驗收
```

使用內建 image_gen 產圖與修圖，非 API／CLI。產圖完整提示詞與修圖提示詞、採用版來源已保存於 `prologue-production-v1.json`。`runtimeIntegrated`、`published`、`userApproved` 均為 false；後續不能只改這些旗標就宣稱已部署。

審閱器無後端、無新資料庫、無登入權限或雲端 API。唯一 HTTP 資料為同目錄 `prologue-catalog.json`（version/title/status/pages）；每頁有 id/title/era/image/text/reviewStatus。圖片路徑只允許 `review/prologue-01.webp` 至 `12.webp`，拒絕遠端、越界或重複路徑。文字一律 `textContent`，不執行目錄中的 HTML。每次只預載下一頁，不一次解碼全套圖。

修改對白或圖稿時，同步來源清單與逐句文字；重跑測試再交作者核對。不修改正式遊戲目錄，也不搬到會發布的根目錄。

## 重建與測試

閱讀既有 WebP 不需要 sharp。重新轉圖需要可解析 `sharp` 的 Node 環境；瀏覽器 QA 另需 `playwright` 與 Edge。可使用 Codex 已配置的工作區依賴，或在專案外的工具環境安裝依賴並設定 NODE_PATH；不將個人快取路徑當其他維護者的安裝位置。

```powershell
npm run prepare:story-review
npm run test:story-review
npm run qa:story-review
npm test
```

QA 預設連 4189；不同埠以 `STORY_V2_REVIEW_QA_URL` 設定。轉圖脚本只更新 review 副本，不改 PNG。生成後審查字形仍需人眼，不以自動測試替代。

## 作者驗收清單與後续關卡

1. 遮住年代標題，仍能辨認小商鎮與當代共同城市？

作者驗收之後再決定正式接入；主線繪圖須先鎖定三名英雄原版臉與王子／老王／首相／證人辨認稿。主線不可沿用已停用的人臉，不能省略案發、封存、調查受阻與護證後追捕的順序。AI 複核不是人類專家背書，也不是上班族真人盲測。

## FAQ

**為何遊戲內還是舊漫畫？** 新版目前是獨立審閱，未正式替換；主線 32 頁仍未畫。

**膚色深淺有隱藏劇情嗎？** 沒有這項設定。不同人可有不同膚色；同一人若跨頁變膚色是連續性問題，應修圖，不補編設定合理化。

**黑畫面怎麼辦？** 先看載入狀態，按「重新載入圖片」；失敗仍可看逐句或翻頁。目錄錯誤則檢查 HTTP 服務與 JSON，按「重新讀取目錄」。

**為何手機整頁文字小？** 四格整頁優先保留構圖；細讀用放大與逐句。正式手機整合仍須 Safari 真機驗收，不能以本次模擬結果代替。
