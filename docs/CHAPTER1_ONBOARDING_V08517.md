# v0.85.17 第一章教學操作與聚焦修正

## 使用者流程

《烽火初燃》現在有七個短步驟：看路線、按亮起的「王國獵手」卡、在發光圓心部署、按商城入口、按「職業武器鍛造」完成一次購買、按「立即迎戰」、再學升級與第三波掉落裝備。這些都是實際介面按鈕，不再只靠文字描述。

新手關在教學啟動時補足至 400G；補給只存在這一局，重新開局會重新計算，不影響帳戶、存檔、排行榜或其他任務。商城內的職業武器鍛造會立即強化目前英雄；第三波的獅心王弓仍用來教導士兵裝備。

第一波改為 4 名輕裝斥候，第二波才介紹耐打的長戟衛。已以新手谷地的推薦部署座標 `(680, 415)` 模擬：一名王國獵手可在城門前擊倒一名首波斥候，避免「照做卻看不到成果」的矛盾。

## 介面與架構

教學聚焦會將建造欄、波次控制區、快捷商城列、選取操作區與商城視窗提升到遮罩之上；目標按鈕保持正常亮度、具有外框且可點擊。關閉商城但尚未購買時，引導會安全回到商城入口，玩家不會卡在被關閉的商品提示。

`TutorialIntegration` 只包裝既有的 `queueDeploy()`、`openShop()`、`closeShop()` 和 `ShopSystem.buy()` 事件，`TutorialSystem` 保留流程狀態與顯示。戰鬥、商城價格、裝備規則、HTTP API、資料庫、權限與存檔 schema 均未改變。

## 安裝、部署、回復與備份

完整發布 `td.html`、`td-tutorial.css`、`TutorialSystem.js`、`TutorialIntegration.js`、`StoryCatalog.js`、版本顯示檔與 `sw.js`。版本為 `0.85.17`，離線快取為 `sky-strike-v0.85.17`；更新後重新整理頁面以取得新快取。

回復時一併還原上述檔案與快取名稱。沒有資料遷移；既有故事存檔、裝備、帳戶與備份皆相容。

## QA 清單

1. 確認「王國獵手」、商城入口、商城的職業武器鍛造與立即迎戰在遮罩上方、保持亮度並可按。
2. 在新手推薦點放置獵手，確認首波 4 名斥候可被擊倒；第二波仍有長戟衛作為耐打敵軍範例。
3. 確認開局金幣為 400G，放置獵手後仍可購買 100G 的職業武器鍛造。
4. 關閉商城而未購買，確認引導回到商城入口；購買後確認自動轉到立即迎戰。
5. 執行 `npm run check` 及 `node --test tests/td-tutorial.test.js tests/td-story-maps.test.js tests/td-profiles-story.test.js`。
