# v0.85.48 娜迦戰場可靠性與首領階級曲線

## 交付目標

修正三項會破壞信任或中斷遊玩的問題：新英雄選取肖像錯置、支援攻速沒有可驗證回饋、賽洛 W「旋潮領域」在戰場可能失去回應。同步處理已確認的固定首領後段耐久不足。

## 玩家可見結果

- 選取破潮者・賽洛時，右側資訊卡直接顯示其正式娜迦立繪；不限於娜迦，所有英雄均由自身 `selectionArt` 顯示，不會回退為舊三英雄。
- 深淵祭壇覆蓋範圍內的賽洛與娜迦守軍，在選取卡會顯示「深淵祭壇 攻速 +18%」。選取祭壇會看到「潮衛共鳴：N 名受益」。戰鼓、統領、時間光環也以相同來源機制顯示。
- W 每 0.5 秒只處理當前一次脈衝、前線最多 12 名目標；快速連按不能併發兩個領域。領域仍持續 6 秒、共最多 12 脈衝，數值傷害與緩速不變。
- 第 5、10、15…50 波的首領有獨立等階耐久與護甲，不會與一般怪物共用過低成長；首領後的雜兵波仍刻意較短，作為戰術喘息，而非保證每一波總血量線性增加。

## 實作界線

- `BattleSynergySystem.applyHaste` 僅在最高加速效果取代舊效果時同步記錄來源；不引入疊加、不改存檔。
- `TDGame` 只將既有戰鬥數值轉為可讀 UI；肖像與支援說明不改傷害公式。
- `HeroRoster` 對旋潮設定硬上限，避免背景回復、快速輸入或敵群聚集把同一幀工作量放大。
- `Monster` 僅對 `combatRole === 'boss'` 疊加五波一階的耐久／護甲；一般敵軍、獎勵與波次編成不變。

## 驗收

1. 選娜迦英雄進自由遠征，點選英雄：右側小肖像與選角立繪應一致。
2. 在賽洛與一名娜迦守軍旁建深淵祭壇：選兩位受益者均可見祭壇名稱與 +18%，選祭壇可看到受益數。
3. 對密集敵群連按 W 並切換背景再回來：戰場不停止回應，領域不會重疊，六秒後正常消失。
4. 比較第 5、10、15、20 波首領：每次首領血量皆提高，後段亦提高護甲。
5. 執行 `npm run check`、`npm test`。本專案可能仍有與本版無關的世界觀 Bible SHA 基線失配；不得為使測試全綠而覆寫該基線。
