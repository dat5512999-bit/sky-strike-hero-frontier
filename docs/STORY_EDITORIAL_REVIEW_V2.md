# 漫畫主線重整與交叉審稿

2026-10-10。依使用者要求，由三個 AI 審稿角色分別檢查世界觀、劇本因果、視覺連貫，再由主編整合。本流程不是人類專家背書，也不等於玩家盲測已通過。已確認設定見 WORLD_STORY_REVISION_V2.md。

## 本輪共識

先修劇本，再續畫。問題不是頁數不足，而是讀者尚未看見關鍵事件，角色便已在撤離與遠征。不能依既有 16 個關卡倒推主線，更不能把每關壓成一張六格摘要就宣稱故事完整。

三份獨立審稿一致要求：

1. 雷恩、希爾芙與維菈的遊戲形象及故事身分合一。
2. 改掉中立城被畫成王國首都、古今角色相似、開場已混居的視覺錯誤。
3. 補王子本人被讀者認識、受害現場、疑似暮影線索與傳言變形。
4. 補雷恩合法調查到權力衝突的過程；撤離不是無因的逃亡。
5. 當代暮影長老退出新版敘事；本輪詢問後，使用者已確認維菈為保護族人痛苦決定重啟禁魔，不是審稿者自行轉移責任。

三項作者決策已回覆並完成世界觀覆核：雷恩遭撤權追捕後以小隊護證人撤離；王子現場只有疑似暮影術式且後續發現破綻；維菈承擔解封決定。這只放行大綱與文字分鏡，不自動放行舊圖片。

## 作者決策後的因果覆核

主線推進為：商鎮互助與同址擴建 → 當代王子建立聲望 → 王子受害與疑似暮影術式 → 老王要求調查、雷恩依法查驗 → 痕跡出現不合理處、調查遭阻撓 → 雷恩遭撤權追捕，以小隊保護證人撤離 → 銀葉王在悲痛、表面證據與內部壓力下逐步轉向開戰 → 暮影受攻擊 → 維菈為保護族人痛苦地重啟黑魔法。

調查與銀葉王的轉變需交錯演出，不是等一條線結束才突然切換。真正重新使用黑魔法必須發生在銀葉攻擊之後，不能倒過來替最初的嫁禍背書。

兩場必須細寫的戲：

- **現場第一次對不上。** 讀者先看見疑似暮影痕跡，再看見形成時間的疑點；作者已確認以救援者扶過的屏風與封存記錄新增焦紋來呈現。雷恩要求交叉重查，隨後被具體權限與行動阻止。證人記憶不自動成為客觀答案，不能靠直覺宣布王室有罪，也不新增未核准魔法法則。
- **交權與護送。** 撤權命令當面送達，雷恩先嘗試依程序保護證人；在正常途徑被封死、證人有立即風險之後，才安排少數可信部屬掩護與撤離。讀者須看見選擇的代價，不以追逐場面替代動機。具體罪名與文書內容尚待設計。

## 每場戲的檢查表

編劇需記錄：年代與場所、在場角色 ID、各自想做什麼、阻力、實際行動、改變的事、作者知道／角色知道／讀者知道、下一場為何發生。

同一問句連續出現卻沒有新增證據、代價、關係變化或決策，應刪改；「仍不知道」不能作每關唯一成果。

## 後續放行關卡

1. 設定關：衝突解決、未知與待作者決策分明。
2. 劇本關：每場前因後果完整，英雄身分與能力一致，不強接戰鬥關卡。
3. 分鏡關：先驗收同地點古今對照與人物登場；少量樣頁通過後才批量。
4. 美術關：每頁附 HeroRoster 原版立繪；並排檢查眉眼、鼻顎、髮型、體型、耳／獠牙與裝備。配角不得複製英雄臉。
5. 讀者關：請使用者在遮住姓名時辨認人物、年代與城市性質；這是真正待做的驗收，不由 AI 自稱通過。
6. 遊戲關：只有已通過頁面才加入正式目錄、文字與配樂；再驗證橫向顯示、續讀、載圖、手機操作及不改通關資格。concepts 下的 WebP 僅為獨立審閱副本，不代表正式放行。

重大設定和動機有分歧時，先給使用者少量具體選擇並解釋角色後果，不以票數取代作者決定。沒有使用者回覆時，可整理不依賴該決定的內容，不能把偏好選项自動當同意。
