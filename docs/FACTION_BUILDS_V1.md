# 軍團 Build、傭兵與 Combat VFX V1（0.64.0）

## 產品決策與範圍

目標：不用看傷害數字，也能辨認彈射、印記、召喚、亡魂與爆破；保留既有 Combat、建造、裝備及計分入口。

開發順序為名稱來源盤點 → 搖桿輸入隔離 → 軍團能力資料 → 共用命中／死亡 Hook → 圖集與特效 → 自動測試與瀏覽器驗收。沒有新增後端、資料庫、帳號或 HTTP API。

- 日耀騎士依後段較具體需求保留為友軍衝鋒單位；另外提供敵方失誓日耀騎士。長戟衛與銀葉樹靈改為敵軍，舊 ID 留存但不能招募或解鎖。
- 所有可部署士兵／建築仍永久固定、不能承傷或阻擋。騎士衝鋒、幼龍飛掠使用渲染座標，不改部署錨點。只有既有 Summon 可自動追擊。
- 王國獵手「Lv2 +三發」採每次共三箭解讀：Lv1～Lv5 為 2／3／4／5／6 箭；敵人不足時不重複射同一目標。
- 同兵種無硬性部署上限；每位士兵仍是獨立個體，最多一件獨立裝備，換裝回庫。
- 英雄改名不改能力／數值。這次軍團數值調整只來自明確要求的新定位。

## 已實作的能力

### 王國遠征軍

- 6 位士兵、8 座建築；保留原盾衛，移除長戟衛的友軍入口。
- 王國魔法師：Lv1／2／3 彈射 2／3／4 次，即最多命中 3／4／5 名敵人；Lv3 起附帶 3 秒感電，受傷增加 10%。Lv4～5 不繼續增加跳數。
- 王國煉金術師：低傷害、4 秒易傷；其他傷害來源 +25%，不放大同一位施加者的攻擊。
- 日耀騎士：約 4 秒一次貫穿衝鋒（仍受既有升級攻速影響）；Lv2 聖火持續 2 秒，Lv3 起每次擊殺減少下一次冷卻 0.45 秒。
- 王國火槍手：基礎射程 265、穿甲 8，優先精英、Boss 及支援怪；槍口火光與高速彈道。
- 補給站：170 範圍內部署／升級金幣 -15%，同類取最大值、不疊加；回收按實付金幣計算，避免折扣套利。
- 王國戰旗：附近守軍傷害 +12%。軍械工坊：附近塔傷害 +15%。保留戰鼓堡攻速支援。

### 月影守望者

- 奧術學徒：小範圍魔法與 5 秒奧術印記。
- 月刃哨兵：最多 3 名目標；任一跳命中奧術印記時額外一跳，同次攻擊只加一次。
- 林裔獵手：6 秒自然印記；後續任意非 secondary 攻擊累積 3 次，觸發藤蔓範圍爆發，不再普通緩速。
- 翡翠幼龍：飛掠噴吐；命中自然印記有額外自然爆炸。
- 翠靈古樹：每 6 秒纏繞一群敵人，持續 1.1 + 等級 × 0.1 秒；自然系單位／自然召喚物強化，無常駐巨大光環。
- 月泉稜鏡塔：附近魔法有 25% 機率折射一發、傷害 65%；折射彈不再被折射。
- 森靈馭獸師：本人遠攻，維持一隻森林熊；約 22 秒期滿後再召喚。Lv1 幼熊、Lv2 裝甲熊、Lv3 起古樹巨熊與範圍攻擊；不是狼。現有召喚物不承受敵軍傷害，以時限／擁有者回收控制生命週期。

### 暗影軍團

- 所有合法 Enemy Death 共用 `TDGame.onKill`：英雄、任何軍團、傭兵、召喚物、DOT、爆炸都能產生亡魂。漏怪不算死亡，同一敵人只記一次。
- 亡魂是本局共享資源；選取召喚殿／收割塔／墓園可讀到數量；有收集建築時短暫靈魂飛向建築。
- 幽骨召喚殿：沒有亡魂也能正常召喚。消耗 1 魂使該次召喚傷害 ×1.5，下一次召喚間隔 ×0.65；敵人死亡另減少召喚冷卻 0.35 秒。保留既有單殿召喚容量。
- 冥燈墓園：不生產第二種亡靈，改為附近所有 `summon` 標籤傷害 +25%；亡靈、森林熊、爆破機器人都可受益。
- 瘟疫尖碑：4 秒 DOT、每 0.5 秒結算；死亡可擴散一次，擴散感染不再自行連鎖擴散。
- 靈魂收割塔：範圍內死亡多收 1 魂；射擊時有魂消耗 1，傷害 ×1.8 並產生半徑 48 爆發。沒有魂仍可攻擊。

傭兵仍依既有規則售價為基礎金幣 ×1.5、免木材；成功部署才付款。可招募本軍團未提供的兵種，新增建築型傭兵，不強迫所有契約都變 CombatUnit。商店每張卡有與戰場相同的預覽圖。

V1 的鐵匠是範圍支援，不是參考圖的永久隨機鍛造。海盜是範圍爆破，未增加二次彈跳。這些是先適配既有規則的可測版本。

地精賭徒、瘋狂鍊金師、龍蛋商人、鏡像法師、黑市商人暫不加入：各自需要機率收益、混合狀態、孵化生命週期、攻擊複製邊界或獨立商品系統。避免與既有易傷、稜鏡及商店規則混淆；本版沒有假裝全部圖鑑已完成。

## VFX 架構與預算

沿用 Canvas，沒有 DOM 粒子，沒有重寫 Combat System，也沒有新建第二套傷害事件。

```text
Hero / CombatUnit / Building / Summon
  → Projectile.hit 或既有直接傷害
  → TDGame.onHit → BattleSynergy.hit + CombatFeedback.hit
  → TDGame.onKill（冪等）
       ├─ Economy / XP / Score（原入口）
       ├─ BattleSynergy.onEnemyDeath（魂／瘟疫）
       └─ Corpses + CombatFeedback（死亡／魂飛行）
```

箭、槍、火砲、冰晶、雷弧、月刃、暗影、自然使用不同軌跡。連鎖保留 0.32 秒並逐段顯示；爆炸約 0.6 秒，半徑讀實際 AOE；召喚成形約 0.55 秒後才能戰鬥。暴擊使用火花和約 2px Sprite 微震，沒有頻繁 Camera Shake。普通敵人沿用死亡分格淡出，魔法生物能量消散，Boss 回饋更大更久，機器人以火花爆炸退場。

| 類別 | Desktop | Mobile |
| --- | --- | --- |
| CombatFeedback 總事件 | 140 | 90 |
| 單類傷害／金幣／碎屑 | 30 | 18 |
| 同時魂粒子 | 18 | 10 |
| 同幀召喚成形粒子 | 32 | 16 |
| 既有 Effects | 80 | 50 |
| 聖火繪製條數 | 32 | 16 |

Synergy pulse 上限 100；狀態裝飾每幀最多畫 100 名敵人；屍體沿用上限 60。超量只降級視覺，不能取消傷害、亡魂或召喚。沒有既存 Object Pool／Graphics Quality 設定可接入，故只擴充既有生命週期和預算，不建新設定系統。大量同兵種部署仍可能增加 AI／索敵成本，沒有以兵種數量限制代替效能處理。

## 新素材與限制

`assets/td/faction-builds-v1.png` 是依使用者三張風格參考，以 imagegen 產生的透明角色／建築圖集。`ArtSystem.BUILD_RECTS` 使用實際像素框，避免跨格露出其他單位；更換素材需同步矩形。既有戰鼓堡／古樹圖集也校正了非等分列。

V1 新角色採單張立繪配輕量浮動、朝向與攻擊特效；不是完整逐幀跑步／揮武器動畫。原單位已有的動畫保持使用。正式地圖完全未重畫、未拉伸。

## Mobile Hero Joystick 接入

既有移動：`entities/Hero.js` 的 `setTarget/update` 搭配 `systems/NavigationSystem.js`。既有觸控：`TDGame.attachInput`、`BattlefieldCamera.attach`。新增 `HeroJoystick.js` 只建立短距離方向目標，經 Navigation 邊界／建築檢查，再交給同一 Hero Movement。從不寫士兵座標。

搖桿左下，104～124px、半透明、360°、中心 16% 死區；放手／取消／失焦／旋轉／暫停／換英雄都停止。隔離 Pointer Capture，另一手可使用原技能；空地仍拖圖／縮放，PC 不顯示搖桿。建造或對話框開啟時暫時隱藏。

地圖目前可行走規則是既有世界邊界與建築障礙，沒有獨立森林／水域 walkability mask；本版不憑背景像素新增碰撞規則。若要讓所有視覺河流／山壁也不可走，需另做地圖移動遮罩，不能宣稱目前已存在。

實際驗收、重跑方式與尚未驗證事項見 [0.64.0 QA](RELEASE_V064_QA.md)。
