# 英雄 RTS 元素發展藍圖

## 設計方向

目標是保留縱向射擊的即時閃避，同時加入經典英雄 RTS 的「流派選擇、地圖事件、中立強敵、遺物組合、階段首領」節奏。所有名稱、角色、圖像、音效與世界觀均採原創設計，不複製既有遊戲素材。

## 已完成：戰場事件基礎（v0.6.0）

- 四種難度形成不同資源與敵潮規則。
- 限時獵殺、無傷考驗提供局中次要目標。
- 龍果作為事件限定的高價值獎勵。
- `ChallengeSystem` 已獨立，可再增加護送、據點、精英追獵等事件，不需改寫碰撞核心。

## 已完成：遠征與召喚支援（v0.8.0）

- 100 波／10 章節／每 5 波 Boss 的長線遠征骨架。
- 鏡像僚機與星靈戰寵形成第一批召喚物構築。
- 支援系統與主武器分離，可繼續擴充治療寵、坦克僚機、元素召喚物與召喚天賦。

## 已完成：符文防線（v0.9.0）

- 防線耐久讓「漏怪」成為明確的戰術失敗條件，不再只靠玩家 HP。
- 狂戰、鐵壁、疾射與雙生詞綴形成可預讀、可反制的波次規則。
- Boss 威壓與階段警告延伸英雄 RTS 的首領轉階段節奏，但名稱、美術與數值均為原創。

## 已完成：英雄塔防垂直切片（v0.10.0）

- 獨立守城模式、四種一般怪物與每五波首領；目前正式內容為 15 波。
- 三種可升級／出售防禦塔，形成單體、控制與範圍傷害定位。
- 可移動英雄、自動攻擊、近身攔截與主動霜環技能。
- 金幣、城門生命、漏怪與勝敗讓經濟取捨形成完整閉環。

## 已完成：塔防美術重製（v0.11.0）

- 斜俯視森林峽谷、石板路、水景與花樹取代程式原型背景。
- 三種防禦塔、英雄、五類敵軍與守護城堡均使用同鏡頭、同光源的原創透明資產。
- `ArtSystem` 將正式美術與遊戲規則解耦，未來能增加第二張地圖或主題圖集而不改寫戰鬥邏輯。

## 已完成：人族 TD 職業試煉（v0.12.0）

- 三職業單局鎖定：獵手多重狙擊、奧術範圍魔法、盜賊賞金經濟。
- 固定塔座改為合法草地自由部署，加入道路、邊界與單位距離驗證。

## 已完成：可移動軍團（v0.13.0）

- 人物型守軍由固定塔拆分為 `CombatUnit`，可被選取、移動、轉向與自動攻擊。
- 三職業導入待機、行走、攻擊及受擊／死亡 4×4 原創動作圖集。
- 防禦建築拆分為 `Building`，首批加入林地弩塔、寒霜水晶塔與赤焰火砲塔。
- 單位可進入道路干擾怪物，建築保持禁建規則；後續再加入 A*、框選、巡邏與完整近戰交戰。
- Lv.1～5 成長、金幣／木材／功勳經濟及三攻擊對三護甲相剋。
- 經典 RTS 小地圖、選取資訊與 3×3 指令盤；桌機及手機共享操作邏輯。
- 新增原創人族邊境戰場及三職業人物圖集，不直接使用既有遊戲角色或素材。

## 已完成：戰術指令與尋路（v0.14.0）

- 新增八方向 A* 導航格，人物能繞過已建造的防禦塔，路徑經可視性簡化後以虛線顯示。
- 新增一般移動、攻擊移動、固守與停止，桌面提供 M／A／H／S，手機提供相同的大型按鈕。
- 攻擊移動會停下處理射程內威脅；一般移動維持隊形調度用途，不會因沿途敵人中斷。
- `CommandSystem` 與 `NavigationSystem` 分離，後續可在不改 UI 的前提下加入巡邏、跟隨、框選與編隊。

## 已完成：跨裝置介面（v0.15.0）

- 玩家可在自動、電腦、手機三種塔防介面間即時切換，戰局狀態不會被重建。
- 電腦版優先提供寬版戰場、資訊密度與快捷鍵；手機版優先提供觸控尺寸與三欄指令盤。
- 介面偏好在本機保存，無儲存權限時安全回退自動模式。

## 已完成：塔防波次循環 Phase 1（v0.16.0）

- `WaveCatalog` 將 15 波編成、戰術提示、威脅與獎勵從流程程式抽離，後續增加關卡不需改寫狀態機。
- 選職後先準備與預讀下一波；倒數可自動開波，也可立即開始，清場後才發放資源並進入下一輪整備。
- `EconomySystem` 集中處理擊殺、波次、建造、升級與出售收支，避免重複發獎或開波套利。
- Boss 波總耐久已校正高於前一波。下一階段是讓怪物具備速度、護甲之外的可辨識能力與反制方式。

下一階段建議依序加入：三位原創英雄流派、職業分支科技、帶主動能力的特殊怪物、每五波三選一遺物，以及不同地形的關卡選擇。

## 建議開發順序

1. 英雄流派：每局從「重裝先鋒、風暴術士、遊俠獵手」三種原創流派擇一，各自改變主動技能與果實加成。
2. 天賦三選一：每個里程碑從三個隨機天賦選一個，讓同一流派每局產生不同構築。
3. 中立菁英：地圖側邊出現可選擇挑戰的強敵，擊破後掉落遺物，不阻擋一般敵潮。
4. 遺物與配方：低階遺物可組合成高階神器，介面明示配方進度，避免玩家必須背表。
5. 階段 Boss：依 HP 切換彈幕與召喚模式，擊破後進入下一個戰場區域並選擇永久增益。

## UX 原則

- 戰鬥中選擇最多三項，使用大按鈕與暫停背景，手機也能快速理解。
- 每個新系統首次出現時只顯示一句目標與一個圖示。
- 強力獎勵必須來自清楚的風險或任務，而不是純隨機大量掉落。
- 皮膚保持純視覺；英雄流派與遺物屬於獨立玩法層，避免付費或品牌外觀影響平衡。

## 模組預留

後續建議新增 `HeroSystem`、`TalentSystem`、`ArtifactSystem` 與 `EncounterDirector`。它們透過事件或明確 context 與 `Game` 溝通，不直接互相修改內部狀態；Boss 則延伸現有 `Boss` 實體與 `Collision` 介面。
