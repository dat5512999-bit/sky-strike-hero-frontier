# 英雄 RTS 元素發展藍圖

## 設計方向

目標是保留縱向射擊的即時閃避，同時加入經典英雄 RTS 的「流派選擇、地圖事件、中立強敵、遺物組合、階段首領」節奏。所有名稱、角色、圖像、音效與世界觀均採原創設計，不複製既有遊戲素材。

## 已完成：戰場事件基礎（v0.6.0）

- 四種難度形成不同資源與敵潮規則。
- 限時獵殺、無傷考驗提供局中次要目標。
- 龍果作為事件限定的高價值獎勵。
- `ChallengeSystem` 已獨立，可再增加護送、據點、精英追獵等事件，不需改寫碰撞核心。

## 已完成：遠征與召喚支援（v0.8.0）

- 100 波／10 章節／每 5 波 Boss 的長線遠征骨架。
- 鏡像僚機與星靈戰寵形成第一批召喚物構築。
- 支援系統與主武器分離，可繼續擴充治療寵、坦克僚機、元素召喚物與召喚天賦。

## 建議開發順序

1. 英雄流派：每局從「重裝先鋒、風暴術士、遊俠獵手」三種原創流派擇一，各自改變主動技能與果實加成。
2. 天賦三選一：每個里程碑從三個隨機天賦選一個，讓同一流派每局產生不同構築。
3. 中立菁英：地圖側邊出現可選擇挑戰的強敵，擊破後掉落遺物，不阻擋一般敵潮。
4. 遺物與配方：低階遺物可組合成高階神器，介面明示配方進度，避免玩家必須背表。
5. 階段 Boss：依 HP 切換彈幕與召喚模式，擊破後進入下一個戰場區域並選擇永久增益。

## UX 原則

- 戰鬥中選擇最多三項，使用大按鈕與暫停背景，手機也能快速理解。
- 每個新系統首次出現時只顯示一句目標與一個圖示。
- 強力獎勵必須來自清楚的風險或任務，而不是純隨機大量掉落。
- 皮膚保持純視覺；英雄流派與遺物屬於獨立玩法層，避免付費或品牌外觀影響平衡。

## 模組預留

後續建議新增 `HeroSystem`、`TalentSystem`、`ArtifactSystem` 與 `EncounterDirector`。它們透過事件或明確 context 與 `Game` 溝通，不直接互相修改內部狀態；Boss 則延伸現有 `Boss` 實體與 `Collision` 介面。
