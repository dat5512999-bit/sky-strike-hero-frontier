# 第二章 2-2「燼道相逢」地圖交付 v0.85.42

## 玩家流程

完成 2-1〈西境風號〉後，劇情模式開放 2-2〈燼道相逢〉。玩家使用既有的雷恩與王國軍團守住七波燼火商道，讓荒野小隊的傷者與補給車先安全離開。通關只推進一段可驗證的路名線索；不解鎖荒野部族、戈爾、自由遠征地圖或任何商城內容。

## 戰場與平衡

`ember-road-encounter-v1.png` 是 1536×1024 的正式戰場底圖。`maps.js` 另行定義路線、出生點、城門、可建區、燒毀補給車／岩棚／高台／城門禁建區與手機鏡頭安全範圍，背景像素不參與碰撞。

第 3 波起，補給車旁的「燼火煙障」只作用於指定路段：敵軍獲得 +2 護甲；遭受緩速、冰凍或定身時降為 +1。這是局部、暫態的 `mapPressure`，離開路段立即清除，既有道路、傷害類型、獎勵與存檔資料不變。地圖上有固定旗標，第 3 波前顯示啟動條件，啟動後顯示「煙障 +2甲」；波次預告、進場訊息和敵軍「煙」狀態徽記同步說明規則。

## QA 與回復

`tests/td-story-maps.test.js` 驗證 PNG 尺寸、路線到城門、完整底座禁建、每個合法建點距道路、障礙禁建、故事前置條件、七波任務與手機鏡頭資料。`tests/td-map-pressure.test.js` 驗證第 3 波啟動、+2／受控 +1 護甲與離開路段清除。

本版沒有資料遷移。若需回復，必須同步回復地圖 PNG、`maps.js`、`StoryCatalog.js`、`MapPressureSystem.js`、`Monster.js`、`WaveHUD.js`、狀態呈現、測試、版本標示與 Service Worker；不可只回復單一檔案。
