# 娜迦潮衛・自由遠征 V1

狀態：`AVAILABLE · FREE_EXPEDITION`。娜迦已可直接在自由遠征選擇與使用；此文件仍不改寫《世界觀聖經 V1》，也不會把娜迦插篇視為既有主線劇情完成。

## 故事定位

娜迦在第二章與第三章之間的插篇《潮下引路》先以未知的潮道守衛登場。濁潮小魔王控制水門並扭曲遷徙路線；玩家先對抗怪物、理解其守護意圖，完成盟約後才可能取得軍團。這不是收服奴役，而是從誤解到合作。

## 美術一致性規格

- 共同識別：深青鱗片、海綠鰭髮／鰭冠、古金與珊瑚甲、青藍潮光。
- 英雄固定為賽洛的基礎造型；不是商城造型，軍團僅可共享種族語彙，不能與英雄五官混淆。
- 每名角色有 16 幀：待機 4、移動 4、攻擊 4、技能／受擊／倒下 4。
- 運行引擎使用 4×4 圖集；格線不會顯示在遊戲中。每格必須保留透明安全邊界，長兵器、翼膜與水特效若超界，須拆成特效層或重製圖集。
- `tests/td-naga-prototype.test.js` 驗證透明畫布、16 格有內容、離線快取、資料與軍械相容性。圖集的人工視覺驗收仍必須檢查水特效沒有觸及分格線。

## 武器與軍械

破潮者使用初始 `破潮三叉戟`，並依序鍛造：`珊瑚潮鋼戟` → `深淵潮印戟` → `萬潮王戟`。三階維持既有商店升級流程，累積傷害為 +20% / +40% / +60%。

軍械庫不新增無法使用的掉落：盾、戰鼓給潮汐衛士／破殼者／戰神；遠攻與月銀裝備給翼襲者／潛獵者；破潮者可使用戰鼓。掉落與商店會沿用既有「隊伍中必須有人能裝備」篩選。

## 邊界與發布門檻

### 戰場品質修正（v0.85.44）

賽洛的四個按鍵已有獨立的可測試實作：Q〈潮門突刺〉命中前線敵人並留下潮痕；W〈旋潮領域〉每 0.5 秒造成魔法傷害與緩速；E〈潮衛號令〉必須命中至少一名 220 範圍內的娜迦守軍，讓其 5 秒獲得傷害 +18%、攻速 +18%；F〈萬潮裁決〉以敵群密度選點，首要目標與範圍目標的傷害不同。這些不共用人族、盜賊或通用召喚邏輯。

`tidebreaker-skill-icons-v1.png` 是賽洛的獨立 2×2 HUD／選角圖示圖集；離線快取必須包含它。所有賽洛與五名娜迦士兵動作圖都已寫入 `SpriteFrameBounds` 的逐幀邊界與遮罩，渲染可以跨越原 4×4 格線但會排除相鄰動作，不能再退回等格硬裁切。

效能上，×1 現在是實際一倍模擬；不可再在名稱顯示 ×1 時把怪物、投射物與特效以兩倍更新。×3 在長時間低於約 12 FPS 時會保護性降為 ×2，穩定後再恢復。

### 啟動修正（v0.85.43）

自由遠征的英雄卡現在只更新選擇，使用者點擊「開始遠征」時才以完整的英雄 × 軍團組合啟動。娜迦英雄、五名軍團士兵與四座建築同樣適用；英雄圖與建築圖會預載，載入失敗可由既有「重新載入圖片」流程重試。

同版新增賽洛與娜迦潮衛的獨立選角立繪；既有 4×4 戰場動作圖不再被用作選單背景。破潮三叉戟四個鍛造階段維持既有商店價格與數值，並以三叉戟、潮環與傳說粒子在戰場上區分。第二章 2-1／2-2 已獨立加入自由遠征，並不等於娜迦主線盟約或故事完成。完整邊界見 [v0.85.43 交付](NAGA_CHAPTER2_FREE_EXPEDITION_V08543.md)。

娜迦目前有四座正式可部署建築：潮門尖塔（潮壓標記）、鹽甲棱堡（雙發穿甲）、深淵祭壇（娜迦攻速共鳴）、翼潮獵台（連鎖緩速）；各自提供兩條三級進階分支，並使用獨立高解析建築圖集。

自由遠征不需要先完成《潮下引路》即可使用娜迦；這是使用者確認的直接加入決策。故事模式與主線圖鑑仍不宣稱已完成娜迦盟約。若未來加入插篇，應改為補強敘事解鎖演出，而非收回既有自由遠征資格。
