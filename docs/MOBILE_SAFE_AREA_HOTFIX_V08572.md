# v0.85.72 iPhone 旋轉安全區熱修正

版本：0.85.72 · 日期：2026-09-28。

## 問題與修正

v0.85.71 在直向 iPhone 的旋轉外殼中，從 iframe 寬度扣除 `safe-area-inset-top`，再以位移補償。iOS 會將該縮減映射成畫面上下兩側的空白，導致戰場被裁切。

本版 iframe 一律佔滿實體視窗。外殼量測實體頂端安全區，僅把數值傳給內頁的 `--mobile-shell-system-inset`；內頁因旋轉而在邏輯左側預留空間。這保留完整高度，且不讓時間與電量壓住遊戲按鈕。

## 驗收

1. 在 iPhone 直向開啟時，畫面上下沒有黑邊。
2. 橫向遊戲高度完整，右側與底部控制沒有被裁切。
3. 時間與電量若仍由 iOS 顯示，只能落在左側安全邊，不能覆蓋控制或戰場。
4. 將手機轉為橫向後，安全邊自動歸零，遊戲維持滿版。

## 更新方式

開啟更新頁後關閉所有舊遊戲分頁，再重新開啟主畫面圖示或網址。確認 Service Worker 快取鍵為 `sky-strike-v0.85.72`。此修正不會變更玩家資料；如需回退，回到 Git commit `29b053f`。
