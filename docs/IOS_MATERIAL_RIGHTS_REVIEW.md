# iOS 素材來源與商用依據審查

2026-11-03，素材審查工具 v1.0.0。針對本次發布規劃內的全部 569 個媒體建立逐檔清單；另外記錄程式合成配樂／音效。完成的是來源與證據整理，不是第三方權利人的授權書或無侵權法律保證。遊戲素材本輪沒有刪除、替換、下架或改名，也沒有對外寄信。

## 目前結論

使用者已於本聊天直接確認：本專案圖片及生成參考圖沒有使用其他遊戲、網路下載或委託外包圖片，都是本專案生成或自行繪製。此聲明已寫入 `native/ios/rights-evidence.json`，並附到全部 564 個圖片項目；不套用到外部供應商生成的五個 WAV。

| 類別 | 數量與結果 | 處理方式 |
| --- | --- | --- |
| 圖片 | 564 個，使用者確認來源為專案生成／自繪 | 保留現有素材，保存生成紀錄與工具條款；不用因缺少檔名索引就整批重畫 |
| 戰牛配音 | 5 個，供應商公開頁面明示生成音訊可商用 | 保存聲明、原台詞、音色代碼與處理紀錄；供應商聲明不等於完整上游權利保證 |
| 劇情配樂 | StoryMusic 內九組程序主題，不是另九個音檔 | 已核對和弦、旋律與 Web Audio 合成程式及既有製作文件，沒有外部歌曲素材 |
| 戰鬥合成音效 | GameAudio、CharacterAudioMaterials、BullAudioMaterials 程式來源 | 與配音 WAV 分開記錄，不誤套配音供應商授權 |
| 商城封面視覺檢視 | 8 張跨界造型封面 | 沒有辨識到可直接確認的第三方標誌；仍不宣稱檢視過所有動作格或排除一切相似性 |

不把任何圖直接判為侵權，也不將 AI 生成直接判成無權商用。使用者的來源聲明解決了是否混入外部圖片這個問題；逐檔工具紀錄的保存與日後被詢問時的舉證仍是另一件事。

## 已核對的條款

[Voice-Generator 中文工具頁](https://voice-generator.com/text-to-speech/chinese) 明示生成語音可用於商業用途；[其服務條款](https://voice-generator.com/terms) 表示不主張輸入內容的所有權，頁尾提及 Kokoro 與 Apache 2.0。專案 manifest 記錄音色 `zm_yunjian`、原台詞與後製參數，但供應商網頁未把該音色逐一對應到上游權利。這是仍存在的供應鏈證據限制，不是已確認有侵權。App 內只包含五個生成 WAV，沒有因而取得或散布模型權重，也不能自動推定模型授權必須套用到輸出。

[OpenAI 個人服務條款](https://openai.com/policies/terms-of-use/) 與 [Services Agreement](https://openai.com/policies/services-agreement/) 均在雙方之間、法律容許範圍內將輸出權利歸使用者，同時要求使用者對輸入素材有權利，並說明輸出可能相似。這提供使用生成素材的條款依據，不能代替第三方角色、商標或外部參考圖授權。實際適用條款取決於生成當時的帳號、服務與地區；本輪核對現行條款，不捏造歷史合約或帳號付款證明。

供應商聲明與網頁核對日期為 2026-11-03。沒有代用戶對外聯絡供應商、簽署保證或取得額外合約。若日後有人提出具體權利爭議，應對照原圖與生成紀錄個別處理，不以本報告當作法律意見。

## 每個素材的證據狀態

擴大搜尋 docs 與 assets 的 JSON／Markdown 製作資料後，569 個媒體依直接檔名對應分類：

| 狀態 | 數量 | 含義 |
| --- | --- | --- |
| provider-permission-found | 5 | 配音供應商有商用聲明 |
| production-record-found | 90 | 路徑出現在 prompt／manifest 製作紀錄中；也可能是參考圖，不代表已確認該檔的生成者 |
| documentation-found | 88 | 找到一般文件中的明確檔案引用 |
| source-evidence-needed | 386 | 尚無直接檔名對應；圖片已有使用者的專案來源聲明，不等於斷言來源不明或無授權 |

這些分類彼此互斥、合計 569，但圖片來源聲明是另一個維度，覆蓋全部 564 個圖片。名稱不完全相同的裁切、縮圖、轉檔不會被工具自動推定為同源；接下來應補檔名對應，避免把同一生成來源重複要求證明。舊工具只對八份選定 JSON 比對而得到 38 個命中，是較小搜尋範圍的歷史值。

完整逐檔報告在 `artifacts/ios-compliance/content-audit.json`，包含路徑、位元組數、SHA-256、來源聲明、文件證據路徑／雜湊、具體下一步與視覺檢查狀態。素材或證據變更後要重新執行工具；八張封面的 SHA-256 改變時，舊視覺檢查會標為非目前版本，不會繼續沿用。

## 重現與管理

```text
npm run ios:audit
node --test tests/ios-rights-review.test.js
```

工具不下載素材或修改玩家存檔，也沒有新的網路 API、資料庫或執行期依賴。`scripts/ios-rights-review.cjs` 把擴大證據搜尋、使用者聲明及視覺檢查掛到既有 audit；`native/ios/rights-evidence.json` 保存核對結論、來源與限制。新增素材會進入清單，但不會因同名、文件提到或使用者聲明而自動變成 releaseApproved。

本輪全套 1,198 項測試通過，包含：供應商／製作紀錄／缺檔名索引分類、圖片聲明不誤套到配音、檔案變更後舊檢查失效，以及八張實際檢視封面的雜湊和程序音效來源存在。網站與 iOS 遊戲內容未改，無須因本輪報告重打約 879 MB 資源包。

## 送審與回復

本工具保留 releaseApproved 為 false，表示它不會代發行者或權利人簽署核准，並非斷言 569 個素材都不能商用。發行前保存使用者來源確認、原生成／繪製檔、適用條款及配音紀錄；未來新增網路素材或外包內容須另附許可，不可套用本次聲明。若要求完整法律意見或發生具體爭議，需交由合格專業人員評估。

正式發布仍受 [iOS 上架準備](IOS_RELEASE_PREPARATION.md) 中的 Mac 建置、真機驗收、發行資料及隱私申報限制。原始素材沒有刪除，回復本輪僅需還原審查工具／紀錄，不涉及進度遷移。報告可由指令重建；本輪未提交、推送或送審。
