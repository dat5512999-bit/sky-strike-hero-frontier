# v0.72.0 戰局統計第一階段

## 產品目標

在只有一名主要測試者的階段，把主觀感受轉成可比較的本機資料。此版本只建立觀測能力，不調整塔價、升級曲線、擊殺賞金、清關金、敵人或積分。

## 記錄內容

- 每波開始與結束：金幣、木材、城門、軍備數量、等級分布、滿級數量與實際總投入。
- 全局投入：成功部署、成功升級、商店消費；失敗或取消操作不計。
- 戰鬥貢獻：依英雄、士兵、塔與召喚物統計實際有效傷害及擊殺。
- 戰後訊號：擴軍／升級投入偏向、單一傷害來源過度集中、滿級軍備數量。

訊號只提示值得複測的現象，不宣告某種玩法錯誤，也不直接推薦唯一配置。

## 資料與隱私

沒有伺服器、帳號、Cookie 或網路遙測。資料隨既有戰績保存在瀏覽器 localStorage；清除網站資料會移除紀錄。既有 V3 戰績可直接讀取。

## 測試方式

分別用擴軍型、核心升級型與混合型完成多局，固定地圖、難度、英雄與軍團後比較結果。至少累積三局再提出數值假設，並以人工遊玩確認節奏與樂趣。
