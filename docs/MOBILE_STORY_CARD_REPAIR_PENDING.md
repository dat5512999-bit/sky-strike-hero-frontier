# 手機劇情閱讀畫面修正（待發布）

## 範圍

本修正只套用到 `td-mobile.html` 轉向容器，以及手機模擬預覽中的「戰前劇情卡」。戰場、大廳與既有橫向遊戲流程不改成直向。

## 玩家可見結果

- 直式握持手機時，內層遊戲仍以橫向顯示；劇情卡會填滿該橫向遊戲區，不再停在中央的狹窄桌機卡片。
- 劇情圖片鋪滿舞台；文字維持在左側暗色可讀區，角色構圖保留在右側。
- 頂端大廳列在閱讀劇情時隱藏；下方保留章節進度、返回與下一幕按鈕，並使用瀏海／底部安全區留白。

## 技術與驗收

- `td-lobby.css` 以 `data-mobile-shell`／`data-mobile-preview` 明確覆寫劇情卡的桌機最大寬度，改為 100% 寬高的兩列 grid。
- 2026-09-28：`node --test tests/td-prologue-cinematic.test.js` 19/19 通過；`npm run check` 通過。
- 本機 iPhone 直式外殼驗證：內層劇情卡計算為 `display:grid`，寬度 100%、高度 100%，劇情舞台與底部操作列分列顯示。
