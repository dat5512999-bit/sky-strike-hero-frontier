# v0.85.27 第一關教學擴充

## 玩家流程

第一關現在以十四個短步驟帶玩家完成完整的一局核心循環：

```text
道路與城門 → 金幣／木材用途 → 部署獵手 → 商城武器
→ 倒數與提前開戰 → 第一波實戰 → 選取／升級
→ 第二波敵軍預告 → 召喚援軍 → 第三波戰利品 → 配裝
→ 回收用途與安全解鎖 → 自由完成第四、第五波
```

資源與敵軍預告是閱讀提示，不會要求玩家做無意義點擊。第二波會提示「召喚援軍」的用途；技能可直接試用，但不是進入第三波的門檻，玩家按「立即迎戰」或倒數結束都能繼續，避免新手誤以為戰鬥當機。

第三波的獅心王弓仍會要求領取與裝上。接著說明回收可取回部分金幣以重整防線，但在教學最後一步前保持鎖定，避免唯一示範獵手被賣掉。

## 可見性與介面規則

教學黑幕絕不覆蓋玩家需要操作的目標：一般按鈕、商城品項、戰利品與裝備會暫時移到黑幕的上層；戰場選取士兵則使用「圈外變暗、圈內原亮度」的挖洞式遮罩。技能步驟只保留亮起的「召喚援軍」可操作，其餘技能鍵不會誤觸。

這些聚焦層皆保留原按鈕的事件與位置。引導完成、跳過或例外收尾時，元素會回到原本版面，並釋放波次等待與暫停狀態。推薦部署點位於中央 U 形彎道內側、玩家指定的平坦草地（680, 415）；該點已驗證士兵與塔皆可部署，且獵手射程確實覆蓋道路。

## 架構、資料與維護

`TutorialSystem` 管理步驟、波次等待、回收鎖與聚焦畫面；`TutorialIntegration` 包裝既有英雄技能呼叫，成功施放時會收起提示，但不會攔住開戰。沒有新增資料庫、HTTP API、權限或存檔 schema；完成狀態仍存於既有瀏覽器儲存鍵。教學儲存鍵已升為 `chapter1-border-onboarding-v3`，因此已完成舊版引導的玩家會在下一次進入 1-1 時看到新增的掉裝與配裝流程一次。

部署需要同步發布 `TutorialSystem.js`、`TutorialIntegration.js`、`td-tutorial.css`、版本檔、`package.json`、`update.html` 與 `sw.js`。離線快取名稱為 `sky-strike-v0.85.27`。若客戶端仍顯示舊版，開啟 `update.html` 後再重新整理。

回復時應同時還原上述檔案與快取版號，避免 UI 與快取版本不一致。

## QA 清單

- 所有被要求點擊的按鈕、資源列與士兵均保持明亮，且黑幕不攔截目標點擊。
- 第一波後可選取獵手並進行升級說明；回收保持鎖定。
- 第二波預告後，召喚技能可試用；不按技能時「立即迎戰」與第三波倒數仍能正常運作。
- 第三波可完成戰利品、裝備與回收說明；完成或跳過後第四波繼續正常倒數。
- 執行 `node --test tests/td-tutorial.test.js tests/td-story-maps.test.js tests/td-profiles-story.test.js`、`npm run check:tutorial` 與 `git diff --check`。
