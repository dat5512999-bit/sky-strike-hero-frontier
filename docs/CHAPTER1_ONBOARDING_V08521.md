# v0.85.21 第一章選取、升級與暫停收尾

## 玩家流程

第一波結束後，教學先以不會擋住點擊的亮色光圈框住已部署的王國獵手。玩家點選他後才會出現並高亮升級按鈕，建立「選士兵 → 看資訊 → 升級」的正確心智模型。直到玩家完成升級或按「暫不升級」前，回收按鈕與回收行為都被鎖住，避免唯一示範單位被賣掉。

第三波結束時會暫停，因為軍械波在等待玩家選擇戰利品；提示明確說明原因與下一步。領取獅心王弓並完成配裝，或按跳過引導時，系統會關閉教學開啟的戰利品／配裝面板、清除黑幕並恢復下一波倒數，玩家不會留在「已暫停」狀態。

獵手卡移到黑幕上層時會保留它原本 Canvas 預覽，不會再額外加上第二個圖示。

## 架構與 API

`TutorialSystem.positionUnitFocus()` 將單位的地圖座標換算成固定的螢幕光圈；`onUnitSelected(hunter)` 才能前進到升級。`TutorialIntegration` 在 `updateUi()` 後觀察既有選取結果，且包裝 `BuildSystem.sell()`，僅在教學鎖定期間拒絕回收。

```text
第一波結算 → 光圈指向獵手 → 玩家選取獵手 → 高亮升級
      └─ 回收鎖住，升級或略過後解除

第三波結算 → 戰利品暫停 → 領取／配裝，或跳過 → 關閉教學彈窗 → 下一波倒數
```

`dismissTutorialModal()` 僅處理由教學引導開啟且仍可見的戰利品或配裝面板，恢復各自開啟前的暫停狀態。不新增 HTTP API、資料庫、權限或存檔 schema。

## 安裝、部署、回復與 QA

需求為 Node.js 18+ 與既有靜態站流程，沒有新增套件。部署需同時發布 `TutorialSystem.js`、`TutorialIntegration.js`、`ArmoryUI.js`、`td-tutorial.css`、`StoryCatalog.js`、`td.html`、`update.html`、`package.json`、版本顯示檔與 `sw.js`；快取名稱為 `sky-strike-v0.85.21`。更新後重開遊戲；舊畫面仍在時以 `update.html` 更新快取。

此版沒有資料遷移。回復時同時回復上述檔案與快取版號，勿只回退單一教學檔案。

驗收項目：獵手卡只有原始 Canvas 圖示；第一波後光圈覆蓋實際獵手、點選後才出現升級；回收不可按也不可透過邏輯呼叫；第三波暫停說明清楚；完成與跳過均會關閉教學面板並恢復倒數。執行 `node --test tests/td-tutorial.test.js`、`npm run check`、`git diff --check`，並以「重玩新手引導」實玩桌機與手機橫向版面。
