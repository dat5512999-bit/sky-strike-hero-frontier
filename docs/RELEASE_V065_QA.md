## 實作與限制

- 同源橫向 iframe 讓瀏覽器處理旋轉後的觸控座標；旋轉不重建遊戲，不要求方向鎖定權限。

- 拖曳預覽同步確認位置；合法位置與足夠資源仍由 BuildSystem 驗證。確認／升級觸控事件只執行一次。
