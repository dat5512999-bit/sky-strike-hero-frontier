# v0.85.52 娜迦塔樓潮汐特效統一

## 目的

潮門尖塔原本的 `tidebolt` 在高速移動時會收斂成一個單色藍色箭頭；鹽甲棱堡與翼潮獵台也仍共用過於通用的潮汐輪廓。本次讓所有娜迦塔都有專屬、可讀的潮汐演出，只替換 Canvas 呈現，沒有修改任何戰鬥數值。

## 玩家可見結果

- 潮門尖塔：三叉水刃核心、雙旋潮尾跡與命中三叉水冠。
- 鹽甲棱堡：三枚並行的重叉與兩道壓力環，表現雙叉拒馬的穿甲重量。
- 翼潮獵台：飛行中為翼形水刃，連鎖時每次彈射展開成雙翼潮鰭，而非細線加圓點。
- 深淵祭壇：沒有直接普攻；改以低頻的三枚浮游潮環表現它持續對範圍內娜迦單位的攻速共鳴。

## 架構與效能

`Projectile.draw()` 依 `tidegate-bolt`、`tide-bastion-spear`、`tide-manta-chain` 分別繪製三座攻擊塔；賽洛仍使用原本 `tidebolt`。`NagaArt.drawBuilding()` 只為深淵祭壇增加純視覺共鳴環。移動、目標選擇、傷害、潮壓易傷、命中回呼、戰報、攻速共鳴數值與特效預算均維持既有流程。

## QA 與還原

- `node --test tests/td-vfx.test.js`：驗證潮門彈體包含水叉、尾跡與水粒子，命中有獨立水冠。
- `npm run check` 與 `npm test`：確認語法與既有戰鬥回歸。
- 若需還原，只回復 `src/td/entities/Projectile.js` 的 `tidebolt` 專屬繪圖分支與對應 VFX 測試即可；不涉及玩家存檔、資料遷移或戰鬥平衡資料。
