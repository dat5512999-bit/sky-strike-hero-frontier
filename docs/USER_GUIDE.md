# 使用者操作手冊

## 開始遊戲

雙擊 `index.html`，以 Chrome 或 Edge 開啟，選擇外觀包後按「開始任務」或 Enter。

## 外觀包

- 經典戰機：科幻戰機、雷射與入侵者。
- 歡樂速食：飲料杯戰機，交替發射漢堡與薯條，敵人為花椰菜。
- 貓咪中隊：貓咪戰機，發射肉球與小魚，敵人為毛線球。
- 糖果星球：糖果火箭、棒棒糖／糖果彈與酸糖敵人。
- 深海巡航：深海艇、泡泡／海星彈與水母敵人。
- 紙上作戰：紙飛機、鉛筆／橡皮擦彈與紙團敵人。

選擇會保存在目前瀏覽器的本機儲存空間。若瀏覽器禁止本機儲存，遊戲仍可玩，但下次會回到預設外觀。

## 操作

- 移動滑鼠：戰機以平滑速度跟隨游標。
- 自動射擊：無需點擊。
- Esc：暫停／繼續。切換到其他視窗也會自動暫停。
- Enter：在開始或任務失敗畫面開始遊戲。

## 遊戲目標

擊中普通敵機兩次可將其擊破並獲得 100 分。玩家初始有 3 HP；與敵機碰撞會失去 1 HP，受傷後短時間閃爍且不會再次受傷。HP 歸零後可重新開始。
