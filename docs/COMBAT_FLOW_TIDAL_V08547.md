# v0.85.47 戰鬥流暢與潮汐特效交付

## 目的

本版處理實戰中「怪物一個停、整列都停」與英雄移動卡在攻擊／施法收勢的問題，同時讓娜迦攻擊視覺與潮汐陣營一致。這是呈現與操作修正；敵軍血量、波次、獎勵、技能傷害、控制時長和軍械數值均未調整。

## 玩家操作與可見結果

- 點地面移動英雄，或持續推動手機搖桿時，英雄會立刻取消正在準備的普攻與施法，朝指令位置移動；停止後才重新自動索敵。
- 一般怪物攻擊英雄時仍會放慢並播放攻擊姿勢，但不再原地把整條隊列堵死。定身、冰凍、根纏與首領明確蓄力技能仍可完全停止行軍，保留策略判讀。
- 娜迦的潮門尖塔為潮箭、鹽甲棱堡為潮叉、翼潮獵台為曲線潮線；賽洛普攻與二、三階三叉戟鍛造也使用潮汐軌跡和命中濺浪，而不是雷電折線。

## 架構與效能

- `Monster` 僅改變攻擊中的移動步幅；根纏與首領技能仍由既有控制狀態決定停止。
- `TDGame` 的隊列在單路以路程排序，在雙路匯流後以剩餘路程排序。接近時先降速，最小安全距離則禁止穿入前一個模型。
- `Projectile` 的潮汐樣式只改繪圖分支。每幀先由遊戲設定特效預算：手機 48、桌面 96。預算不足只跳過裝飾性漣漪／鏈線，投射、命中、傷害、連鎖與狀態計算照常執行。
- 沒有新增 API、網路請求、帳號欄位或資料庫遷移；現有 Profile 與戰報可直接使用。

## 驗收清單

1. 使用娜迦英雄進入自由遠征，連續移動英雄穿過敵群：英雄不應等三叉戟攻擊或施法結束才移動。
2. 觀察普通怪物攻擊英雄：隊列維持前進且不重疊；首領蓄力、冰凍和根纏仍會明確停住。
3. 在雙隘口讓兩路敵軍合流：怪物不重疊、不倒退，並可到達城門一次計入漏怪。
4. 建造娜迦潮門／鹽甲／翼潮塔，確認彈道與連鎖呈水色潮線；切換到大量怪物與手機時，傷害與波次仍正常結算。
5. 執行 `npm run check` 與 `npm test`。目前專案另有一項既存的世界觀 Bible 雜湊基線不符；它不由本版檔案修改，詳見測試輸出。

## 更新、還原與疑難排除

- 線上更新後若仍顯示舊版本，從遊戲設定啟動離線更新復原流程，等待顯示 `v0.85.47` 後重新進入戰場。
- 版本以 Service Worker 快取鍵 `sky-strike-v0.85.47` 區隔；不會覆寫玩家存檔。要回到先前程式版本，部署前一個已知版本的靜態檔與其對應 Service Worker 即可，Profile 資料無需回復。
- 若只在特效密集時感到掉幀，可在戰鬥設定開啟「減少裝飾特效」；這不會降低傷害或控制效果。
