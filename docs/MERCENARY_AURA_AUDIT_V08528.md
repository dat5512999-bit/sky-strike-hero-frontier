# 傭兵上架與增益盤點（v0.85.28）

## 本版範圍

- 傭兵館新增：冰原狼人 113G、極凍鳥 218G、連發火器手 173G、鉚釘重射手 225G。價格為原始金幣成本的 1.5 倍向上取整，且不消耗木材。
- 自己軍團的兵會隱藏；成功部署後固定在場、可升到 Lv.5，回收規則與既有傭兵相同。
- 地精選兩名 `networkCost: 1` 的射手：無電仍可戰鬥，供電才加 +22% 傷害；不販售需要完整電網才能開火的重型機偶。

## 軍械相容性

商城現在把「已部署傭兵」與目前軍團一起納入軍械可用性，避免已上場卻不能購買可穿戴裝備。

| 傭兵 | 可購買並裝備的軍械 |
| --- | --- |
| 冰原狼人 | 先鋒戰鼓 |
| 極凍鳥 | 月銀古杖、常青冠冕 |
| 連發火器手 | 獅心王弓 |
| 鉚釘重射手 | 獅心王弓 |

每種軍械均維持最多購買三件的既有規則；傭兵不會改寫掉落池或永久解鎖狀態。

## 結論與後續建議

戰鬥數值部分已逐一確認會寫入 `CombatUnit.config()`、`Building.config()`、`Summon.update()` 或英雄投射物結算；範圍外、退休／出售與時效結束後也會移除。

不過「每一位受益者都能一直看出來」尚未完全成立：傷害類光環、荒野脈衝與霜原效率只使用短暫或來源特效；同一刻超過 16 名受益者時，短暫光圈也會被效能上限截斷。這正是實玩時容易以為沒有吃到 BUFF 的原因。

若要改善，下一版應統一在單位腳下保留小型、可疊加但不遮擋模型的狀態環／圖示，並在選取面板列出「來源、+% 與剩餘秒數」；這是可讀性改進，未改動本版平衡值。

## 驗收與回復

已通過針對傭兵、軍械、霜原、地精與既有光環的 77 項測試。全套測試目前有一項既有新手教學流程測試失敗（流程步驟預期為 `deploy`，實際為 `resources`），與本版傭兵／增益變更無關，未在未授權範圍修改。

回復時還原 `td.html` 的四張傭兵卡、`src/td/systems/ShopSystem.js` 的已部署對象判斷、相關測試與版本檔；沒有資料庫或存檔遷移。
