# 跨界造型第一季（v0.85.74）

## 玩家內容

- 商城新增四套可購買、可裝備且只改變外觀的英雄造型：霜牙・凜的「北境搜救犬」、破潮者・賽洛的「深淵應變員」、戰神・奧魯姆的「鋼鐵工頭」，以及銅齒・奇克的「特勤維修兵」。
- 霜原、娜迦與地精各使用 4×4 的透明戰場動作圖；戰牛使用 5×5，因此也具備至少四格的完整待機、移動、攻擊與施放演出。
- 商城購買後按「裝備」，再進入遠征即可在選角與戰鬥中看到同一套外觀。造型不影響傷害、技能冷卻、裝備相容性、怪物、掉落或排行榜。

## 架構與維護

- `SkinCatalog` 是售價、目標英雄及商城封面的單一資料來源。
- `CrossworldSkinArt` 只攔截三名採用 4×4 圖集的英雄；沒有裝備、素材尚未載好或發生載入錯誤時，會回到原軍團渲染器。
- 戰牛保留既有的獨立 5×5 渲染器，只依已裝備的 `steel-foreman` 切換圖集。
- Service Worker 改為 `sky-strike-v0.85.74`，並預快取八張新素材及渲染模組，避免舊 PWA 快取蓋掉新版。

## 驗收與還原

執行：`node --test tests/td-crossworld-skins.test.js tests/td-cosmetic-shop.test.js tests/td-bull-wargod.test.js`。

若要還原，將商城四個 ID 從 `SkinCatalog.js` 移除，撤除 `CrossworldSkinArt.js` 的載入與快取條目，並將版本與快取名稱回復到上一個已發佈版本；玩家已存的未知造型 ID 會由既有商店存檔驗證安全拒絕，不會修改戰鬥資料。
