# v0.85.49 旋潮領域防當機熱修

## 問題與修正

先前即使限制了目標數，W 仍為每個命中目標執行完整投射物命中鏈。任一特殊敵軍、命中回呼或 Canvas 繪製例外都可能從主更新／繪製函式往外拋出，讓下一個動畫影格無法排程，表現為整個戰場當掉。

本版將旋潮改為獨立範圍脈衝：每 0.5 秒最多 12 個前線目標，直接沿用魔法傷害、緩速、命中、擊殺和戰報回呼，不建立投射物。傷害／半徑／六秒持續／12 秒冷卻不變。

脈衝結算與地面繪製分別隔離例外。若仍遇到未預期資料，僅旋潮安全終止並顯示提示，戰局、資源、波次與其他技能繼續運作。

## 驗收與還原

1. 在密集敵群按 W，連續移動英雄、切到背景後切回，戰場必須持續運作。
2. 若顯示「旋潮領域已安全中止，戰場仍可繼續」，請提供版本、地圖、波次與操作順序；此訊息代表已避免整局卡死。
3. PWA 應更新為 `sky-strike-v0.85.49`。本版無存檔遷移；還原時程式與 `sw.js` 快取鍵一起回復。
