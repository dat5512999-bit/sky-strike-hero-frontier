# 士兵軍械購買導引 v0.85.66

## 使用結果

選取一名已部署士兵，按選取快捷列的「裝備」。畫面現在只會列出該士兵實際相容的軍械：已持有的物品可直接裝上；尚未持有的物品會顯示「可購買」與當前價格，按「前往商店」即可跳到對應商品。商店會以綠色標記並寫出「✓ 適用目前選取」，其餘商品明示不適用目前士兵。

這解決了軍械庫為空時只顯示「沒有裝備」、卻不告訴玩家該買什麼的問題。士兵仍維持一件軍械上限；英雄維持武器、護甲、戰器各一件的原有規則。

## 設計與資料來源

相容規則的唯一來源仍是 `ArmorySystem.ITEMS` 的 `types`／`heroes`，沒有新增平行相容表或存檔欄位。`ArmorySystem.compatibleItems(target)` 將相容清單提供給選取卡和配裝畫面；`ArmoryUI` 將清單對應到既有 `ShopSystem.ITEMS` 商品；`TDGame` 則在商店依目前選取單位標示適用性。

部分特殊支援或傭兵目前沒有定義相容軍械時，配裝畫面會明確顯示「沒有可使用的軍械」，不會推薦無效商品。這版不自行新增軍械或改寫其戰鬥數值。

## 驗收、部署與回復

驗收執行 `node --test tests/td-armory-flow.test.js`、`npm run check`、`npm test`。手動驗收至少選取遊俠與盾衛：遊俠看到獅心王弓；盾衛看到不落獅盾與先鋒戰鼓；點選「前往商店」後只有相容商品標成綠色。桌機和手機橫向都必須可讀、可點。

部署需包含 `ArmorySystem.js`、`ArmoryUI.js`、`TDGame.js`、`td.css`、`td.html`、版本檔和 `sw.js`，快取名稱為 `sky-strike-v0.85.66`。本版不遷移或清除玩家資料；如要回復，先匯出玩家備份，再完整回到 v0.85.65 與 `sky-strike-v0.85.65`，不可只回退其中一個介面檔。
