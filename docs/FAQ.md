# FAQ

## 雙擊後只看到空白畫面？

確認 `src` 資料夾與 `index.html` 位於同一專案根目錄，並按 F12 查看 Console。建議使用目前版本的 Chrome 或 Edge。

## 為何不用滑鼠點擊射擊？

依核心玩法，戰機會自動射擊，玩家專注於移動與閃避。

## 為何還沒有道具、Boss 或多種武器？

目前版本刻意只交付 Phase 1。這些功能已有模組擴充位置，將在指定 Phase 實作。

## 遊戲離開視窗後為何暫停？

為避免玩家因切換視窗受到不可控傷害，視窗失焦會自動暫停。

## 可以調整難度嗎？

開發者可修改 `src/config.js`；正式的使用者難度選項不屬於 Phase 1。

## 可以加入真正的品牌主題嗎？

技術上可以，外觀包介面支援獨立品牌模組。公開或商業發行前必須取得商標、角色、包裝、圖像和音效的使用授權；未授權時建議像「歡樂速食」一樣採原創名稱與造型。

## 皮膚會改變攻擊力嗎？

不會。所有皮膚共用相同碰撞箱、射速與傷害，只替換視覺，確保公平。

## GitHub 上有檔案，為何網址不能直接玩？

Repository 檔案頁不是遊戲網站。需在 Settings → Pages 選擇 GitHub Actions，等待 Pages 工作流程成功，再開啟 Pages 提供的網址。

## 手機拖曳時為何戰機不會直接跳到手指下？

這是刻意的相對拖曳設計，讓手指可放在戰機旁邊，避免遮住敵機、子彈與玩家。

## 離線為何第一次不能玩？

Service Worker 必須先在線上完整下載一次必要資產。直接雙擊檔案不會啟用離線快取；需由 HTTPS 網站（例如 GitHub Pages）開啟。

## 為何一開始不立刻出現射擊敵人？

威脅採漸進解鎖，先讓玩家熟悉移動與果實，再加入追蹤與瞄準彈。每 12 秒升一級，第一分鐘內會看到全部五種敵人。

## 為何換皮膚後技能仍相同？

皮膚只管理視覺；果實、傷害與難度是獨立系統，避免特定外觀取得玩法優勢。
