# FAQ

## 雙擊後只看到空白畫面？

確認 `src` 資料夾與 `index.html` 位於同一專案根目錄，並按 F12 查看 Console。建議使用目前版本的 Chrome 或 Edge。

## 為何不用滑鼠點擊射擊？

依核心玩法，戰機會自動射擊，玩家專注於移動與閃避。

## 為何還沒有道具、Boss 或多種武器？

目前版本刻意只交付 Phase 1。這些功能已有模組擴充位置，將在指定 Phase 實作。

## 遊戲離開視窗後為何暫停？

為避免玩家因切換視窗受到不可控傷害，視窗失焦會自動暫停。

## 可以調整難度嗎？

開發者可修改 `src/config.js`；正式的使用者難度選項不屬於 Phase 1。
